# Week 03 课堂实验

## 实验目标

构建个人文献 RAG 知识库，并用 Prompt 驱动 LLM 生成文献综述初稿。

## 实验步骤

1. 把 W2 原始文献库导入向量数据库（切分、嵌入）
2. 调整检索策略（chunk size、overlap、top-k）
3. 构建个人 RAG 知识库（≥20 篇文献）
4. 设计 Prompt 引导 LLM 生成有结构的综述
5. 撰写综述初稿，确保有逻辑框架
6. 组内互评综述逻辑框架

## 实验交付

- RAG 知识库代码 + 向量数据库
- AI 辅助综述初稿（含逻辑框架说明）

## 卡住了

- 卡住 → 问 AI（附报错）→ 同组互查 → 举手教师
