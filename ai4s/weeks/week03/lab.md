# Week 03 课堂实验

## 实验目标

整理 Zotero 文献库，配置个人文献知识库（主线：第三方平台；进阶轨：手写最小 RAG），用 Prompt 驱动 LLM 生成有逻辑框架的文献综述初稿。

## 实验步骤（主线）

1. 把 W2 原始文献库导入 Zotero：去重、规范化、打标签
2. 按纳入排除标准确认最终文献集（≥20 篇）
3. 用第三方工具（Kimi/智谱清言/Coze）做智能检索，提取综述所需关键信息
4. 在 Coze/智谱清言上配置个人文献知识库，设计结构化 Prompt（逻辑框架 + 综合要求 + 输出模板）
5. 生成综述初稿，检查逻辑框架（主题/方法论/时间线组织，而非逐篇罗列）
6. 同学互评综述逻辑框架

## 实验步骤（进阶轨·加分，课后）

按 `weeks/week03/RAG-lab.md` 手写最小 RAG：切分→嵌入→存库→检索，跑通语义检索 demo（30 行代码）；可对照 `zotero-lab.md` 的 Zotero MCP 直连路线，比较"谁在检索、检索什么"。

## 实验交付

- Zotero 文献库导出文件（≥20 篇，已去重规范化）
- 个人文献知识库配置（平台配置截图或链接；进阶轨为 RAG demo 代码）
- AI 辅助综述初稿（含逻辑框架说明）
- 阶段反思日志（回应罗家德等（2026）第3章）

## 卡住了

- 卡住 → 问 AI（附报错）→ 同学互助解答 → 举手教师
- 平台知识库检索效果差 → 检查文献切分与标签；进阶轨同理检查 chunk size 与 top-k
- 综述像"逐篇罗列" → 回到结构化 Prompt：先定逻辑框架，再让 LLM 按框架组织
