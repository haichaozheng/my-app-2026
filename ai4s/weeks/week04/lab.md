# Week 04 课堂实验

## 实验目标

配置并运行 gap 分析多智能体（1 主 + 6 子），以自己的 W3 综述为语料完成至少 1 轮完整流程，对关键节点做人工裁决，产出研究问题陈述初稿与 Gap 证据表。

## 实验步骤

1. 检查 opencode agents 配置：主 Agent（primary）+ 六个子智能体（subagent），确认各角色 prompt 与权限纪律（主 Agent 只编排不生成内容）
2. 以 W3 综述为语料启动流程，观察主 Agent 推进"抽取→标注→核验→侦察→凝练"
3. 阅读 Gap Extractor 与 Innovation Mapper 的输出，检查证据锚点（文献、章节、页码）是否可回查
4. 重点裁决：对 Verifier 的新颖性三档（伪空白/相邻/候选真空白）与 Feasibility Scout 的四维侦察（数据/方法/时间/伦理 + MVR）逐条裁决，记录同意/推翻及理由
5. 用 Prober 的条件化追问把 gap 逼成可研究的问题
6. 偏误自检：确认偏误、AI 引用文献真实性抽查（抽 2-3 条锚点文献亲自核验）
7. 撰写研究问题陈述初稿，整理 Gap 证据表与协变量结构，同学互评

## 实验交付

- gap 分析多智能体运行记录（Audit Scribe 核验日志）
- 人工裁决记录（哪里同意智能体、哪里推翻、为什么）
- 研究问题陈述初稿（gap 分析 + 问题表述 + 研究意义 + 贡献类型与"So What?"检验 + 可行性 + 偏误自检）
- Gap 证据表与协变量结构（W5 输入）

## 卡住了

- 卡住 → 问 AI（附上下文）→ 同学互助解答 → 举手教师
- 智能体输出不合理 → 先检查自己的裁决记录，再检查角色 prompt 是否越权（如主 Agent 是否在生成内容）
