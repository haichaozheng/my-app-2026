# Week 04 课堂实验

## 实验目标

用 Prompt 与 Agent 驱动 gap analysis，凝练个人研究问题。

## 实验步骤

1. 从 W3 综述中初步定位潜在 gap
2. 进行至少 1 轮 LLM 多轮 gap analysis 对话
3. 用 Agent 辅助搜索并汇总文献中的 gap
4. 凝练研究问题，判断其分类（描述性/解释性/探索性）
5. 验证选题可行性（数据、方法、理论）
6. 偏误自检：确认偏误、AI 引用文献真实性
7. 撰写研究问题陈述初稿，组内互评

## 实验交付

- gap analysis 对话记录
- 研究问题陈述初稿（gap 分析 + 问题表述 + 研究意义 + 可行性 + 偏误自检）

## 卡住了

- 卡住 → 问 AI（附上下文）→ 同组互查 → 举手教师
