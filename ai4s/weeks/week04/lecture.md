# Week 04 课堂串讲

> 本文件为课堂投影串讲稿，规格与兜底以 `plan.md` 为准。

## 第1节 · Gap analysis 方法论与 Problematization

- 选题是 gap-driven 而非兴趣-driven
- Gap 类型：方法论/理论/数据/情境空白（罗家德第4章研究类型图谱作坐标系）
- gap-spotting vs problematization
- 从综述中定位 gap

## 第2节 · Gap 分析多智能体：从一次对话到一条流水线

- 单次对话的三个局限：无证据锚点、不可核验、无留痕
- 架构：1 主 + 6 子（opencode agents primary/subagent）
  - 主Agent 只编排不生成内容
  - Gap Extractor / Innovation Mapper / Verifier / Feasibility Scout / Prober / Audit Scribe
- 配置与演示：完整运行一轮，展示 Gap 证据表
- AI 引用文献真实性验证：Verifier 存在的理由

## 第3节 · 运行、裁决与凝练

- 个人多智能体运行实操（W3 综述为语料）
- 人工裁决：Verifier 三档核验 + Feasibility Scout 四维侦察 + MVR
- "So What?" 检验与贡献类型（Davis "That's Interesting!"）
- Prober 凝练、可行性自检
- 预告 W5：Gap 证据表与协变量结构是研究设计的直接输入
