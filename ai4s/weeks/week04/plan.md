# Week 04 教学计划

## 本周主题

发现空白→凝练问题 — gap analysis + 选题

> Phase 2: Design 第1周。选题是 gap-driven 而非兴趣-driven；AI 辅助发现空白但研究价值由人判断。本周引入 Agent 工具。

## 学习目标

- 能说明 gap analysis 方法论：gap 不是"我觉得没人做"，而是系统性分析（方法论空白、理论空白、数据空白、情境空白）
- 能用 Prompt 驱动 LLM 进行多轮 gap analysis 对话
- 能用 Agent 辅助文献空白发现（自动搜索并汇总文献中的 gap）
- 能把模糊兴趣凝练为清晰的研究问题，并说明其分类（描述性/解释性/探索性）
- 能对 gap 分析做偏误自检（确认偏误、AI 引用文献真实性验证）

## 教学步骤（3节课）

**第1节 · Gap analysis 方法论（45 分钟）**

1. 选题是 gap-driven 而非兴趣-driven（10 分钟）
2. Gap 类型讲解（15 分钟）：方法论空白、理论空白、数据空白、情境空白
3. Sandberg & Alvesson 的 gap-spotting vs problematization（10 分钟）：💡 课堂互动：教师展示 3 个研究问题实例，全班快速判断各属于哪种 gap 类型（方法论/理论/数据/情境空白），3 分钟抢答
4. 从 W3 综述中初步定位 gap（10 分钟）

**第2节 · Prompt 与 Agent 驱动的 gap 发现（45 分钟）**

5. Prompt 驱动多轮 gap analysis 对话演示（15 分钟）：Deep Research / 多轮对话
6. Agent 辅助文献空白发现（15 分钟）：让 Agent 自动搜索并汇总文献中的 gap
7. 个人 gap analysis 对话实操（15 分钟）：每位博士生进行至少 1 轮 LLM gap analysis

**第3节 · 选题凝练与验证（45 分钟）**

8. 研究问题分类与凝练（15 分钟）：描述性/解释性/探索性
9. 选题可行性验证（10 分钟）：数据可得性、方法适用性、理论支撑
10. 偏误自检（10 分钟）：确认偏误、AI 引用文献真实性验证
11. 研究问题陈述初稿与互评（10 分钟）

## 交付物

- **研究问题陈述**（评分锚点，对应 milestones §2.1，与 W5 合并评分）
  - 研究领域现状概述
  - gap 分析过程和发现的研究空白
  - 凝练的研究问题和初步研究方向
  - 选题可行性的初步判断
- 方法论锚定：体现 gap analysis 方法论、Prompt 驱动对话、Agent 辅助、研究问题分类、选题验证、批判性思维与偏误自检
