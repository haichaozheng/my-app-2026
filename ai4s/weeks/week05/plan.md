# Week 05 教学计划

## 本周主题

研究设计 — 方法选择与规划

> Phase 2: Design 第2周，阶段成果二。"做对"比"做出来"重要；方法选择是研究者的核心判断，不可委托给 AI；偏误自检是人机交互的关键素养。

## 学习目标

- 能为研究问题构建理论框架，说明"为什么需要这个框架、它如何指导假设推导和变量设计"
- 能说明因果推断方法论选择（DID/RDD/IV/面板回归）的理由、前提假设和局限
- 能对比至少 2 种方法论框架并说明选择逻辑
- 能用 Agent 作为"研究设计顾问"探索设计方案
- 能对研究设计做偏误自检，判断 AI 方法建议的可信度
- 能用 Skill 生成研究方案框架模板

## 教学步骤（3节课）

**第1节 · 理论框架与因果推断方法论（45 分钟）**

1. 理论框架构建（15 分钟）：不是"选了某个理论"，而是说明问题为什么需要这个框架
2. 因果推断方法论（15 分钟）：DID/RDD/IV/面板回归，前提假设与局限
3. 变量与测量设计（10 分钟）：理论概念→操作化变量
4. 方法选择逻辑初议（5 分钟）

**第2节 · Agent 辅助研究设计（45 分钟）**

5. Agent 作为"研究设计顾问"演示（15 分钟）：用 Agent 探索设计方案
6. 至少 2 种方法论框架对比（15 分钟）：考虑了哪些方法、为什么选这个。💡 课堂互动：给定一个研究问题，全班分两半分别论证 DID 与 IV 的适用性，各 3 分钟陈述，教师点评
7. 个人研究设计对话实操（15 分钟）：每位博士生用 Agent 探索自己的设计方案

**第3节 · 偏误自检与方案定稿（45 分钟）**

8. 批判性思维与偏误自检（15 分钟）：如何判断 AI 方法建议是否可信
9. Skill 研究方案模板（10 分钟）：用 Skill 快速生成研究方案框架（W2 已学基础，此处深化应用）
10. 研究设计方案撰写与互评（15 分钟）
11. 阶段收束（5 分钟）：Phase 2 完成，预告 Phase 3 研究实施

## 交付物

- **研究设计方案**（评分锚点，对应 milestones §2.2，与 W4 合并评分，阶段成果二 15%）
  - 理论框架、研究假设、变量与测量、数据需求、方法选择理由
- 方法论锚定：体现理论框架构建过程、因果推断方法论选择、至少 2 种方法对比、Agent 辅助设计、偏误自检
