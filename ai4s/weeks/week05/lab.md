# Week 05 课堂实验

## 实验目标

完成个人研究设计方案，包含理论框架、假设、变量、方法选择理由与偏误自检。

## 实验步骤

1. 为研究问题构建理论框架，说明选择理由
2. 梳理因果推断方法论，列出前提假设与局限
3. 设计变量与测量方式
4. 用 Agent 探索设计方案，对比至少 2 种方法
5. 偏误自检：判断 AI 方法建议可信度
6. 用 Skill 生成研究方案框架模板
7. 撰写研究设计方案，组内互评

## 实验交付

- 研究设计方案（理论框架 + 假设 + 变量 + 方法选择理由）
- 偏误自检记录（含方法对比与 Agent 对话记录）

## 卡住了

- 卡住 → 问 AI（附上下文）→ 同组互查 → 举手教师
