# W1 案例：发展为了什么？——GDP、寿命与不平等的跨国速览

## 为什么选这个话题

这门课的受众是社科类博士生——经济学、社会学、政治学、管理学、传播学。第一周的案例要找到一个**所有方向都有共鸣**的问题。

阿马蒂亚·森在《以自由看待发展》中提出：发展不只是 GDP 增长，而是人的可行能力的扩展（健康、教育、自由）。这个命题是所有社科博士的共识起点。但现实数据是否支持？**一张跨国对比表就能制造认知冲突**：

- 美国最富，但不是最长寿
- 中国增长最快，但基尼系数也在攀升
- 一些穷国的预期寿命并不差

这种"不是理所当然"的发现，正是社科研究的起点——**好奇心驱动问题，问题驱动方法**。

## 案例做了什么

用 `wbgapi` 拉取世界银行数据，做三件事：

1. **6 国速览**：6 个代表性国家 × 3 个核心指标（人均 GDP、预期寿命、基尼系数），打印一张表，自动标注最富/最穷/最长寿/最不平等
2. **中国 20 年趋势**：拉取中国 2005-2024 的 6 个核心指标，看增长是否伴随不平等变化
3. **存为 CSV**：拉取全部国家（217 国）× 15 个指标 × 20 年的面板数据，存为三个 CSV 文件，供后续周次分析

## 怎么跑

```text
pip install wbgapi pandas
python wb_explore.py
```

不需要 API key，不需要注册。脚本运行约 1-2 分钟（17 个指标逐个拉取，每个间隔 0.5 秒避免限流）。终端会打印两张表和速览发现，同时生成三个 CSV 文件。

## 如何扩展（留给学生）

### 换成自己研究方向的指标

浏览 [世界银行指标文档](https://data.worldbank.org/indicator?tab=all)（19 个主题、1400+ 指标，可按主题筛选）。找到自己领域的指标代码，加到脚本的 `INDICATORS` 字典里即可：

```python

'IP.PAT.RESD': '本国居民专利申请数'
# 劳动
'SL.UEM.TOTL.ZS': '失业率(%)'
```

### 按收入分组拉取

```python
# 只看高收入国家

# 只看中低收入国家
```

### 用 opencode 改脚本

在项目根目录打开 opencode，直接对话：

```text
读一下 wb/wb_explore.py 和 wb/data/panel.csv。
把脚本改成：
1. 从 panel.csv 读取数据（不要重新调 API）
2. 画一张散点图：X 轴人均GDP，Y 轴预期寿命，点的大小=人口，颜色=基尼系数
3. 标注中国、美国、印度、韩国、巴西、尼日利亚
4. 保存为 data/gdp_vs_life.png
```

这就是 W1 要建立的"对话→改文件→运行"工作模式——**一行代码换一个研究问题**。

## 关于 API 限流

世界银行 API 免费，但偶发限流（返回空响应导致 JSON 解析失败）。脚本已内置 3 次重试 + 0.5 秒间隔。如果仍有个别指标拉取失败（如本次的卫生支出和 CO2 排放），可以：

1. **稍后重跑**：限流通常 10 分钟后恢复
2. **单独补拉**：在 opencode 里单独调 `wb.data.DataFrame('SH.XPD.CHEX.GD.S', 'all', mrv=10)`
3. **接受缺失**：真实社科数据就是有缺口的——这本身就是 W6 数据验证的教学素材

## 与课程的衔接

这个案例不是"做完就结束"的练习，而是**贯穿九周的种子**：

| 周次 | 用这个数据做什么 |
|---|---|
| **W1** | 跑通脚本，看到数据，产生好奇，存 CSV |
| **W2** | 用 Semantic Scholar API 检索"GDP and health"文献 |
| **W3** | 把文献导入 RAG，生成综述 |
| **W4** | 基于综述做 gap analysis——已有研究忽略了什么？ |
| **W5** | 设计研究方案——面板回归？DID？IV？（panel.csv 直接可用） |
| **W6** | 用 `panel.csv` 做实证估计（`statsmodels` / `linearmodels`） |
| **W7** | 仿真——如果基尼系数降低 5%，预期寿命会变多少？ |
| **W8-W9** | 写成论文 |
