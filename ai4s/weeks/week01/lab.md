# Week 01 课堂实验

## 实验目标

验证 AI 工作环境可用，完成第一个 Prompt 驱动的小脚本。

## 实验步骤

1. 安装并配置 opencode/cursor，登录并设置 API key
2. 创建 Python `.venv` 虚拟环境，安装核心依赖库
3. 安装文献管理工具（Zotero 或同类）
4. 编写脚本：调用 LLM API 总结一段文本
5. 运行脚本，确认输出正确
6. 组内互查：每人机器跑通

## 实验交付

- Prompt 驱动小脚本（代码 + 运行截图）
- 环境配置就绪确认
