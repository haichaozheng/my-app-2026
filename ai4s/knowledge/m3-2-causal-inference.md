# 因果推断方法论

> **引入时机**：W4 | **核心挑战**："社科研究需要因果结论，DID/RDD/IV/PSM等方法如何选择和应用？" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

社科研究的核心诉求之一是因果结论——"X导致了Y"，而非仅仅"X与Y相关"。政策评估需要知道"政策是否有效"，管理学研究需要知道"战略选择是否导致了绩效变化"，政治学需要知道"制度变革是否改变了行为"。如果你的研究止步于相关性描述，学术贡献将大打折扣。

W4是研究设计的关键窗口。你需要在这个阶段确定因果识别策略——即如何从观测数据中识别因果效应。因果推断方法的选择不是"哪个方法更高级"，而是"哪个方法的假设在你的研究情境中最可能成立"。选错方法的代价是整个研究设计的失败。

AI工具可以辅助你识别内生性问题、推荐识别策略，但因果推断的核心判断——假设是否合理、识别策略是否可信——必须由你自己做出。LLM可以告诉你DID的平行趋势假设是什么，但无法替你判断在你的数据中平行趋势是否成立。

## 这个知识点的核心内容

### 一、因果推断的核心问题：反事实框架

因果推断的本质是回答一个问题：**如果X没有发生变化，Y会怎样？** 这就是反事实（Counterfactual）——你永远无法同时观察到同一个体在处理和未处理两种状态下的结果。

```
因果效应 = 实际结果 - 反事实结果
         = Y(处理) - Y(未处理)

问题：你只能观察到其中一个

解决思路：找到一个好的"反事实代理"
  - DID: 用控制组的变化趋势作为反事实
  - RDD: 用断点附近的未处理组作为反事实
  - IV: 用工具变量创造外生变异来识别因果
  - PSM: 用倾向得分匹配"相似"的未处理组作为反事实
```

**反事实框架的核心教训**：每种因果推断方法本质上都是在构造反事实，方法的优劣取决于它构造的反事实是否可信。

### 二、常用因果推断方法概览

#### 1. 双重差分法（DID）

```
核心逻辑：处理组与对照组的差异变化
DID估计量 = [Y_处理,后 - Y_处理,前] - [Y_对照,后 - Y_对照,前]

前提假设：
  - 平行趋势假设：在无处理情况下，处理组和对照组有相同的变化趋势
  - 无溢出效应：处理不影响对照组
  - 处理不可逆：个体不会在处理组和对照组间切换

适用场景：
  - 政策评估（政策实施地区 vs 未实施地区）
  - 制度变革的效应（改革前 vs 改革后）

经典应用：Card & Krueger (1994) 最低工资对就业的影响
```

#### 2. 断点回归设计（RDD）

```
核心逻辑：在断点附近，处理分配近似随机
Sharp RDD: X >= c 则处理，X < c 则未处理
Fuzzy RDD: X >= c 增加处理概率

前提假设：
  - 个体无法精确操控断点变量（连续性假设）
  - 断点附近的其他特征连续

适用场景：
  - 选举门槛（得票率断点）
  - 政策资格线（贫困线、分数线）
  - 地理边界

经典应用：Lee (2008) 美国众议院选举的在位者优势
```

#### 3. 工具变量法（IV）

```
核心逻辑：找到一个只通过X影响Y的变量Z
Z → X → Y（有效通道）
Z → Y（排他性约束：不允许直接通道）

前提假设：
  - 相关性：Z与X强相关
  - 外生性：Z只通过X影响Y
  - 单调性：Z对X的影响方向对所有个体一致

适用场景：
  - 内生性来源明确（如遗漏变量、反向因果）
  - 能找到满足排他性约束的工具变量

经典应用：Acemoglu et al. (2001) 殖民者死亡率作为制度质量的工具变量
```

#### 4. 倾向得分匹配（PSM）

```
核心逻辑：用倾向得分匹配"相似"的未处理个体作为反事实

前提假设：
  - 条件独立假设：给定可观测特征，处理分配与潜在结果独立
  - 共同支撑：处理组和对照组在倾向得分分布上有重叠

注意：PSM只能解决基于可观测变量的选择偏误
  → 如果存在不可观测的混淆因素，PSM无法解决

适用场景：
  - 处理非随机但有丰富的可观测协变量
  - 常作为DID的前置步骤（PSM-DID）

经典应用：Heckman et al. (1997) 职业培训的效应评估
```

#### 5. 合成控制法（SCM）

```
核心逻辑：用多个未处理单位的加权组合构造"合成控制组"

前提假设：
  - 处理单位与合成控制组在干预前有相似的轨迹
  - 权重非负且总和为1

适用场景：
  - 只有一个或少数处理单位（如某省的政策试点）
  - 干预期较长，需要长期反事实轨迹

经典应用：Abadie & Gardeazabal (2003) 巴斯克地区冲突的经济影响
```

### 三、各方法的前提假设与适用条件

| 方法 | 核心假设 | 最关键的检验 | 不适合的情况 |
|---|---|---|---|
| DID | 平行趋势 | 平行趋势检验（事件研究图） | 处理组与对照组趋势本就不同 |
| RDD | 断点处连续性 | 操控检验（McCrary密度检验） | 个体可操纵断点变量 |
| IV | 排他性约束 | 过度识别检验（若过度识别） | 找不到有效的工具变量 |
| PSM | 条件独立 | 平衡性检验、共同支撑 | 有重要的不可观测混淆变量 |
| SCM | 拟合优度 | 干预前的拟合优度 | 干预前拟合差 |

### 四、方法选择决策树

```
你的研究是否有明确的"处理"或"干预"？
├── 否 → 考虑自然实验或IV，或退回描述性/关联性研究
└── 是
    ├── 处理是否在某个断点/门槛处发生？
    │   └── 是 → RDD
    ├── 是否有明确的处理组和对照组？
    │   ├── 是，且处理前有数据 → DID
    │   ├── 是，但处理前无数据 → PSM（注意局限）
    │   └── 否，只有一个处理单位 → SCM
    └── 是否存在内生性问题需要解决？
        └── 是，且有合适工具变量 → IV
        └── 是，但无工具变量 → 考虑自然实验或识别策略重构
```

### 五、AI辅助因果推断方案设计

#### 用LLM识别内生性问题

```
Prompt模板：

我的研究问题是[X对Y的因果效应]，数据来自[数据描述]。
请帮我识别可能存在的内生性问题：
1. 遗漏变量偏误：哪些不可观测因素可能同时影响X和Y？
2. 反向因果：Y是否可能影响X？
3. 选择偏误：处理分配是否与潜在结果相关？
4. 测量误差：X或Y的测量是否存在系统性偏差？

请按严重程度排序，并说明每个问题的潜在方向（正偏还是负偏）。
```

#### 用LLM推荐识别策略

```
Prompt模板：

我的研究情境如下：
- 研究问题：[X对Y的效应]
- 处理定义：[处理是什么]
- 数据结构：[面板/截面、时间范围、样本规模]
- 已知的内生性来源：[列出]

请推荐2-3种可能的因果识别策略，对每种策略：
1. 核心假设是什么？
2. 在我的情境下这个假设是否合理？
3. 需要什么数据来实施？
4. 主要局限性是什么？
```

#### 用LLM辅助方法论证

```
Prompt模板：

我计划用[DID/RDD/IV]方法研究[问题]。请帮我：
1. 列出该方法的所有关键假设
2. 对每个假设，给出在我的情境下是否成立的初步判断
3. 建议具体的检验方法（统计检验或逻辑论证）
4. 指出最可能被审稿人质疑的假设，以及如何应对
```

## 关键细节与易错点

- **易错：DID不加检验就使用**。DID的有效性完全依赖平行趋势假设，不做事件研究图就使用DID等于跳过了最关键的假设检验
- **易错：PSM当作"万能药"**。PSM只能控制可观测变量，如果你的内生性来自不可观测因素，PSM无能为力。很多论文用PSM却忽略了这一点
- **易错：IV的排他性约束不可验证**。排他性约束在逻辑上不可验证，只能论证。你需要给出令人信服的理论论证，而非仅靠过度识别检验
- **易错：RDD带宽选择不当**。带宽太大引入偏误，太小损失精度。应该报告不同带宽下的稳健性
- **易错：用AI推荐方法时忽视假设**。LLM可能推荐DID因为"最常用"，但你的数据可能不满足平行趋势
- **易错：混淆"统计显著性"与"因果识别"**。系数显著不代表因果识别成功——因果识别取决于假设是否成立，而非p值大小

## 社科科研示例

你研究"数字普惠金融政策对农村居民消费的影响"。某省2018年起推行数字普惠金融试点，其他省未推行。

**内生性问题识别**：
1. 选择偏误：试点省可能本就经济更发达、金融基础设施更好
2. 反向因果：消费水平高的地区可能更早被选为试点

**方法选择推理**：
- RDD？政策没有明确的断点变量，不适合
- IV？难以找到只影响试点选择但不直接影响消费的工具变量
- DID？有处理组（试点省）和对照组（非试点省），有政策前后数据——可行！但需检验平行趋势
- PSM-DID？可以先用PSM匹配相似的对照组，再做DID，增强平行趋势的可信度

**最终策略**：PSM-DID，并做以下检验：
1. 平行趋势检验（事件研究法）
2. 安慰剂检验（随机化政策时间）
3. 排除其他同期政策干扰

**AI辅助**：用LLM识别可能遗漏的控制变量，用LLM起草方法论证段落，但平行趋势检验的逻辑和安慰剂检验的设计必须自己把关。
