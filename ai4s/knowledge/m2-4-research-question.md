# 研究问题分类与凝练

> **引入时机**：W4 | **核心挑战**："如何把模糊的兴趣凝练为清晰的研究问题？描述性/解释性/探索性问题如何区分？" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

W3选题阶段最常见的问题不是"找不到题"，而是"问题不够清晰"。很多博士生的选题表述停留在"我想研究XX和YY的关系"这种模糊层面——既不知道自己到底在问什么，也不知道不同类型的研究问题对方法和论证的要求完全不同。

研究问题的类型决定了后续一切：方法选择、数据需求、论证结构、理论贡献的表述方式。一个解释性问题和描述性问题需要的论证逻辑截然不同；一个探索性问题和因果推断问题需要的证据标准也完全不同。如果你在选题阶段没有把问题类型弄清楚，后续的研究设计就会陷入混乱——用描述性方法回答因果问题，或者用因果推断方法回答探索性问题。

掌握研究问题的分类体系和凝练方法，你能把"我对XX感兴趣"转化为"XX在ZZ条件下对YY的影响机制是什么"这样清晰、可操作的研究问题，并据此选择正确的研究路径。

## 这个知识点的核心内容

### 一、研究问题的三种类型

#### 1. 描述性问题（Descriptive Questions）

描述现象的基本特征：是什么？有多少？分布如何？

```
典型表述：
- "XX的分布特征是什么？"
- "XX在不同群体间的差异有多大？"
- "XX随时间的变化趋势是什么？"

方法论含义：
- 方法：描述性统计、可视化、聚类分析
- 数据：需要代表性样本，关注抽样设计
- 理论：不需要因果机制，但需要分类/测量框架
- 论证：核心是测量的信度和效度

社科示例：
- "中国城市居民数字素养的水平分布与群体差异是什么？"
- "平台经济中灵活就业者的收入分布特征如何？"
- "各国数字治理政策的类型与演变趋势是什么？"

常见误区：
- 误以为描述性问题"没有理论贡献"——好的描述本身就是贡献，
  特别是新现象、新数据、新测量
- 误以为描述性问题"不需要方法"——抽样设计、测量信效度、
  分类框架都是方法论挑战
```

#### 2. 解释性问题（Explanatory Questions）

解释现象的原因或机制：为什么？因果机制是什么？

```
典型表述：
- "XX是否导致YY？"
- "XX对YY的因果效应是什么？"
- "XX通过什么机制影响YY？"

方法论含义：
- 方法：因果推断（DID/IV/RDD/实验）、机制检验
- 数据：需要满足因果识别条件的数据结构
- 理论：必须有理论框架预测因果方向和机制
- 论证：核心是因果识别策略和稳健性

社科示例：
- "数字金融普及是否导致农村居民消费升级？因果效应与机制"
- "制度透明度对政府信任的因果效应是什么？"
- "社交媒体使用通过何种机制影响政治参与？"

常见误区：
- 误以为"发现相关=发现因果"——相关只是起点，不是结论
- 误以为因果推断方法本身就能保证因果推断——方法只是工具，
  关键是研究设计和识别策略
- 忽略异质性——平均处理效应可能掩盖重要的群体差异
```

#### 3. 探索性问题（Exploratory Questions）

探索未知领域：如何理解？什么机制在起作用？如何建构理论？

```
典型表述：
- "XX现象的内在逻辑是什么？"
- "XX在ZZ情境中如何运作？"
- "如何理解XX与YY之间的关系？"

方法论含义：
- 方法：案例研究、扎根理论、深度访谈、民族志
- 数据：需要深入、丰富的质性数据
- 理论：目标是建构或修正理论，而非检验已有理论
- 论证：核心是理论抽样的合理性、分析的信实度、
  理论饱和的达成

社科示例：
- "平台劳动者如何理解和管理自己的职业身份？"
- "乡村数字治理中正式制度与非正式规范如何互动？"
- "社交媒体上的公共讨论如何形构集体记忆？"

常见误区：
- 误以为探索性研究"不需要方法论"——质性研究有严格的方法规范
- 误以为探索性研究"不严谨"——严谨的标准不同，但要求同样高
- 误把探索性发现当作解释性结论——探索性研究提出假设，
  不应声称验证假设
```

#### 三种类型的关系

```
探索性问题 → 提出假设/理论
    ↓
描述性问题 → 量化现象、描述分布
    ↓
解释性问题 → 检验因果、验证理论

但实际研究中，三者的关系不是线性的：
- 一个好的研究可能同时包含多种类型的问题
- 描述性发现可能触发新的探索性问题
- 解释性研究的失败可能要求回到探索性阶段
- 混合方法研究自然跨越多种问题类型

关键：明确你的核心研究问题属于哪种类型，
以该类型的标准为首要标准，其他类型的问题为辅助。
```

### 二、从模糊兴趣到清晰问题的凝练过程

#### 凝练三步法

```
Step 1：兴趣陈述
"我对[现象X]感兴趣" → 记录你的原始兴趣，不做评判

示例：
"我对社交媒体对青年人政治态度的影响感兴趣"

Step 2：现象聚焦
从宽泛兴趣中提取可观察的现象

引导问题：
- 具体是什么现象？（"政治态度"太宽泛→"政治极化"/"政治冷漠"/"政治效能感"）
- 哪个群体？（"青年人"→"18-25岁城市大学生"/"30-40岁白领"）
- 什么情境？（哪个国家/平台/时间段？）

示例：
"我对社交媒体算法推荐对18-30岁城市青年政治极化的影响感兴趣"

Step 3：问题凝练
将聚焦后的现象转化为特定类型的研究问题

选择问题类型的判断：
- 该现象缺乏基本描述？→ 描述性问题
- 已有描述但因果不清？→ 解释性问题
- 现象本身未被深入理解？→ 探索性问题

示例（解释性路径）：
"社交媒体算法推荐对18-30岁城市青年政治极化是否有因果效应？
如果存在，通过何种机制起作用？"

示例（探索性路径）：
"18-30岁城市青年如何在社交媒体信息环境中形成和调整政治立场？"
```

#### 常见的凝练障碍与对策

```
障碍1：兴趣太宽泛
表现："我想研究数字化转型"
对策：逐层追问——数字化转型中的什么现象？对谁的影响？
      哪个方面的数字化转型？

障碍2：问题与兴趣脱节
表现：凝练后的问题自己不感兴趣
对策：回到Step 1，检查凝练过程中是否丢失了核心兴趣点

障碍3：问题类型混淆
表现：想回答因果问题但数据只支持描述性分析
对策：诚实地面对数据约束，要么换问题类型，要么换数据

障碍4：问题过于琐碎
表现：凝练后的问题太窄，理论贡献有限
对策：在具体问题和更广的理论意义之间建立桥梁——
      "这个具体问题如何回应更大的理论争论？"

障碍5：问题过于宏大
表现：一个问题试图回答太多
对策：拆分为子问题，选择最核心的一个作为主问题
```

### 三、好的研究问题的标准：FINER原则

FINER是评估研究问题质量的经典框架：

```
F - Feasible（可行性）
- 能否在给定资源（时间、数据、方法、经费）内完成？
- 关键检查：数据可得性、方法掌握程度、时间预算

I - Interesting（有趣性）
- 你自己是否真的感兴趣？（将投入大量时间，不感兴趣很难坚持）
- 领域内其他研究者是否关心？（决定论文的发表前景和影响力）

N - Novel（新颖性）
- 是否对已有知识有增量贡献？（不需要革命性创新，但需要有增量）
- 新颖性的来源：新现象、新方法、新数据、新情境、新理论

E - Ethical（伦理合规）
- 研究过程是否符合伦理规范？（人体实验、数据隐私、知情同意等）
- 关键检查：是否需要伦理审查？数据使用是否合规？

R - Relevant（相关性）
- 对学术共同体是否有价值？（理论贡献）
- 对社会实践是否有意义？（政策含义、实践启示）
```

#### FINER评估模板

```
对研究问题[你的问题]做FINER评估：

| 维度 | 评分(1-5) | 理由 | 风险 |
|------|-----------|------|------|
| Feasible |     |      |      |
| Interesting |     |      |      |
| Novel |     |      |      |
| Ethical |     |      |      |
| Relevant |     |      |      |
| 总分 |     | /25  |      |

判断标准：
- 总分 ≥ 20：推进
- 总分 15-19：有条件推进，需要改进低分维度
- 总分 < 15：需要重大调整或重新选题

特别注意：
- Feasible ≤ 2：直接否决，无论其他维度多高
- Ethical ≤ 2：直接否决，需要重新设计
- Novel ≤ 2：需要调整问题表述或增加创新维度
```

#### 与LLM对话做FINER评估

```
Prompt模板：

"请用FINER框架评估我的研究问题：

研究问题：[完整问题表述]
研究方法：[方法概要]
数据来源：[数据描述]
时间约束：6周

对每个维度：
1. 给出1-5的评分
2. 给出评分理由
3. 如果评分≤3，请提出改进建议
4. 指出该维度最可能出现的风险

最后请给出：
- 总体评估：推荐推进 / 有条件推进 / 建议调整
- 最需要改进的1-2个维度
- 具体的改进建议"
```

### 四、研究问题与研究方法的关系

研究问题的类型从根本上约束了研究方法的选择。

#### 匹配矩阵

```
| 研究问题类型 | 推荐方法 | 可选方法 | 不适用方法 |
|---|---|---|---|
| 描述性 | 描述统计, 可视化, 聚类 | 问卷, 内容分析 | 因果推断方法 |
| 解释性(因果效应) | DID, IV, RDD, 实验 | PSM, 断点回归 | 纯描述统计 |
| 解释性(因果机制) | 中介分析, 过程追踪 | 案例比较 | 仅相关性分析 |
| 探索性 | 扎根理论, 民族志 | 深度访谈, 案例研究 | 假设检验方法 |
```

#### 方法选择的决策树

```
你的核心问题是什么？
├── "XX是什么？" → 描述性问题
│   ├── 需要量化描述 → 问卷调查/二手数据分析
│   └── 需要类型刻画 → 内容分析/分类研究
│
├── "XX是否导致YY？" → 解释性问题（因果效应）
│   ├── 有准自然实验 → DID/RDD
│   ├── 有工具变量 → IV
│   ├── 可以做实验 → 实验/问卷实验
│   └── 都没有 → 需要调整问题或寻找研究设计创新
│
├── "XX为什么导致YY？" → 解释性问题（因果机制）
│   ├── 量化路径 → 中介分析+调节效应
│   └── 质性路径 → 过程追踪
│
└── "如何理解XX？" → 探索性问题
    ├── 新现象 → 案例研究/扎根理论
    ├── 新情境 → 民族志/深度访谈
    └── 新概念 → 概念分析/理论建构
```

#### 常见的错配与纠正

```
错配1：用OLS回归回答因果问题
纠正：如果问题是因果性的，必须使用因果推断方法，
      OLS只是起点而非终点

错配2：用问卷调查回答探索性问题
纠正：问卷预设了答案框架，不适合探索性研究；
      探索性研究需要开放式方法

错配3：用案例研究做因果推断
纠正：案例研究可以揭示因果机制（过程追踪），
      但不能估计因果效应的大小

错配4：用实验方法研究宏观现象
纠正：实验的内部效度高但外部效度低，
      宏观因果问题通常需要自然实验或准实验
```

## 关键细节与易错点

- **易错：把研究问题和研究主题混淆**。"数字金融"是主题，"数字金融普及对农村居民消费升级的因果效应"是问题。选题定的是问题，不是主题
- **易错：一个问题包含多个子问题但未区分主次**。一篇论文应该有一个核心问题和1-2个辅助问题，超过3个子问题通常意味着选题过大
- **易错：问题表述中使用模糊因果语言**。"XX对YY有影响"这种表述不够精确——是因果效应还是相关性？影响的方向是什么？通过什么机制？
- **易错：选择问题类型时受方法偏好驱动而非问题性质驱动**。不要因为你会DID就把所有问题都表述为因果问题——有些现象更需要描述或探索
- **误区：认为解释性问题一定比描述性问题"高级"**。好的描述性研究可以开辟新领域，而差的解释性研究只是用复杂方法得出不可靠的结论
- **误区：FINER各维度同等重要**。Feasible和Ethical是一票否决项，Novel和Relevant决定价值，Interesting决定持久性

## 社科科研示例

你是社会学博士生，对"社区治理中的居民参与"感兴趣。

**Step 1（兴趣陈述）**：
"我对社区治理中居民如何参与公共事务感兴趣"

**Step 2（现象聚焦）**：
引导追问后聚焦——
- 什么现象？"数字社区平台上的居民参与行为"
- 哪个群体？"城市商品房小区居民"
- 什么情境？"使用社区App的小区 vs 不使用的小区"

**Step 3（问题凝练，三条路径）**：

描述性路径："城市商品房小区中，数字社区平台使用者的居民参与行为特征是什么？与不使用者有何差异？"

解释性路径："数字社区平台的引入是否提高了居民参与公共事务的频率和深度？如果存在效应，通过何种机制起作用？"

探索性路径："城市商品房小区居民如何在数字社区平台与线下社区空间的交互中建构公共参与实践？"

**FINER评估（解释性路径）**：

| 维度 | 评分 | 理由 | 风险 |
|------|------|------|------|
| Feasible | 3 | 需要找到平台引入的准自然实验，数据可得性中等 | 平台引入时间不一致，DID设计可能受限 |
| Interesting | 4 | 数字治理是热点，本人也感兴趣 | 无 |
| Novel | 3 | 已有数字参与研究，但社区平台的因果评估较少 | 可能已有类似研究 |
| Ethical | 5 | 使用公开数据，无伦理风险 | 无 |
| Relevant | 4 | 社区治理数字化是政策前沿 | 无 |

总分19/25，有条件推进。关键改进方向：Feasible——需要尽快确认是否有合适的准自然实验数据。如果数据不可得，转向描述性或探索性路径。

**与LLM对话验证**：

你把解释性路径发给LLM做反方论证。LLM指出："社区App的引入往往是社区自选的，存在严重的自选择偏误——愿意引入App的社区可能本身就是参与度高的社区。DID的平行趋势很可能不成立。"

你据此调整：增加PSM-DID策略，或考虑换用"政府统一推进平台"的政策作为外生冲击。如果找不到合适的外生冲击，则降级为描述性+探索性的混合方法研究。
