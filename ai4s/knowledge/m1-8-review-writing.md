# 综述写作规范

> **引入时机**：W2 | **核心挑战**："文献综述不是罗列，需要有逻辑框架——如何写好的综述？" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

文献综述是社科博士论文中最难写的部分之一。很多同学以为综述就是"把读过的文献按主题分类，然后逐篇介绍"，结果写出来的是"文献罗列"而非"文献综述"——读起来像一本注释目录，缺乏论证逻辑，无法引导读者理解"这个领域走到了哪里、还有哪些问题没解决"。

综述不是罗列而是论证，这个区分至关重要。罗列式的综述只是告诉读者"A说了什么、B说了什么、C说了什么"，而论证式的综述要让读者理解"为什么这些研究走到了今天这个状态、当前的争论焦点是什么、下一步应该往哪里走"。前者是信息的堆砌，后者是知识的组织。

在AI4S模式下，这个区分更加重要——AI可以快速生成"罗列式"的综述（因为它擅长归纳和罗列），但无法自动生成"论证式"的综述（因为这需要研究者对领域的深层理解和独特判断）。理解好综述的写作规范，你才能有效地指导AI生成有价值的内容，并在AI初稿基础上注入你的学术判断力。

## 这个知识点的核心内容

### 综述的三大组织逻辑

**按主题组织（Thematic Organization）**——最常用、最推荐

将文献按研究主题分组，每个主题下展示不同学者的观点对话：

```
综述结构示例（数字鸿沟与教育公平）：

1. 数字鸿沟的概念演化
   1.1 从"接入鸿沟"到"使用鸿沟"（van Dijk, 2006; Wei et al., 2011）
   1.2 从"使用鸿沟"到"结果鸿沟"（Wei & Teo, 2021; Ragnedda, 2018）
   1.3 争论：鸿沟在缩小还是深化？

2. 数字鸿沟影响教育公平的机制
   2.1 资源获取机制：在线教育资源的不平等分配
   2.2 技能转化机制：数字素养差异放大学习差距
   2.3 社会网络机制：在线学习社群的排斥效应

3. 干预策略的效果评估
   3.1 基础设施供给策略的局限
   3.2 数字素养培训的效果
   3.3 制度设计：从"可及性"到"可利用性"

4. 研究空白与本文贡献
```

按主题组织的优势：逻辑清晰，便于展示学术对话，读者容易跟随。适合大多数社科综述。

**按方法论组织（Methodological Organization）**——适合方法论多元的领域

将文献按研究方法分组，比较不同方法得出的结论差异：

```
综述结构示例（社会资本与健康）：

1. 问卷调查研究的发现
   - 社会网络规模与自评健康的正相关（多次横截面验证）
   - 但因果方向不明确

2. 纵向追踪研究的发现
   - 社会资本对健康的长期预测效应
   - 但存在选择性偏误

3. 实验研究的发现
   - 社会排斥实验对生理指标的即时影响
   - 但生态效度存疑

4. 自然实验的发现
   - 社区社会资本的外生变异对健康的影响
   - 方法比较与整合
```

按方法论组织的优势：便于评估证据强度，凸显方法论对结论的影响。适合因果推断类综述。

**按时间线组织（Chronological Organization）**——适合概念演化类综述

按研究的时间发展展示知识积累过程：

```
综述结构示例（组织韧性研究）：

1. 奠基期（2000-2010）：从工程韧性到生态韧性
2. 扩展期（2010-2018）：从"恢复"到"适应"
3. 转型期（2018至今）：从"适应"到"转型"
4. 当前前沿：数字化情境下的韧性重构
```

按时间线组织的优势：展示知识积累过程，适合概念演化叙事。但容易变成"罗列"——A年B说了什么、C年D说了什么——需要在时间叙事中嵌入论证逻辑。

**选择建议**：外层按主题组织，内层可选择方法论或时间线细化。

### 综述不是罗列而是论证

**罗列式综述**（差）：

> 张三（2020）研究了数字经济对就业的影响，发现存在替代效应。李四（2021）也研究了这个问题，发现存在互补效应。王五（2022）的研究表明效应方向取决于行业特征。赵六（2023）基于微观数据发现...

问题：只是按顺序介绍每篇文献的结论，读者无法理解为什么不同研究得出不同结论，也无法判断哪个结论更可信。

**论证式综述**（好）：

> 数字经济对就业的影响是否存在替代效应，是当前文献的核心争论。基于行业层面数据的研究普遍发现替代效应占主导（张三，2020；赵六，2023），但基于企业层面数据的研究则更多发现互补效应（李四，2021）。这一分歧可能源于分析单位的不同：行业层面数据掩盖了企业内部的岗位重组——当AI替代某些岗位时，同一企业可能创造新的互补性岗位（王五，2022）。这意味着，替代与互补可能并非对立关系，而是同一过程的不同维度。然而，现有研究大多将两者视为互斥，缺乏同时考察替代与互补的分析框架。

区别：论证式综述不仅报告了每篇文献的结论，还解释了分歧的来源、评估了不同结论的可信度、指出了现有研究的逻辑缺陷，最终自然地引出了研究空白。

**从罗列到论证的转化技巧**：

1. **先问"为什么"再介绍**：在介绍每篇文献前，先说明"为什么要在这篇文献的位置讨论它"——它与前面的文献是什么关系（支持/挑战/细化/替代）？

2. **用连接词建立逻辑**：
   - 递进：更进一层、在此基础上、进一步地
   - 转折：然而、与此相反、值得注意的是
   - 因果：正因如此、由此导致、这解释了
   - 整合：综合以上、调和这两种观点、这似乎表明

3. **每个段落有论点句**：段落的第一句应是该段的核心论点，后面的文献是用来支撑这个论点的证据，而非反过来。

### 从文献到研究空白的论证链路

好的综述不是在结尾突然宣布"本文填补了XX空白"，而是通过文献梳理自然地推导出空白的存在。论证链路如下：

```
文献现状 → 内在逻辑矛盾 → 空白识别 → 我的贡献
```

**示例**：

```
文献现状：
- 数字经济对就业的影响研究中，替代效应和互补效应的证据并存
- 替代效应主要在行业层面数据中发现，互补效应主要在企业层面数据中发现

内在逻辑矛盾：
- 如果替代和互补是同一过程的不同维度，那么将两者视为互斥的分析框架存在逻辑缺陷
- 行业层面和企业层面结论的不一致，暗示分析单位的选择影响了结论

空白识别：
- 缺乏一个同时考察替代与互补效应的统一分析框架
- 缺乏跨分析单位的系统性比较研究

我的贡献：
- 构建"任务替代-岗位互补"的分析框架，统一解释替代与互补
- 使用多层数据（个体-企业-行业）进行跨层次分析
```

关键：空白不是"没人做过"，而是"现有研究在逻辑上有缺陷/不足，而我的方法可以弥补"。前者的论证力弱（没人做可能是因为不值得做），后者的论证力强（从文献内在逻辑推导出来）。

### 好综述与差综述的对比

| 维度 | 差综述 | 好综述 |
|------|-------|-------|
| 组织 | 按文献顺序罗列 | 按论点逻辑组织 |
| 连接 | "A说了X。B说了Y。" | "A发现X，但B基于不同数据发现Y，这一分歧源于..." |
| 贡献 | "没人做过这个" | "现有研究在这个逻辑节点上有缺陷" |
| 理论 | 只列举理论名称 | 阐述理论的核心命题和竞争性预测 |
| 争论 | 只呈现共识 | 凸显分歧并分析分歧根源 |
| 方法 | 不讨论方法差异 | 比较不同方法的证据强度 |
| 空白 | 最后一节突然出现 | 从文献逻辑自然推导 |
| 语气 | 客观陈述无立场 | 有学术判断但尊重不同观点 |

### 学术写作中的引用规范

**引用的时机和方式**：

- **支撑论点**：当你提出一个论点时，需要引用支持该论点的文献。"社会资本对健康有正向影响（Putnam, 2000; 张三, 2021）"
- **标注来源**：当你引用具体数据、定义或理论时，必须标注来源。"根据世界银行（2022）的数据，全球数字鸿沟指数为..."
- **呈现分歧**：当你指出文献中的分歧时，引用正反双方的代表性文献。"关于X的影响，既有研究支持正向效应（A, 2020），也有研究发现负向效应（B, 2021）"
- **标注方法**：当你描述某研究的方法时，引用原文。"该研究采用断点回归设计识别因果效应（C, 2019）"

**常见引用错误**：

- 只引用不评价：列了一堆引用但没有说明这些文献为什么支持你的论点
- 选择性引用：只引用支持自己观点的文献，忽略反方证据
- 二手引用：引用A对B的转述而非B的原文，可能导致误读
- 过度自引：过多引用自己的前期工作

**AI辅助引用的注意事项**：

- AI可能编造引用——每条引用必须验证
- AI倾向于引用高被引文献——可能遗漏重要的新近研究
- AI的引用格式可能不一致——需要统一调整
- AI可能错误归因——将A的观点归于B，检查引文与观点的对应关系

## 关键细节与易错点

- **易错：综述写成"文献罗列"**。最常见的错误。检验方法：遮住文献作者名，看段落是否仍有逻辑——如果去掉"张三说""李四说"后段落变成一堆无关联的句子，说明你在罗列而非论证
- **易错：研究空白凭空提出**。"没人做过"不是好的空白论证。好的空白论证是"现有研究在这里有逻辑缺陷/方法局限/理论矛盾，而我可以弥补"
- **易错：综述缺乏自己的学术判断**。好的综述不仅有文献的组织，还有作者的判断——哪些论点更可信、哪个争论更关键、哪种方法更有说服力。这种判断是你作为研究者的核心价值
- **易错：AI生成综述后不修改论证逻辑**。AI擅长生成"罗列式"综述，因为它的训练数据中这类文本最多。你必须将AI的罗列式初稿改造为论证式综述
- **易错：引用密度不均**。有的段落大量堆砌引用，有的段落完全没有引用。前者可能是罗列而非论证，后者可能是缺乏文献支撑的个人观点

## 社科科研示例

**场景**：一位传播学博士生撰写"算法推荐与政治极化"的文献综述，比较罗列式和论证式写作。

**罗列式（差）**：

> 算法推荐对政治极化的影响引起了学者的关注。Pariser（2011）提出了"过滤气泡"的概念，认为算法会限制用户接触多元观点。Sunstein（2001）早前就提出了"信息茧房"的概念。Flaxman et al.（2016）通过实验发现算法推荐增加了意识形态隔离。然而，Guess et al.（2018）的调查数据表明算法对极化的影响有限。Bakshy et al.（2015）基于Facebook数据发现用户的选择性接触比算法影响更大。最近，Moser et al.（2023）的元分析发现...

**论证式（好）**：

> 算法推荐是否加剧政治极化，取决于算法效应与用户选择效应的相对大小，这是当前文献的核心争论。早期理论（Pariser, 2011; Sunstein, 2001）假设算法是信息过滤的主要驱动力，但实证研究揭示了更复杂的图景。一方面，实验研究普遍发现算法推荐确实增加了意识形态隔离（Flaxman et al., 2016）；另一方面，基于大规模观察数据的研究则表明，用户自身的选择性接触远比算法过滤的影响更大（Bakshy et al., 2015; Guess et al., 2018）。这一实验-观察分歧可能源于方法论的差异：实验控制了用户选择，因此能分离出算法的纯效应；而观察数据中算法效应和选择效应混杂，难以分离。这一方法论困境意味着，我们需要一种能同时捕捉算法和用户行为互动的研究设计——这正是本文的切入点。

**用AI将罗列式改写为论证式**：

在实际写作中，你可以先用AI生成罗列式初稿（效率高），然后用以下Prompt将其改造为论证式综述：

```
以下是一段罗列式文献综述。请将其改写为论证式综述，要求：
1. 每个段落以论点句开头
2. 文献之间用逻辑连接词串联（而非简单罗列）
3. 呈现不同文献之间的对话关系（支持/挑战/细化/替代）
4. 在段落结尾归纳该段的核心结论
5. 如果文献间存在分歧，分析分歧的根源（方法论？数据？理论？）

原文：
[粘贴罗列式综述]
```

**综述写作的渐进流程**：

1. 第一稿：让AI生成罗列式初稿，确保文献覆盖全面
2. 第二稿：人工改写为论证式，注入你的学术判断
3. 第三稿：用RAG知识库补充遗漏的引用和证据
4. 第四稿：检查论证链路是否通顺，空白推导是否自然
5. 第五稿：同行评议（同学互评），发现逻辑漏洞
