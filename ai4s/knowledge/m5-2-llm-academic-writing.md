# LLM辅助学术写作

> **引入时机**：W8 | **核心挑战**："如何用LLM辅助各章节起草、润色、修订？注意学术诚信边界。" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

到了W8，同学们已经积累了大量的研究材料——文献笔记、研究设计方案、数据分析代码和结果——现在需要将这些碎片化的素材组织成一篇完整的学术论文。这个过程耗时且痛苦：初稿的空白页焦虑、每一段的反复推敲、格式调整的机械劳动。LLM可以显著加速这个过程，但前提是你知道如何正确地使用它。

LLM辅助写作的本质不是"让AI替你写论文"，而是"让你成为更高效的学术写作者"。类比来看，这就像用统计软件做回归分析：软件负责计算，但选择模型、解读结果、判断因果逻辑的责任始终在研究者本人。同样，LLM可以帮你润色语言、检查逻辑、生成初稿段落，但研究问题的提出、理论框架的构建、学术贡献的判断——这些构成论文灵魂的工作——必须由你自己完成。

值得注意的是，LLM辅助写作的效果高度依赖于你给出的指令质量。一个模糊的Prompt只能得到泛泛而谈的输出，而一个精确的、包含足够上下文的Prompt则能产出高度可用的文本片段。这正是本知识点要解决的核心问题：如何为论文各章节设计高质量的Prompt，让LLM真正成为你的写作助手。

## 这个知识点的核心内容

### LLM辅助写作的流程

LLM辅助学术写作遵循"大纲→初稿→修订→润色"四步流程：

**第一步：大纲生成**。不要让LLM直接写正文，先让它帮你构建大纲。提供你的研究问题、核心发现和目标期刊，让LLM生成结构化大纲，然后你在此基础上调整。

**第二步：初稿起草**。对大纲中的每个小节，分别让LLM辅助起草。关键技巧是提供充分的素材——你的文献笔记、分析结果、核心论点——而不是让LLM凭空生成。

**第三步：修订**。这是最重要的步骤。让LLM从读者视角审视初稿，检查论证链路、逻辑过渡、论据支撑，并根据反馈自行修改。

**第四步：润色**。让LLM优化语言表达，检查语法和术语一致性，但不要改变实质内容。

### 各章节的Prompt策略

**引言部分的Prompt策略**：

```
我正在撰写一篇关于[研究主题]的社科论文，目标期刊是[期刊名]。
我的研究问题是：[研究问题]。
我的核心贡献是：[贡献1]，[贡献2]，[贡献3]。
请帮我起草引言部分，要求：
1. 第一段用数据或现象引出研究问题的现实重要性
2. 第二段指出既有研究的不足
3. 第三段阐明本研究的定位和贡献
4. 第四段概述论文结构
语气：学术、客观、精确。不要使用"前所未有""开创性"等夸大表述。
```

**方法部分的Prompt策略**：

```
我的研究设计如下：
- 研究方法：[方法，如双重差分/案例比较/扎根理论]
- 数据来源：[数据描述]
- 样本：[样本量和选择标准]
- 分析策略：[具体步骤]
请帮我起草方法部分，要求：
1. 说明方法选择的理由（为什么这个方法适合回答我的研究问题）
2. 详细描述数据来源和样本
3. 逐步说明分析过程
4. 讨论方法的局限性
语气：客观、精确，使用学术术语但避免过度专业化。
```

**结果部分的Prompt策略**：

```
以下是我的实证结果：
[粘贴关键结果：回归表、统计量、主题分析结果等]
请帮我起草结果部分，要求：
1. 按逻辑顺序呈现结果（先主要发现后补充分析）
2. 先用文字描述趋势和模式，再报告具体统计量
3. 不要解释结果的理论含义（这属于讨论部分）
4. 正确使用统计术语（如"显著"对应p<0.05）
```

**讨论部分的Prompt策略**：

```
我的核心发现是：[发现1]，[发现2]，[发现3]。
相关理论包括：[理论1]和[理论2]。
以下是我的理论框架：[简述]
请帮我起草讨论部分，要求：
1. 第一段总结核心发现
2. 将发现与理论对话，说明对理论的推进或修正
3. 讨论实践启示
4. 诚实说明研究局限
5. 提出未来研究方向
注意：不要引入结果部分未呈现的新发现。
```

### 学术诚信边界

在使用LLM辅助写作时，必须明确三条边界线：

**红线（绝对禁止）**：让LLM编造数据、伪造引用、生成虚假统计结果。这是学术不端行为，无论是否使用AI都不可接受。

**黄线（需要谨慎）**：让LLM生成理论论证或学术贡献判断。LLM可以提供参考，但最终的学术判断必须由你自己做出。如果直接使用LLM生成的理论论述而不加验证和修改，可能导致论文逻辑不自洽或贡献被夸大。

**绿线（可以放心使用）**：让LLM辅助语言润色、格式调整、代码编写、文献整理。这些属于工具性辅助，不涉及学术判断的核心环节。

一个实用的自检方法：**论文中的每一个实质性论断，你都应该能向导师清晰解释其来源和逻辑。** 如果你无法解释某个论断为什么成立，说明你可能过度依赖了AI生成。

### LLM辅助的写作质量保障

使用LLM辅助写作后，必须建立质量保障流程：

1. **事实核查**：逐句检查LLM生成内容中的事实性陈述，确认数据、引用、统计结果的真实性
2. **逻辑审查**：检查论证链路是否完整，是否存在逻辑跳跃或循环论证
3. **引用验证**：LLM可能生成不存在的引用（幻觉），必须逐一验证每条引用的真实性
4. **术语检查**：确认专业术语的使用与你的学科惯例一致
5. **风格统一**：确保全文写作风格一致，避免不同段落因AI辅助程度不同而出现风格割裂

## 关键细节与易错点

- **易错：让LLM直接写完整章节**。LLM对长文本的连贯性控制较弱，容易在长段落中偏离主题。正确做法是分小节、分段落逐步生成，每段提供充分的上下文。
- **易错：不验证LLM生成的引用**。LLM最常见的幻觉之一是编造不存在的文献。必须将每条引用在Google Scholar或数据库中验证。
- **易错：忽视学科特定的写作惯例**。不同学科的论文在结构、语气、论证方式上有显著差异。给LLM的Prompt中应明确学科和期刊背景。
- **易错：AI生成文本的"过于完美"问题**。LLM生成的文本往往行文流畅但内容空洞，缺乏真正的学术深度。必须注入你自己的分析和判断。
- **易错：在修订环节完全信任LLM的反馈**。LLM可能建议删除你认为重要的论证，或添加不必要的铺垫。修订建议需要你逐一评估。

## 社科科研示例

场景：一位政治学博士生正在撰写关于"社交媒体对政治参与的影响"的论文，使用LLM辅助写作。

**大纲生成阶段**的对话：

```
用户：我正在写一篇关于社交媒体使用对政治参与影响的论文。
核心发现是：社交媒体的信息获取功能显著提升政治参与（β=0.23, p<0.01），
但社交互动功能的影响不显著。理论框架基于Dahl的多元主义和Putnam的社会资本理论。
目标期刊是《政治学研究》。请帮我设计论文大纲。

LLM：基于您的研究，建议以下大纲：
1. 引言：数字时代的政治参与困境
   1.1 研究问题与意义
   1.2 核心发现概述
   1.3 论文结构
2. 文献综述与理论框架
   2.1 政治参与的理论演进
   2.2 社交媒体与政治参与：既有研究
   2.3 理论框架：区分信息功能与互动功能
   2.4 研究假设
3. 研究方法
   3.1 数据与样本
   3.2 变量测量
   3.3 分析策略
   3.4 方法论证
4. 实证结果
   4.1 描述性统计
   4.2 主效应分析
   4.3 稳健性检验
5. 讨论
   5.1 理论贡献：信息功能与互动功能的分化效应
   5.2 与社会资本理论的对话
   5.3 实践启示
   5.4 局限与展望
6. 结论

用户：我需要在大纲中增加一个子节，专门讨论内生性问题及处理方式，
因为社交媒体使用和政治参与可能存在反向因果。
请调整第3节和第4节。

LLM：（调整后的大纲，在3.4增加"内生性处理策略"，
在4.3增加"内生性检验"）
```

**初稿起草阶段**——讨论部分的Prompt：

```
用户：请帮我起草讨论部分5.1的理论贡献段落。
核心论点：本研究区分了社交媒体的信息功能与互动功能，
发现只有信息功能促进政治参与，
这一发现对Putnam的社会资本理论提出了修正——
并非所有形式的社交互动都能转化为政治参与，
只有以公共信息为核心的网络互动才具有促进效应。
要求：与Putnam的理论直接对话，指出本发现对其理论的推进。
语气：学术但不过度自夸，约300字。

LLM：（生成讨论段落，用户在此基础上修改调整）
```

**质量保障阶段**的检查清单：

用户在完成初稿后，系统性地执行以下检查：
- 验证所有引用文献的真实性（在CNKI和Google Scholar中逐条确认）
- 核对所有统计结果与原始分析输出的一致性
- 检查全文术语统一性（如统一使用"政治参与"而非混用"政治介入"）
- 确保每个实质性论断都有明确的证据或引用支撑
- 检查讨论部分是否引入了结果部分未呈现的新发现
