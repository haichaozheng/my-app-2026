# Prompt Engineering方法论

> **引入时机**：W1 | **核心挑战**："如何与LLM有效交互？系统Prompt、多轮对话、Deep Research等方法如何用于科研？" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

在AI4S范式中，Prompt（提示词）是你与AI交互的核心接口。同样用GPT-4或Claude，有人能获得高质量的学术建议，有人只得到泛泛而谈的废话——差异不在工具，而在你如何提问。对于社科博士生而言，Prompt Engineering不是锦上添花的技巧，而是AI4S工具栈的基础设施——RAG的检索策略需要Prompt设计，Agent的行为需要系统Prompt约束，Skill的功能需要Prompt定义。

不理解Prompt Engineering，你会陷入一个困境：AI明明很强大，但你的使用效果却很差。你问"怎么写文献综述"，AI给你一篇高中水平的泛泛之谈；你问"帮我分析数据"，AI给你一段跑不通的通用代码。问题不在AI的能力，而在你的提问方式——模糊的问题只能得到模糊的回答。

掌握Prompt Engineering后，你可以：精准描述研究需求，获得方法论层面的专业建议；设计系统Prompt，让AI持续扮演你的研究助手角色；构建迭代式对话工作流，从初步想法逐步推进到可执行方案；用Deep Research模式让AI自主完成文献检索和整合。这些能力是将AI从"聊天工具"升级为"研究伙伴"的关键。

## 这个知识点的核心内容

### Prompt核心原则：清晰性、上下文、约束

**清晰性（Clarity）**：指令明确、具体、无歧义。社科领域尤其需要精确的术语使用。

- 差的prompt："帮我分析社会不平等"
- 好的prompt："基于中国综合社会调查（CGSS）2021年数据，分析教育获得对收入不平等的影响。使用基尼系数分解方法，区分组内和组间不平等，控制户籍、性别、地区变量。"

**上下文（Context）**：提供研究背景、学科范式、数据特征等完整信息。

- 差的prompt："这个回归结果怎么解释？"
- 好的prompt："我正在用固定效应面板模型研究数字经济对地级市就业率的影响，数据是2015-2023年283个地级市的面板数据。回归结果显示数字经济指数的系数为0.023（p<0.01），请结合劳动力经济学理论解释这个结果的经济含义，并讨论可能的遗漏变量偏误。"

**约束（Constraints）**：限定输出范围、深度、格式、方法论偏好。

```
请从制度经济学视角分析中国土地制度改革的文献，
要求：
1. 聚焦2000年以来的研究，不讨论改革开放初期的文献
2. 区分"产权理论"和"治理理论"两条主线
3. 每条主线列出3-5篇代表性文献（含作者、年份、核心论点）
4. 用学术语言，避免科普风格
5. 不超过800字
```

### 科研场景的Prompt模式

**角色扮演（Role Prompting）**——让AI以特定学科专家身份回答

```
你是一位专注于中国政治经济学的资深学者，熟悉"联邦主义的中国模式"辩论
（即Montinola-Qian-Weingast联邦主义假说 vs. 许成钢的"分权式威权体制"框架）。
请从这两个理论视角，分别解释中国地方政府的经济增长激励，
指出两个理论的核心分歧点，并评价各自的解释力和局限。
```

关键：角色扮演改变的是AI输出的视角和深度，不是AI的能力边界。AI"扮演经济学家"不等于它真的具备经济学家的学术判断力。

**分步指导（Chain-of-Thought, CoT）**——要求AI按步骤推理

```
请按以下步骤分析我的研究设计：
1. 首先陈述我的研究问题和核心假设
2. 识别我使用的因果识别策略（如DID、RD、IV）
3. 检查识别策略的核心假设是否满足
4. 列出可能的威胁识别的替代解释
5. 建议稳健性检验方案
6. 评价整体设计的可行性，给出改进建议

我的研究设计如下：[粘贴研究设计]
```

**结构化输出（Structured Output）**——指定输出格式

```
对以下5篇文献生成结构化摘要，每篇包含：
| 字段 | 内容 |
|------|------|
| 作者/年份 | |
| 研究问题 | 一句话 |
| 理论框架 | |
| 方法 | |
| 核心发现 | |
| 研究局限 | |
| 与我研究的关联 | 一句话 |

文献列表：
1. Zhou et al. (2023) Digital Economy and Employment...
2. ...
```

### Deep Research方法论

Deep Research是指让AI自主进行多轮检索、整合、分析的研究模式。与传统单轮问答不同，Deep Research让AI像研究员一样工作：检索→阅读→分析→再检索→整合→输出。

**Deep Research的适用场景**：
- 文献综述的初步框架搭建
- 某个研究领域的全景扫描
- 跨学科概念的关联发现
- 研究方法论的对比分析

**Deep Research的Prompt设计**：

```
请对"数字不平等"领域进行深度研究，要求：

研究范围：
- 涵盖社会学、传播学、信息科学三个学科
- 时间范围：2015年至今
- 聚焦但不限于中国情境

请执行以下研究步骤：
1. 检索"数字不平等"的核心概念定义和理论演化
2. 识别该领域的主要研究范式和代表性学者
3. 梳理三条主要研究线索：接入不平等→使用不平等→结果不平等
4. 总结当前研究的前沿争论和未解决问题
5. 建议可能的研究切入点

输出格式：结构化报告，每部分标注信息来源
```

**Deep Research的局限与应对**：
- AI可能引用不存在的文献→必须验证每条引用
- AI可能偏向英文文献→明确要求包含中文学术成果
- AI可能遗漏最新研究→手动补充近1-2年的文献

### 系统Prompt设计

系统Prompt（System Prompt）是预置的、持久的指令，定义AI在后续对话中的行为规范。在AI4S工具栈中，系统Prompt用于定制个性化的研究助手。

```python
# 示例：为社科研究助手设计系统Prompt
SYSTEM_PROMPT = """你是一位专业的社科研究助手，服务于一位中国社会学博士生。

## 你的角色定位
- 你不是替代研究者做判断，而是辅助研究者做更好的判断
- 每次建议都需附带方法论依据，不要只给结论不给理由
- 当你不确定时，明确表达不确定性，而非编造答案

## 方法论偏好
- 社会学研究传统：注重因果推断而非仅相关分析
- 重视研究设计（识别策略）而非仅统计技术
- 定量研究需报告效应量和置信区间，不仅报告p值
- 定性研究需关注反例和竞争性解释

## 输出规范
- 使用学术语言，但避免不必要的术语堆砌
- 区分"已有定论的共识"和"正在争论的问题"
- 引用文献时标注（作者，年份），不要编造引用
- 代码示例使用Python（优先）或R，Stata仅在明确要求时使用

## 禁止行为
- 不要编造数据、统计结果或文献引用
- 不要直接回答"这个假设是否成立"，而是提供验证思路
- 不要忽略方法论反思，即使技术上可行也要讨论伦理和方法论适当性
"""
```

系统Prompt的关键设计原则：
- **角色边界清晰**：明确AI能做什么、不能做什么
- **方法论约束**：嵌入你所在学科的方法论规范
- **输出规范**：统一语言风格和引用格式
- **安全边界**：禁止编造、禁止替代研究者做核心判断

### 迭代式Prompt工作流

科研场景中，一次Prompt几乎不可能获得完美结果。需要设计迭代式工作流：

```
[第1轮：框架生成]
"请帮我梳理'数字鸿沟与教育公平'领域的文献脉络，
 给出一个初步的综述框架（3-5个主要论点及支撑文献）"

[第2轮：深化补充]
"框架的第二点'数字鸿沟的代际传递'，请补充：
1. 这一论点的理论依据（文化再生产理论？）
2. 3-5篇核心实证研究
3. 该论点的反方观点"

[第3轮：批判检验]
"请对上述综述框架提出批评：
1. 是否有重要文献被遗漏？
2. 各论点之间的逻辑关系是否严密？
3. 是否存在选择性引用的倾向？"

[第4轮：整合输出]
"综合以上讨论，请输出一份1500字的文献综述初稿，
要求：按主题组织（非时间线），每个论点至少引用2篇文献，
结尾指出研究空白并提出我的可能贡献方向。"
```

### 社科领域的Prompt技巧

**指定研究范式**：

```
从批判实在论（Critical Realism）的立场出发，
分析定量方法在研究"制度变迁"时的局限，
并提出混合方法设计的改进方案。
```

**要求方法论引用**：

```
在讨论因果推断策略时，请引用方法论文献
（如Angrist & Pischke 2009; Imbens & Rubin 2015;
Morgan & Winship 2015），
不要只引用实证应用文献。
```

**设定理论深度**：

```
我正在撰写博士论文的理论框架章节，
已有社会学理论基础（熟悉布迪厄、吉登斯、格兰诺维特）。
请用我能理解的学术深度讨论"数字资本"的理论定位——
它是人力资本的子类？还是独立的文化资本形态？
请引用相关理论辩论文献。
```

## 关键细节与易错点

- **易错：把Prompt当搜索引擎查询**。输入"社会资本理论"只能得到百科式回答。需要提供研究语境、理论立场、具体问题才能得到有价值的学术建议
- **易错：不验证AI的文献引用**。AI编造引用的倾向在社科领域尤其危险——它可能"发明"一篇看起来很合理的论文（作者真实、期刊真实、年份真实，但文章不存在）。每条引用必须在Google Scholar或CNKI中验证
- **易错：一次Prompt期望完美结果**。好的学术Prompt工作流至少需要3-5轮迭代：框架→深化→质疑→修正→整合
- **易错：忽略AI的理论立场倾向**。AI训练数据中主流经济学/社会学观点占比更高，可能在无形中偏向主流范式。当你做批判性研究时，需要主动要求AI考虑反主流视角
- **易错：系统Prompt一次写完不迭代**。系统Prompt需要根据使用反馈持续优化。建议每周回顾AI的输出，发现系统性偏差后修改系统Prompt

## 社科科研示例

**场景**：一位传播学博士生研究"算法推荐与信息茧房"，需要用Prompt Engineering辅助文献综述写作。

**第1轮：构建系统Prompt**

```
你是一位传播学领域的文献综述助手。

角色：帮助研究者梳理"算法推荐与信息茧房"领域的文献
方法论偏好：
- 重视操作化定义：信息茧房需要可测量的定义，而非仅是隐喻
- 区分"回音室"（同质化社交网络）和"信息茧房"（算法过滤）两个概念
- 关注实证研究的因果识别策略（是选择效应还是因果效应？）
- 平衡乐观派（算法增加信息多样性）和悲观派（算法强化偏见）的文献

输出要求：
- 每个论点至少引用一篇具体文献（作者，年份，期刊）
- 区分"理论论证"和"实证发现"
- 标注你的置信度：哪些论点有充分证据，哪些仍在争论
```

**第2轮：领域扫描**

```
请对"算法推荐与信息茧房"研究进行全景扫描：
1. 该领域的核心概念演化（从Sunstein 2001的"信息茧房"到当代算法研究）
2. 三大研究范式：媒介效果研究、计算传播学、政治传播学
3. 每个范式的2-3篇代表性研究
4. 当前最激烈的学术争论
5. 研究空白
```

**第3轮：深化特定线索**

```
关于"算法推荐是否导致信息茧房"的争论：
1. 支持方的核心证据和因果识别策略
2. 反对方的反驳逻辑和替代解释
3. "选择性接触"（selective exposure）和"算法过滤"各自的作用如何分解？
4. 请建议一个研究设计来推进这个争论
```

**第4轮：生成综述框架**

```
综合以上讨论，请生成一份文献综述大纲：
- 按主题组织（非时间线）
- 包含4个主要部分
- 每个部分列出核心论点、支撑文献、争议点
- 结尾明确指出我的研究可以切入的空白
我的研究定位：用实验方法检验算法推荐的因果效应
```
