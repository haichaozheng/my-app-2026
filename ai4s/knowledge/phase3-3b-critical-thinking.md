# 批判性思维与判断（科研场景）

> **引入时机**：W4 | **核心挑战**："我怎么知道我的研究设计是对的？我该不该信任AI给出的gap和方法建议？" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

研究设计阶段（W4）是整个科研流程中判断力需求最密集的环节：你从AI那里得到了gap分析和方法推荐，你需要判断这些输出是否可靠；你选择了因果推断方法和理论框架，你需要审视自己是否被偏误带偏；你要定稿研究方案，你需要预见可能的失败。

社科科研中，判断失误的代价是数月甚至数年的无效劳动。一个基于AI幻觉文献的选题、一个选择了错误识别策略的研究设计、一个忽略替代解释的因果推断——这些错误在执行阶段很难修正。批判性思维在研究设计阶段的投入，是对后续数周乃至数月科研投入的保险。

## 这个知识点的核心内容

### 一、自我审视：识别认知偏误

#### 偏误自检清单

在做关键判断时，问自己以下问题：

| 偏误类型 | 自检问题 | 科研场景示例 |
|---|---|---|
| 确认偏误 | "我是在寻找证据支持我的选题，还是在寻找推翻它的证据？" | 你想研究"数字金融对农村收入的因果效应"，于是只检索支持性文献，忽略指出内生性问题的研究 |
| 锚定效应 | "我的方法选择是否被最初看到的某篇论文过度影响？" | 你读的第一篇DID论文做得很好，就认为DID适合你的问题，但你的场景可能更适合RDD |
| 幸存者偏差 | "我分析的成功案例是否只代表了一部分现实？" | 你只研究成功转型的企业，忽略转型失败的企业，得出"转型策略有效"的结论 |
| 相关≠因果 | "我是否把相关性当成了因果机制？" | 发现制度质量与经济增长相关，就断言"制度导致增长"，但可能存在反向因果或混淆变量 |
| 过度自信 | "我对这个研究设计的信心是否有充分的方法论支撑？" | 在没有检验平行趋势假设的情况下就确信DID结果可靠 |
| 沉没成本 | "我是否因为已经投入了时间而拒绝调整研究方向？" | 已经花了两周构建的工具链不适合当前方法，但不愿意换方向 |

#### 偏误对抗策略

- **魔鬼代言人**：在定稿研究设计后，强制自己写出"如果我的研究设计是错的，最可能的原因是什么"
- **预验尸（Pre-mortem）**：假设现在是半年后，你的研究被证明结论不可靠，逆推最可能的失败原因
- **寻找反例**：主动搜索与你的假设矛盾的理论或实证发现，而非只找支持证据

### 二、判断AI输出：何时信任、何时质疑

你全程深度使用AI——Deep Research做gap分析、Agent推荐研究设计、LLM辅助方法选择和综述生成。但AI输出不等于可靠知识。

#### AI输出判断三步法

```
Step 1: 这类问题AI擅长吗？
├── 擅长：文献整理与摘要、代码生成、格式转换、已有方法论的归纳
├── 一般：研究空白判断、方法匹配建议、理论框架推荐
└── 不擅长：判断因果识别策略的适用性、评估理论框架的深度适配度、
            预判研究可行性中的隐性约束（如数据可得性、制度背景差异）

Step 2: 输出有可验证的依据吗？
├── 有具体引用/代码/逻辑推导 → 可以验证
├── 只有断言没有依据 → 需要独立核实
└── 依据看起来合理但无法验证 → 标记为"待验证"，不作为设计决策依据

Step 3: 验证成本与决策后果是否匹配？
├── 高后果决策（因果识别策略、核心假设）→ 必须独立验证
├── 中后果决策（变量测量方式、数据来源）→ 抽样验证
└── 低后果决策（代码格式、文献引用格式）→ 快速扫视即可
```

#### 常见AI输出陷阱（社科科研场景）

- **幻觉文献**：AI编造不存在的论文、错误引用作者和年份、虚构期刊名称
- **过时信息**：AI的训练数据截止后发表的重要研究它不知道
- **表面合理但逻辑错误**：推荐了DID但未检验平行趋势、建议了工具变量但未讨论外生性
- **过度泛化**：基于一般性社科知识给出建议，但缺乏对特定学科制度背景的理解
- **混淆方法论层次**：把描述性问题误当因果问题推荐方法、把探索性发现当作解释性结论

#### 验证AI输出的实用方法

- **文献幻觉检测**：将AI给出的每条引用在Google Scholar/CNKI中检索确认存在性
- **方法适用性验证**：将AI推荐的方法与你阅读的权威方法论文献对照，检查前提假设是否满足
- **逻辑一致性检验**：让另一个LLM（或换一个Prompt）审查同一输出，看是否能发现逻辑漏洞
- **边界条件追问**：追问AI"这个方法在什么条件下会失效"，如果AI无法给出合理回答，说明推荐可能流于表面

### 三、结构化决策框架

面对不确定情境下的研究设计决策，仅靠直觉容易偏误。以下是三个轻量级决策工具：

#### 1. 事前验尸（Pre-mortem）

在定稿研究设计之前，假设研究已经失败，逆推最可能的失败原因：

```
场景：你决定用DID研究某政策效果

Pre-mortem：
"假设半年后，DID结果被证明不可靠。最可能的失败原因是："
1. 平行趋势假设不成立——处理组和控制组在政策前已有分化趋势
2. 政策内生性——政策实施本身与地区经济状况相关，存在混淆因素
3. 处理效应异质性——平均处理效应掩盖了重要的异质性，结论不具解释力

→ 基于Pre-mortem调整：先检验平行趋势，增加控制变量缓解内生性，
  预设计异质性分析方案
```

#### 2. 费米估算（Fermi Estimation）

对关键数字做数量级检验，快速判断可行性：

```
场景：你计划用问卷数据做研究，AI建议"收集5000份问卷"

费米估算：
- 目标人群规模约？
- 问卷回收率通常10-30%
- 有效问卷比例约70-80%
- 需要的最低样本量（统计功效分析）= ?
- 5000份需要发放多少？→ 5000/0.2/0.75 ≈ 33000份原始发放
→ 判断：如果目标人群不足33000，这个方案不可行，需要调整样本量目标或方法
```

#### 3. 贝叶斯思维

根据新证据更新你的研究判断：

```
初始判断：你认为某政策对收入有正向因果效应（先验 P(有效)=70%）

新证据1：已有3篇高质量论文发现正向效应 → P(有效)上升
新证据2：但最新1篇论文指出严重的内生性问题 → P(有效)下降
新证据3：你的数据覆盖了政策实施前后5年 → 支持DID可行性，P(有效)上升

最终判断：综合证据后P(有效)≈60%，结论从"大概率有效"修正为"有一定证据但需严格识别策略"
```

核心原则：**让证据改变你的观点，而不是让观点筛选证据**。

### 四、判断力在科研各阶段的锚点

| 科研阶段 | 判断力练习重点 | 具体动作 |
|---|---|---|
| 文献综述 | 判断AI综述中的文献是否真实存在 | 逐条验证关键引用 |
| 研究选题 | 判断gap是否真实、选题是否可行 | 对gap做Pre-mortem |
| 研究设计 | 判断方法选择是否适配研究问题 | 检验方法前提假设是否满足 |
| 方案实施 | 判断AI辅助的分析结果是否可靠 | 对关键结果做稳健性检验 |
| 论文写作 | 判断论证链路是否完整 | 检查每一步推理是否有证据支撑 |

## 关键细节与易错点

- **误区：批判性思维就是"怀疑一切"**。目标是提高判断可靠性，不是否定所有结论。经过检验的结论应该被接受
- **误区：每个决策都要走完整判断流程**。低后果决策用直觉即可，高后果决策才需要结构化判断。过度分析本身也是一种偏误（分析瘫痪）
- **易错：只批判别人的研究，不审视自己的**。批判性思维首先是自我审视
- **易错：把"AI说了"当证据**。AI输出是待检验信息，不是证据本身
- **易错：Pre-mortem变成自我否定**。Pre-mortem是识别风险并提前应对，不是让自己不敢推进研究
- **易错：偏误自检变成形式主义**。自检的目的是真正发现思维漏洞，而非走个流程打勾

## 社科科研示例

你在W3用Deep Research做gap analysis，AI告诉你"数字金融对农村居民消费升级的影响机制研究是重要gap"。

**用判断三步法审视**：

1. AI擅长这类问题吗？→ 擅长整理已有文献和发现表面空白，不擅长判断空白是否真实有价值（这需要领域直觉）
2. 输出有可验证依据吗？→ AI列出了5篇"相关文献"，需要逐条验证是否存在
3. 决策后果如何？→ 基于此定选题属于高后果决策，需要独立验证

**验证结果**：3篇文献真实存在但方法论不同、1篇与你的研究问题不直接相关、1篇无法检索到（幻觉）。gap仍然存在，但不是AI描述的那个gap。

**用偏误自检**：
- 我是否因为自己也想做这个方向而更容易接受AI的gap判断？（确认偏误）
- "重要gap"是否意味着"我能做"？（价值≠可行性，需评估数据可得性和方法适用性）

**用Pre-mortem**：
"如果我选了这个题目但半年后做不出来，最可能的原因是：数据无法识别因果机制、混淆变量无法控制、政策外生性假设不成立"

**调整后的研究设计**：保留该方向但增加识别策略预检验，同时准备一个备选的描述性研究方案。
