# 社科方法论意识（贯穿全程）

> **引入时机**：W1 | **核心挑战**："AI让'做出来'变容易，但'做对'仍需人类的方法论自觉" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

这是AI4S课程最核心的贯穿性知识。所有技术工具——Prompt、RAG、Agent、Skill——都可以让你更快地"做出来"：更快地综述文献、更快地选题、更快地分析数据、更快地写论文。但"做出来"和"做对"之间有一道鸿沟，而跨越这道鸿沟的唯一桥梁就是方法论自觉。

方法论自觉的核心内涵是：**知道为什么要用这个方法、知道这个方法的局限、知道何时应该质疑结果**。这不是抽象的方法论哲学，而是非常具体的实践能力。在AI4S中，这三层意识的重要性被极大放大——因为AI让"做出来"变得前所未有的容易，但"做对"的难度丝毫没有降低。

考虑一个具体的场景：你让Skill自动执行双重差分回归，Skill在3秒内返回了漂亮的结果表，显示处理效应显著为正。没有方法论自觉的研究者可能直接把这个结果写入论文。但方法论自觉会驱使你追问：DID的平行趋势假设满足了吗？处理组和对照组是否真的可比？有没有遗漏变量同时影响处理分配和结果变量？结果对聚类方式敏感吗？——这些问题不是Skill能自动回答的，它们需要研究者的方法论判断。

更深层的问题在于：AI不仅让错误变得更快，还让错误变得更隐蔽。一个Prompt的设计偏差可能导致文献综述系统性遗漏某个理论传统，一个Agent的方法论盲区可能导致研究设计存在未识别的效度威胁，一个Skill的默认参数可能导致回归结果对关键假设敏感。这些错误不是"代码bug"——代码逻辑可能完全正确——而是"方法论错误"，只有具备方法论自觉的研究者才能发现和修正。

## 这个知识点的核心内容

### 方法论自觉的核心内涵

方法论自觉包含三个层次：

**第一层：知道为什么要用这个方法**

这不是"知道这个方法是什么"（那是技术知识），而是"知道为什么在我的研究中用这个方法而不是其他方法"（那是方法论知识）。

以因果推断为例：
- 技术知识：DID是比较处理组和对照组在政策前后的差异
- 方法论知识：DID适用于"外生政策冲击导致处理分配"的场景；如果处理分配是内生的（如地方政府选择实施政策的时机），DID的识别假设就不成立，需要寻找替代策略（如IV、RD等）

在AI4S中，这个层次的方法论自觉体现为：**不让AI替你选择方法**。AI可以列出可选方法和各自的适用条件，但"我的研究场景满足哪个方法的假设"这个判断必须由你做出。

**第二层：知道这个方法的局限**

任何方法都有其局限和假设。方法论自觉要求你不仅能使用方法，还能清晰说明方法的局限，并在论文中诚实讨论。

常见的社科方法局限：
- 问卷研究：社会期望偏差、回忆偏差、非响应偏差
- 实验研究：外部效度问题、伦理约束
- 案例研究：可推广性问题、案例选择的代表性
- DID：平行趋势假设、交错处理效应的异质性
- IV：排他性约束、弱工具变量
- RD：带宽选择的敏感性、操控性检验

在AI4S中，这个层次的方法论自觉体现为：**主动追问AI输出结果的局限**。当Skill返回分析结果时，不是直接接受，而是追问"这个结果在什么条件下可能不成立"。

**第三层：知道何时应该质疑结果**

这是最高层次的方法论自觉——当结果看起来"太好"或"太干净"时，方法论直觉应该触发警觉。

触发警觉的信号：
- 效应量异常大，远超同类研究
- 结果对所有模型设定都稳健（这反而可疑——真正稳健的结果通常在不同设定下有轻微波动）
- 关键假设恰好都满足，没有任何问题
- 数据完美地支持了你的假设，没有任何意外发现

在AI4S中，这个层次的方法论自觉体现为：**对AI辅助产出的"完美"结果保持怀疑**。AI倾向于生成符合预期的结果——如果你的Prompt暗示了期望的方向，AI可能在不知不觉中选择了支持这个方向的路径。

### 在AI4S中的特殊意义

AI4S中方法论自觉的特殊意义源于一个核心悖论：**AI让"做出来"变容易，但"做对"仍需人类判断**。

这个悖论在三个维度上展开：

**维度1：速度与深度的张力**

AI加速了科研的每个环节，但方法论判断需要时间——你需要停下来思考"这样做对吗？"而不是快速推进到下一步。速度和深度之间存在内在张力。

应对策略：在关键节点设置"方法论检查点"——选题判断、设计论证、结果解读、贡献提炼——在这些节点上，不管AI的输出多么流畅，都要暂停、质疑、验证。

**维度2：自动化与方法论的张力**

自动化（Agent、Skill）提高了效率，但也可能让研究者与具体操作脱节。当你不再手动执行每一步分析时，你可能不再理解每一步的含义——这削弱了方法论判断的基础。

应对策略：在使用自动化工具前，先手动执行一次完整流程，理解每一步的逻辑。自动化只有在理解的基础上才有价值。

**维度3：工具与方法论的张力**

工具往往自带方法论偏好——Python的statsmodels默认报告F统计量，Stata的reg默认报告t统计量；sklearn的模型默认不做因果推断，而只做预测。不了解这些偏好，你可能在不自觉中接受了工具的方法论选择。

应对策略：了解你使用的每个工具的方法论假设和默认设置，确保它们与你的研究方法论一致。如果不一致，主动调整而非被动接受。

### 各科研阶段的方法论意识锚点

在每个科研阶段，方法论意识应锚定在不同的焦点上：

**文献综述阶段（W1-W2）**

方法论锚点：**覆盖度与代表性**

- 我的文献检索策略是否覆盖了所有重要的理论传统？
- 我是否因为检索词的偏差而系统性地遗漏了某些视角？
- 我选择文献的标准是否合理（而非只选择支持我观点的文献）？

AI4S中的风险：RAG的检索结果受查询语句影响——如果查询语句有偏差，检索结果就有偏差。需要用多种查询策略交叉验证覆盖度。

**选题阶段（W3）**

方法论锚点：**问题的重要性与可行性**

- 这个研究问题在学术上重要吗（对理论有实质性推进）？
- 这个研究问题在方法上可行吗（数据可获取、方法可实施）？
- 我的贡献陈述是否诚实（不夸大、不回避局限）？

AI4S中的风险：LLM倾向于生成"看起来重要"的研究问题，但重要性需要学术共同体的认可——不能仅凭AI的判断。

**研究设计阶段（W4-W5）**

方法论锚点：**内部效度与外部效度**

- 我的研究设计能否有效识别因果效应（内部效度）？
- 我的发现能推广到什么范围（外部效度）？
- 我是否在研究设计和数据分析中制造了"研究者自由度"（p-hacking风险）？

AI4S中的风险：Agent可能在不知不觉中尝试多种方法选择"最显著"的结果——这是p-hacking的AI版本。必须预先注册分析计划，避免事后选择。

**数据分析阶段（W6-W7）**

方法论锚点：**结果的可信度与稳健性**

- 我的结果对模型设定敏感吗？
- 我的识别策略的核心假设是否成立？
- 我是否诚实地报告了所有分析，包括"不理想"的结果？

AI4S中的风险：Skill可能默认执行标准分析流程而跳过关键的前提检验（如DID的平行趋势检验）。必须确保Skill的流程包含所有必要的前提检验。

**论文写作阶段（W8）**

方法论锚点：**论证的完整性与诚实性**

- 我的论证链路是否完整（问题-理论-假设-方法-结果-结论）？
- 我是否诚实讨论了研究的局限性？
- 我的贡献陈述是否与证据匹配（不过度推断）？

AI4S中的风险：LLM辅助的写作可能在不自觉中"美化"贡献——将"初步证据"写成"强有力地支持"，将"相关关系"写成"因果效应"。必须逐句审查贡献陈述的准确性。

### 培养方法论自觉的实践策略

**策略1：方法论审查清单**

为每个科研环节建立方法论审查清单，在产出前逐项检查：

```markdown
# 数据分析方法论审查清单

- [ ] 识别策略的核心假设是否已检验？
- [ ] 稳健性检验是否覆盖了关键替代解释？
- [ ] 结果对模型设定是否敏感？
- [ ] 效应量是否在合理范围内（与同类研究比较）？
- [ ] 是否诚实地报告了所有分析（包括不显著的结果）？
- [ ] 聚类标准误的选择是否有依据？
- [ ] 样本选择偏差是否已讨论？
```

**策略2："魔鬼代言人"Prompt**

在关键节点，让LLM扮演"严格的审稿人"，质疑你的方法选择：

```
你是一位严格的社会科学期刊审稿人。
请对以下研究设计提出最严厉的批评：
[粘贴研究设计]

重点质疑：
1. 识别策略的有效性
2. 内部效度威胁
3. 外部效度局限
4. 潜在的替代解释
5. 数据和分析的选择性问题

不要客气，尽可能严格。
```

**策略3：方法论日志**

记录每次方法论决策及其理由：

```markdown
# 方法论决策日志

## 2024-XX-XX | 选择DID而非RD

决策：使用双重差分法而非断点回归法
理由：政策实施在省域层面，没有明确的断点，
但政策实施前后有清晰的时间分割，
处理组和对照组在政策前有可比较的趋势
风险：平行趋势假设可能在政策实施前3年内成立，
但更长期的趋势不可观察
缓解：进行事件研究检验政策前各期趋势差异
```

**策略4：交叉验证习惯**

任何重要结果都用两种不同方式验证：
- 回归结果：用Python和Stata分别估计
- 文献覆盖度：用RAG检索和数据库手动检索交叉验证
- 理论推导：用自己的推理和LLM的推理交叉验证

## 关键细节与易错点

- **易错：方法论意识停留在"知道"层面**。知道DID需要平行趋势假设不等于在分析中实际检验了它。方法论自觉必须转化为具体的行动——检验、验证、质疑。
- **易错：把方法论意识等同于"方法论保守主义"**。方法论自觉不是拒绝新方法，而是在使用新方法时更加审慎。创新性和严谨性不是对立的——最优秀的研究往往是方法论创新与方法论严谨的结合。
- **易错：只在"出问题"时才方法论反思**。方法论自觉应该是常态化的，而不是"结果不显著"时的补救。在研究设计的每一步都应该有方法论论证。
- **易错：过度依赖AI的方法论判断**。LLM可以提供方法论建议，但最终的方法论判断必须由研究者做出。LLM可能不了解你研究领域的方法论共识，也可能给出看似合理但实际有问题的建议。
- **易错：忽视学科差异的方法论要求**。经济学强调因果推断和识别策略，社会学强调理论对话和概念操作化，政治学强调机制解释和过程追踪——方法论自觉必须锚定在你的学科传统中。

## 社科科研示例

场景：一位经济学博士生在数据分析阶段展示方法论自觉的具体实践。

**情境**：Skill执行DID回归后返回显著为正的处理效应。

**无方法论自觉的响应**：

"太好了，结果显著为正，说明产业政策促进了企业创新！让我把这个结果写入论文。"

**有方法论自觉的响应**：

"结果显著为正，但让我先检查几个关键问题：

第一，平行趋势假设是否成立？让我查看事件研究图——如果政策前的系数不接近0，说明处理组和对照组本来就有不同的趋势，DID的识别假设不成立。

第二，效应量是否合理？0.23的对数点效应意味着补贴使创新产出增加约26%——这个效应量比既有文献大了两倍，需要警惕。

第三，有没有遗漏变量同时影响补贴分配和创新产出？地方政府的补贴决策可能考虑了企业的创新潜力，这就导致处理分配是内生的。

第四，结果对聚类方式敏感吗？按省份聚类和按企业聚类的标准误差异大吗？

让我逐一检查这些问题。"

**检查后的发现**：

"事件研究显示政策前2期的系数不显著，但前3期开始有差异——平行趋势假设在短窗口内勉强成立，但长期趋势不完全平行。效应量确实偏大，可能是因为样本中包含了政策实施当年就获得补贴的企业（处理定义偏宽）。按省份聚类的标准误比按企业聚类的大40%，显著性消失——说明同一省份内的企业存在未观测的相关性。

修改策略：1) 缩短事件窗口到政策前后各2年；2) 严格定义处理组为政策实施次年才获得补贴的企业；3) 报告按省份聚类的结果作为基准，按企业聚类的结果作为对照；4) 在论文中诚实讨论平行趋势的局限性和结果对聚类方式的敏感性。"

**论文中的呈现**：

"表3报告了基准DID估计结果。列(1)按省份聚类标准误，处理效应为0.23（p=0.12），在5%水平上不显著；列(2)按企业聚类标准误，处理效应为0.23（p=0.03），在5%水平上显著。这一差异提示同一省份内存在未观测的相关性，按企业聚类可能低估标准误。事件研究检验（图2）显示政策前2期系数不显著，但前3期出现微弱趋势差异（beta=-0.05, p=0.18），表明平行趋势假设在短窗口内可接受但需谨慎解读。综合而言，本文发现补贴对创新产出的正向效应在统计上较为脆弱，后续分析需在更严格的识别条件下重新评估。"
