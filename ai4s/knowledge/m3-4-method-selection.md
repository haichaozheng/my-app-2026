# 方法选择逻辑

> **引入时机**：W5 | **核心挑战**："定量、定性、混合方法——如何根据研究问题选择合适的方法？" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

方法选择不是"我会什么就用什么"，而是"研究问题需要什么就用什么"。然而现实中，很多博士生的方法选择受限于三种惯性：方法路径依赖（导师用什么我就用什么）、方法从众效应（顶刊流行什么我就追什么）、方法舒适区偏好（我擅长什么就用什么）。这三种惯性都可能导致方法与研究问题之间的错配。

W4是方法选择的关键决策点。在此之后你将进入方案实施阶段（W5-W7），方法选择一旦确定将很难回头。一个正确的方法选择可以让你的研究问题得到最有效的回答，一个错误的选择则意味着数周的低效劳动。

AI工具可以辅助方法匹配，但核心判断仍需你自己做出。特别是，LLM倾向于推荐"主流方法"而非"最适合的方法"——你需要掌握方法选择的基本逻辑，才能有效评估和修正AI的推荐。

## 这个知识点的核心内容

### 一、方法选择的核心原则

**研究问题驱动方法选择，而非反过来。**

```
正确逻辑：
研究问题 → 需要回答什么类型的问题 → 什么方法能回答这类问题 → 选择方法

错误逻辑：
我会DID → 找一个能用DID的研究问题 → 硬套方法
我看到顶刊都用RDD → 我也要用RDD → 强行构造断点
```

核心判断标准：

| 判断维度 | 问题 |
|---|---|
| 问题类型 | 描述性、解释性、探索性？ |
| 因果层级 | 关联、因果机制、因果效应？ |
| 理论成熟度 | 已有理论可演绎，还是需要归纳建构？ |
| 数据性质 | 大样本/小样本？截面/面板？数值/文本？ |
| 情境复杂度 | 机制是否情境依赖？是否需要深度理解情境？ |

### 二、定量/定性/混合方法的适用场景

#### 定量方法

```
适用场景：
  - 研究问题是"X对Y的效应有多大"（效应估计）
  - 理论框架成熟，可以推导可检验假设
  - 大样本数据可得
  - 变量可以量化测量
  - 目标是推广到更广的总体

典型方法：
  - 回归分析（OLS/面板/非线性）
  - 因果推断（DID/RDD/IV/PSM）
  - 结构方程模型（SEM）
  - 社会网络分析

典型问题：
  - "贸易开放对工资不平等的因果效应是多少？"
  - "企业数字化水平每提高1单位，生产率提高多少？"
```

#### 定性方法

```
适用场景：
  - 研究问题是"为什么"和"如何"（机制理解）
  - 理论不成熟，需要归纳建构
  - 现象复杂，需要深度理解情境
  - 研究对象数量少但信息密度高
  - 目标是理论建构而非统计推广

典型方法：
  - 案例研究（单案例/多案例）
  - 深度访谈
  - 参与观察
  - 扎根理论
  - 过程追踪

典型问题：
  - "地方政府如何在经济增长与环保间权衡？决策过程是怎样的？"
  - "企业数字化转型的微观机制是什么？"
```

#### 混合方法

```
适用场景：
  - 研究问题同时涉及"效应多大"和"为什么"
  - 需要定量估计效应+定性理解机制
  - 单一方法无法充分回答研究问题
  - 定量和定性可以相互补充或验证

典型设计：
  - 顺序解释型：定量→定性（先发现效应，再解释机制）
  - 顺序探索型：定性→定量（先探索机制，再检验普适性）
  - 并行三角验证型：定量+定性同时进行，相互验证

典型问题：
  - "数字金融对农村消费的影响有多大？影响路径是什么？"
```

### 三、从研究问题到方法的映射逻辑

```
你的研究问题是什么类型？
│
├── "是什么"（描述性）
│   ├── 现象的整体图景 → 描述统计 + 可视化
│   ├── 现象的趋势变化 → 时间序列分析
│   └── 现象的群体差异 → 分组比较 + 统计检验
│
├── "为什么/如何"（解释性/探索性）
│   ├── 已有理论，需要检验 → 定量假设检验
│   │   ├── 纯关联关系 → 回归分析
│   │   ├── 因果效应 → 因果推断方法
│   │   └── 因果机制 → 中介效应分析 / 过程追踪
│   ├── 无成熟理论，需要建构 → 定性理论建构
│   │   ├── 单一深度案例 → 单案例研究
│   │   └── 多案例比较 → 多案例研究
│   └── 两者兼顾 → 混合方法
│
└── "应该怎样"（规范性）
    ├── 基于因果理解 → 政策模拟 / 情景分析
    └── 基于价值判断 → 规范分析 + 价值论证
```

### 四、常见的方法选择错误

#### 错误1：方法先行，问题后置

```
错误模式：
"我学会了DID，所以我要找一个能用DID的题目"
→ 结果：研究问题不自然，DID假设不满足，强行构造实验场景

正确做法：
"我的研究问题是X对Y的因果效应，DID可能是合适的识别策略，
 但我需要先检验平行趋势假设是否成立"
```

#### 错误2：方法复杂度崇拜

```
错误模式：
"RDD比OLS更高级，审稿人会更认可"
→ 结果：断点变量可被操纵，RDD假设不成立，不如一个诚实的OLS

正确做法：
方法没有高级低级之分，只有合适不合适。
一个假设满足的简单方法胜过一个假设不满足的复杂方法。
```

#### 错误3：忽视方法的假设前提

```
错误模式：
"别人用DID研究过类似问题，我也用DID"
→ 结果：别人的数据满足平行趋势，你的不满足

正确做法：
每个方法选择都必须论证其假设在你研究情境下是否成立。
方法论证是论文方法部分的核心，不是装饰。
```

#### 错误4：过度方法化

```
错误模式：
"我要同时用DID、PSM、IV三种方法，显示稳健性"
→ 结果：每种方法的假设都不充分满足，反而暴露更多弱点

正确做法：
一种方法做到极致（假设检验充分、稳健性完整），
比三种方法都做得半吊子更有说服力。
```

### 五、AI辅助方法匹配

#### 用LLM做方法对话

```
Prompt模板：

我是一名社科博士生，研究问题是[具体问题]。
请帮我分析最适合的研究方法：

1. 首先，分析我的研究问题属于什么类型（描述性/解释性/探索性）
2. 其次，判断需要回答什么层级的因果问题（关联/机制/效应）
3. 然后，推荐2-3种适合的方法，对每种方法说明：
   a. 为什么适合我的研究问题
   b. 前提假设是什么
   c. 需要什么数据
   d. 主要局限
4. 最后，推荐你认为最合适的方法并说明理由

我的约束条件：
- 数据来源：[描述你已有或可获得的数据]
- 时间预算：[你有多少时间]
- 方法训练背景：[你接受过哪些方法训练]
```

#### 避免AI推荐"流行但不适合"的方法

```
追问Prompt：

你推荐了[方法]，但我不确定它适合我的情况。
请帮我：
1. 列出该方法的所有关键假设
2. 对每个假设，评估在我的研究情境下是否可能成立
3. 如果某个假设不成立，有什么替代方案？
4. 是否存在更简单但同样有效的方法？

我的研究情境：[补充具体情境]
```

#### 从方法推荐到方法论证

```
Prompt模板：

基于我们之前的讨论，我决定使用[方法]研究[问题]。
请帮我起草方法论证段落，包括：
1. 为什么选择这个方法（而非其他方法）
2. 方法的核心假设及其在我的情境下的合理性
3. 假设检验计划
4. 已知局限及应对策略

注意：方法论证需要诚实，不回避局限性。
```

## 关键细节与易错点

- **易错：方法选择变成"方法炫耀"**。选择方法是为了有效回答研究问题，不是为了展示方法论功底。审稿人看重的是方法适配度，不是方法复杂度
- **易错：忽视研究问题的因果层级**。把"为什么"的问题当"多少"的问题来回答，或反过来。先明确你要回答什么层级的问题，再选方法
- **易错：混合方法沦为"两种方法都做一遍"**。混合方法的核心是整合——定性和定量如何相互补充、验证或解释？没有整合逻辑的混合方法只是两篇独立研究拼在一起
- **易错：AI推荐的方法未经适配性检验就采用**。LLM倾向推荐主流/热门方法，你需要追问"这个方法的假设在我的情境下是否成立"
- **易错：因为数据限制就降级研究问题**。如果最优方法需要你无法获得的数据，应该考虑调整数据来源或寻找替代识别策略，而非降低问题的因果层级

## 社科科研示例

你是政治学博士生，研究问题是："基层治理创新为什么在有的地方扩散成功，有的地方失败？"

**问题分析**：
- 问题类型：解释性（"为什么"）
- 因果层级：因果机制（不是"效应多大"，而是"为什么有差异"）
- 理论成熟度：中等——有政策扩散理论，但基层治理创新的扩散机制缺乏研究

**方法推理**：
- 纯定量？样本量有限（某省的基层治理创新案例约50个），变量难以完全量化
- 纯定性？可以深入理解机制，但缺乏推广性
- 混合方法？顺序探索型——先定性探索机制，再定量检验普适性

**最终方法设计**：
1. 阶段一（定性）：选择4个典型案例（2成功2失败），深度访谈+文档分析，归纳扩散机制的假设
2. 阶段二（定量）：用50个案例的数据，对定性阶段提出的假设做logistic回归检验

**AI辅助**：用LLM讨论混合方法的具体设计——定性案例如何选择、定量检验的变量如何设计、两个阶段如何衔接。LLM帮助发现了我未考虑到的案例选择策略（最大差异设计而非典型抽样）。
