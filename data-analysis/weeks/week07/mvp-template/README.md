# MVP 最小骨架模板（W7 兜底用）

> **给谁用**：W7 Streamlit 上手卡住的同学。先用这个骨架让产品"能打开 + 展示一个核心分析"，再逐步填充成自己的 MVP。
> 骨架不是产品本身——验收底线是"数据加载→分析→可视化"闭环可用，填充方向仍按你 W6 的可视化方案。

## 运行

```bash
cd mvp-template
pip install -r requirements.txt
mkdir data        # 把你的项目 CSV（W4 落盘数据）放进这里
streamlit run app.py
```

打开 http://localhost:8501 即见骨架。

## 文件

| 文件 | 作用 |
|---|---|
| `app.py` | 侧栏筛选 + 数据概览 + 核心图表 + 关键发现四段式骨架 |
| `requirements.txt` | streamlit / pandas / plotly |

## 三步填充法（建议交给 AI 辅助编程做）

1. **换数据**：把 `DATA_FILE` 指向你的 W4 落盘数据，让 AI 按你的字段说明改列名与筛选控件。
2. **换分析**：把"数据概览"替换为你 W5 EDA 中已验证的分析逻辑（W4 手动流程转化来的代码搬进来）。
3. **换图表**：按 W6 图表设计说明逐个替换"核心图表"——每张图要传达的洞察写进图标题或说明文字，保持叙事递进。

每步的 Prompt 套路：*"这是我的 app.py 和 W6 图表设计说明（粘贴），请把『核心图表』部分替换为……，替换处须保留侧栏筛选联动，说明你改了哪些行、为什么"*——AI 改完必须本地跑一遍验证，再进下一步。
