# Week 01 课堂实验 — 用代码再跑一遍组里那一问（约 15 分钟）

## 背景：数据是什么

课程群里有两张国家财政月度表：

- `财政收入-月度数据.xlsx`
- `财政支出-月度数据.xlsx`

时间大约从 2001 年到现在，格子里是累计值（亿元）和累计同比（%）。支出列名带「不含债务还本」。读 `.xlsx` 需要 **pandas + openpyxl**（见 `python-setup.md`）。不要让 AI 去编一个不存在的 `data.csv`。

## 背景：刚才已经做过什么

组里已经用 Excel / 网页对话 / 计算器 / 肉眼，商定了 **1 个**想探索的问题，并留下三行：

1. 问题一句
2. 用了什么工具
3. 得到了什么，或卡在哪

验收 Python、在 Cursor 里选解释器；教师用同一类财政表演示过「读文件 + 问一句」。登录或网络不顺可用 Trae，评分一样。

本步要把**同一份数据、组里那一问**，换成代码再跑一遍。

## 开始前检查

- [ ] Cursor 已打开财政数据所在文件夹（已装 Trae 的可继续用 Trae）
- [ ] `Ctrl+Shift+P` → **Python: Select Interpreter**：推荐选 3.13（路径里有 `Python313`，不要选 anaconda）。电脑上已有能用的 Python、你愿意继续用的，选那个也行
- [ ] 终端 `python --version` 能打印版本；已执行过 `python -m pip install pandas openpyxl`

## 任务（每人自己的电脑）

**1. 先跑通「能读文件」（优先）**

把教师演示的问话贴进 Cursor，按你的文件名改一下，例如：

> 用 pandas 读取这个 xlsx，打印行数、列名和第 1 个数值列的均值。

**必须点运行**，终端无报错。可先复制教师问话，再改成你的文件名，或改成看另一列。

**2. 再尽量用代码回答组里那一问**

把三行里的「问题一句」贴给 AI，要求对着**已经读进来的表**回答。能出数或出图都算；15 分钟内答不完，记下卡在哪，第 3 节继续。

## 卡住了

卡住 → 同组（对方口述步骤，盯着你自己键入）→ 把报错贴给 AI → 两分钟仍卡再举手。安装问题优先问组里已经跑通的人。

## 当堂过关

- [ ] 自己的电脑读进了 xlsx，终端跑过、不是「看起来对」
- [ ] 至少改过 AI 输出的一处（文件名、列名、或组里那一问）
