# Week 01 教学计划

## 主题

课程启动 + PBL方法论 + AI工具栈起步

## 本周学习目标

- 能用自己的话说明 Challenge→Gap→Knowledge→Apply 学习循环与"从知识接收者到问题解决者"的角色转变
- 能装好推荐的集成开发环境 **Cursor**（登录或网络不顺时可用 Trae），完成安装并选中 Python 3.13，用 AI 辅助编程跑通一次真实数据（国家财政数据集）的分析
- 能进入一个真实社区场合（线下到场 / 线上旁听 / 需要时再注册），听出原话，再从中抽出数据分析产品可能服务的用户群，用 `templates/community.md` 交齐调研

> **编程小白**：不要求会写 Python。本周过关 = Cursor（或备选 Trae）能打开文件夹 + 让 AI 读入财政数据并跑通 + 能说出自己改了哪一处。语法课不单独开。建组时每组至少 1 人能装环境。详见总方案「编程小白路径」。

> **IDE（告知学生）**：本课**鼓励用 Cursor**（[cursor.com/cn](https://cursor.com/cn)），课堂主演示也用它。登录或校园网不顺时可用国内 **Trae**（[trae.ai](https://www.trae.ai)），课程同样认、评分不扣。装一个用熟即可，不要两个都装当任务。

## 预计投入

课堂 3×45 分钟。课外 6-8h（含社区倾听与提交 `community.md`）

## 教学内容

1. PBL学习方法论
   - 什么是PBL：以学生为中心、在做中学、真实问题驱动
   - Challenge→Gap→Knowledge→Apply 学习循环
   - 学生角色转变：从知识接收者 → 问题解决者 → 主动学习者
2. 课程框架与公约构建
   - 4阶段17周全景图（Idea→MVP→Launch→Scale）
   - "一人公司 + 互助小组"模式
   - 课程公约师生共建（W1 课后填问卷；教师收集为数据；W2 课堂一起分析，整理成课堂公约）
3. AI辅助编程工具实操（鼓励 Cursor；Trae 为登录/网络备选）
   - **Python 3.13（官网安装，不要 Anaconda，不要点首页的 3.14）**：IDE 都不自带解释器，本周必须先装 Python 才能本地运行。步骤见 `weeks/week01/python-setup.md`。个人项目 `.venv` 留到 W2 建仓时再配（`weeks/week02/venv-setup.md`）
   - **Cursor**（推荐）：[https://cursor.com/cn](https://cursor.com/cn)，基于 VS Code 的 AI-first IDE；课堂主演示
   - **Trae**（备选）：[https://www.trae.ai](https://www.trae.ai)，登录或网络不顺时可用，课程同样认可
   - **AI办公平台**（课外选做，不计入 IDE 必选）：TraeWork、workbuddy
   - 国家财政数据：第 2 节先发 xlsx，小组用已会的工具探 1 问；再在 Cursor 里用同一数据跑通（教师机备好 Trae 作回退）
   - Prompt三原则（清晰性、上下文、约束）在实操中自然体验，不单独讲解
   > 个人项目仓库与 AGENTS.md 有意安排在 W2 随 opencode 课堂创建（先创建、再被 opencode 读取），本周不需要。
4. 互助小组组建（**在环境实操之前完成并就座**，练习以小组为单位、每人仍独立跑通）
5. 社区调研（当堂学方法，课后做完并提交 `templates/community.md` 全文）
   - 社区 = 一群经常碰面、反复聊同一类事的人（线下或线上）
   - 先进入社区听人说话，再从中抽出「若做成数据分析产品、会来用的那一类人」
   - 进入方式三选一：线下到场（不必注册）/ 线上可旁听 / 线上需注册才看得见
   - 本周须进场倾听，原话 ≥3 条

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：在课程群发 `weeks/week01/python-setup.md` 与 `weeks/week01/lab.md`，要求带电脑前装好 Python 3.13，并**优先装好 Cursor**（登录或网络不顺再装 Trae；不要两个都当作业）；把 `data/nation/` 下财政月度 **xlsx**（收入、支出）发到课程群，课间就能打开；展示站离线备份可打开；教师机 **Cursor 已登录**（Trae 备着作回退），同一份财政数据能跑；**公约问卷图 `pic/class-norms.png` 课前备好，第 3 节末发课程群**；打印或投影 `templates/community.md`。白板先写课上求助顺序：**卡住 → 同组（盯着对方自己键入，禁止代跑交差）→ 问 AI（附报错）→ 举手教师**。

**第1节 · 定向与建组（45 分钟）**

1. **开场（4 分钟）**：一句话点明学期终点（公开产品 + 路演）；并说清「小白第一胜是环境能跑 + 能判断 AI 对错，不是先学会 Python」。点明等下先建组再动手。学生打开展示站。
2. **展示站走读（15 分钟）**：按上文点击顺序（首页 → 简介 → 项目之旅停在 W1 → 公约页只点开 → 精彩项目一句）。简介页停一句：**一人一产品，小组是互助不是分工写同一个作业。**
3. **白板画学习循环（8 分钟）**：Challenge→Gap→Knowledge→Apply，预告第 2 节会先发真实财政表、用已会的工具试答一问，再引入 Cursor；点明角色从听课转到做产品。
4. **组建互助小组并就座（18 分钟）**：鼓励 5 人一组（约 30 人 → 6 组）。规则当场说清两条：①每人独立交付产品；②**每组至少 1 人这学期能装环境**（举手：装过 Python / 用过 VS Code、Cursor、Trae 的先散开当种子，全是小白的组教师当场拆开混编）。就近自由组合，教师只调剂「全组都不会装」和人数。当场交换姓名，座位调到同组相邻；背景/技能**课后写入协议**，课上不填表。课间保持同组座位，第 2–3 节不再换座。

**第2节 · 演示与小组练习（45 分钟）**

5. **先发数据、用已会的工具探一问（10 分钟）**：课程群里的财政 xlsx 直接打开（U 盘兜底）。组内商定 **1 个**想探索的问题，用**自己已经会的工具**试着答：Excel、网页对话、计算器、肉眼看表都可以。**即使已装 Cursor，这 10 分钟先不用。** 每组纸上或群里留下三行：问题一句 / 用了什么工具 / 得到了什么或卡在哪。教师巡组。
6. **Python 验收 + 安装 Cursor（8 分钟）**：全班终端跑 `python --version`（须为 3.13.x）。当众说明：**鼓励用 Cursor，课堂用它演示；登录或网络不顺可用 Trae。** 未装的按 `python-setup.md` 当场补；**先问同组已装好的同学，教师巡组不巡个人。** 教师机演示一次「打开文件夹 / 选中 3.13 解释器」。不装 Anaconda、不点官网首页 3.14。小白只跟三步：打开文件夹 / 选解释器 / 把报错贴回去。
7. **财政数据演示（12 分钟）**：打开同一份 xlsx，尽量接住某一组刚写下的那一问（接不住则用白板问话：「用 pandas 读取这个 xlsx，打印行数、列名和第 1 个数值列的均值」）。**在 Cursor 里跑通**：读入、看一张表、让 AI 辅助回答刚才那一类问题；超时切回退。Prompt 三原则只在这一问里点破。点明第 1 节的 Gap：刚才用 Excel/网页能做一部分，代码把同一问变得可复现。
8. **小组开做：把刚才那一问用代码再跑一遍（15 分钟）**：学生打开 `lab.md`。同一数据集，**每人自己的电脑**先跑通「能读文件」，再尽量用 Cursor 回答本组第 5 步写下的那一问。可复制教师问话再改一列名。卡住先问同组（对方口述步骤、盯着自己键入）；两分钟仍卡再举手。禁止一人跑通、五人交同一截图。本周小练当堂完成，不另交课后任务。

**第3节 · 小组跟做与社区调研（45 分钟）**

9. **探索与排障（20 分钟）**：在第 2 节那一问上再补到 3 个有趣问题（产出仍是个人的）。组内可轮流说自己的问题、互看报错；教师按组巡视，安装问题优先丢回组内已跑通的人。
10. **社区调研怎么做（17 分钟）**：先给定义（社区 = 经常碰面、反复聊同一类事的人）。白板三种进入方式：线下到场 / 线上可旁听 / 需要才注册。打开 `templates/community.md`，当堂只填第 1 节场合（每人一份）。抽问：「你去听哪一群人？他们在聊什么？」不要先逼学生定产品用户。示范记一条原话进第 4 节；第 5 节「服务谁」课后听完再从原话里抽。**课后须进场听完，交齐全文（含 ≥3 条原话）**。
11. **收束（8 分钟，当天最后一环）**：先布置三件课后作业——① `templates/group-agreement.md` 打印签字；② 扫 `pic/class-norms.png` 填公约问卷；③ 做完社区调研，提交 `templates/community.md` 全文（第 1–6 节，原话 ≥3 条）。TraeWork 留课外。提醒：课外卡住仍是 AI → 互助组 → 课程群。不在本节改公约措辞。**最后一项工作**：打开 `templates/journal.md`，按五格写今天 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）；互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。本周不单独交。W2 建仓时把这份文件拷进仓库。

## 项目活动

**必做**
1. 第 1 节末完成互助小组组建并就座（鼓励 5 人；每组至少 1 人能装环境）；课后在 `templates/group-agreement.md` 补全成员背景/技能并全员签字
2. 按 `weeks/week01/python-setup.md` 安装 **Python 3.13（官网，不要 Anaconda，不要首页 3.14）**，并安装 **Cursor（推荐；登录或网络不顺可用 Trae）**；终端 `python --version` 能打印 3.13
3. 用AI辅助编程完成环境配置（在 IDE 里选中上述解释器；`pip install pandas openpyxl`）；课堂以小组为单位排障，每人自己的机器跑通
4. 国家财政数据探索：第 2 节先用已会的工具探 1 问，再用 Cursor 实操（已装 Trae 的可继续），补到 3 个有趣问题
5. 每人完成并提交社区调研（`templates/community.md` 全文）：进入一个社区场合（线下 / 旁听 / 需要才注册），记下 ≥3 条原话，再从中抽出数据分析产品可能服务的用户群

**进阶（可选）**
- 用 TraeWork / workbuddy 对自己感兴趣的财经话题做一次深度调研

**兜底**
- 电脑装不上环境/性能不足：先借机房或同学环境完成课堂演示，把报错截图带到课堂互助组，不影响本周交付
- 还不确定为谁做产品 / 进不去规划中的场合：先从身边一个会反复聊这类事的场合听起（家里管钱的人、社团、实习点），候选方向可粗
- **编程小白**（没写过 Python 也走主活动，不另开语法课）：本周只要求 Cursor（或备选 Trae）能打开文件夹、让 AI 读财政数据并本地跑通、对 1 个结果写「信/不信，因为」。语法不讲；周末自愿看阅读材料里的 Python 入门即可。互助组混编（每组至少 1 人能装环境）。完整路径见总方案「编程小白路径」。

## 卡住了找谁

- **课上**：卡住 → ①同组（盯着对方自己键入，禁止代跑交差）→ ②问 AI（附报错）→ ③举手教师。安装类问题优先留在组内已跑通的人。
- **课外**：卡住 → ①先问 AI（附报错与上下文截图）→ ②互助组（当日）→ ③课程群（教师承诺 24h 内响应）→ ④课堂一对一交流。账号/安装类问题直接走 ③。

## 课后任务

1. 完成互助小组协议（模板 `templates/group-agreement.md`）：小组名称、小组成员、我们的约定、处理机制、日期与全员签字（提交打印版）
