今天怎么走：看见学期终点 → 建组就座 → 用已经会的工具探财政表 → 换成 Cursor 跑通同一问 → 布置社区调研（先听人，再抽用户）→ 写当天 `journal.md`。

## 第 1 节 · 定向与建组

学期终点是公开产品，不是先学会 Python。先组好队，再动手。

1. **开场**
  17 周后每人一件能打开的数据分析产品，当场给别人试用。第一胜是环境能跑、能判断 AI 对不对，不是先背语法。打开上面的展示站。
2. **展示站走读**（按这个顺序，不用六页都逛）
  ① [首页](https://haichaozheng.github.io/data-analysis-showcase/)：学期结束时的公众入口  
   ② [简介](https://haichaozheng.github.io/data-analysis-showcase/intro.html)：**一人一产品；小组是互助，不是分工写同一份作业。** 成绩结构：平时 50 + 个人项目 50  
   ③ [项目之旅](https://haichaozheng.github.io/data-analysis-showcase/timeline.html)：四阶段 17 周，停在本周  
   ④ [公约](https://haichaozheng.github.io/data-analysis-showcase/rules.html)：先知道有这份草稿，**不当场改措辞**；课后填问卷，下节课用问卷数据一起定  
   ⑤ [精彩项目](https://haichaozheng.github.io/data-analysis-showcase/projects.html)：作品会挂在这里；路演是全员参加、现场试用
3. **学习循环**
  **Challenge → Gap → Knowledge → Apply**  
   下一节先发真实财政表，用已经会的工具试一问，再请 Cursor 进来。角色：从听课转到做产品。
4. **建互助小组并就座**
  鼓励 5 人一组。两条：
  - 每人独立交付自己的产品
  - **每组至少 1 人这学期能装环境**（用过 Python / VS Code / Cursor / Trae 的先散开当种子）
   交换姓名，座位调到同组相邻。课上不填表，背景和技能课后写入协议。课间不换座。

这一节结束：人已按组坐好。

## 第 2 节 · 探一问再跑通

先用旧工具碰到缺口，再用 Cursor 把同一问跑成可复现的代码。

1. **用已经会的工具探 1 问**
  打开两张表：财政收入、财政支出（累计值；支出不含债务还本）。**即使已经装了 Cursor，这一段先不用。**  
   组内商定 1 个问题。Excel、网页对话、计算器、肉眼看表都可以。留下三行：问题一句 / 用了什么工具 / 得到了什么或卡在哪。
2. **Python 和 Cursor**
  终端 `python --version`，本课用 **3.13**。课堂演示用 Cursor；登录或网络不顺可用 Trae。装一个即可。  
   打开文件夹 → `Ctrl+Shift+P` → **Python: Select Interpreter** → 选路径里有 `Python313` 的，不要 Anaconda，不要官网首页的 3.14。  
   小白先跟三步：打开文件夹 / 选解释器 / 把报错贴回去。未装好的先问同组已经装好的同学。
3. **一起跑通同一问**
  尽量接着组里刚写下的那一问。接不住就用：
  > 用 pandas 读取这个 xlsx，打印行数、列名和第 1 个数值列的均值。
   **要点运行。** Prompt 三原则就在这一问里体会：说清楚、给上下文、加约束。刚才 Excel 或网页能做一部分；代码让同一问可以复现。不要让 AI 去编一个不存在的 `data.csv`。
4. **打开** `lab.md`**，每人自己的电脑做**
  先跑通「能读文件」，再尽量用代码回答组里那一问。可以复制上面的问话，改文件名或列名。  
   当堂过关：终端跑过、不是「看起来对」；至少改过 AI 输出的一处。禁止一人跑通、五人交同一截图。本周小练当堂完成。

这一节结束：多数人已经读进 xlsx。没跑通的下一节继续，安装问题先问组里已经跑通的人。

## 第 3 节 · 跟做与社区

财政表是课堂练手。真正的产品用户在社区里。本周先听人说话，不要先发明用户。

1. **继续探索、互相排障**
  在上一问上再补到大约 3 个有趣问题（各写各的）。组内轮流说问题、互看报错。电脑实在装不上：先借同学机器完成课堂演示，报错截图留给小组；本周交付不因安装失败清零。
2. **社区调研怎么做**
  社区 = 一群经常碰面、反复聊同一类事的人（线下或线上）。  
   进入方式三选一：线下到场 / 线上可旁听 / 需要才注册。  
   打开 `templates/community.md`，**当堂只填第 1 节场合**（每人一份）。先问自己：去听哪一群人？他们在聊什么？**先不要定「我计划服务谁」。**  
   示范往第 4 节记一条原话。「服务谁」课后听完再从原话里抽。互助小组不是用户社区。找不到场合：家里管钱的人、社团、实习点都可以先听。
3. **布置课后作业**
  作业见下。公约不当场改措辞。课外卡住：先问 AI → 互助组 → 课程群。
4. **写当天 `journal.md`（最后一项工作）**
  打开 `templates/journal.md`，按五格写今天 1 条：今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录。互助只写谁帮了你、对项目有何影响，没有则写「无」。本周不单独交。个人仓库 W3 才把文档拷进 `docs/`，把这份文件留着，W3 拷到 `docs/journal.md`。
