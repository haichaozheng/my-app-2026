# Week 10 教学计划

## 主题
打磨迭代 + 上线准备

> **前置**：须已完成 W9 同侪互评并开始打磨。本周完成打磨并做上线准备。

## 本周学习目标

- 能按反馈优先级排序完成 v0.4 定向打磨，并说明"为什么先做这些"
- 能写出可执行的上线部署方案：部署目标、进程启动方式、数据库选型理由（首选 SQLite，需要多用户并发写再考虑 PostgreSQL）、AI 功能部署考量（API Key 管理、RAG 向量库存储）
- 能说明公网可访问与本地运行的关键区别（进程常驻、端口暴露、依赖环境）
- 能对照 DSR 七指导原则完成 MVP 阶段自检

## 预计投入

课外 10-12h（注意：腾讯云校园额度审核有等待期，周初就提交申请，别拖到周末）

## 教学内容
1. 据反馈定向打磨与技术债清理
2. 腾讯云账号与轻量应用服务器/CloudBase申请（校园免费额度）
3. 部署方案要点：公网可访问 vs 本地的关键区别 + 数据库选型（首选SQLite）+ AI功能部署考量（LLM API Key管理、RAG向量库存储）
4. 如何做阶段回顾：DSR 自检方法与范例（MVP阶段）——回顾动作本身在课后作业完成

## 项目活动

**必做**
1. 完成根据互评反馈的定向打磨，产出v0.4（可演示版）
2. 申请腾讯云账号并领取校园/免费额度，确定上线方式
3. 撰写个人上线部署方案

**进阶（可选）**
4. 方案确定后即刻试部署：允许失败，记录报错即可——W11 课堂只做验收与排障工作坊，本周先踩坑可前移部署的不确定性（排障先查 `weeks/week10/deployment-faq.md`）

**兜底**
- 云额度审核无响应/过慢：改走 Streamlit Cloud 备选路线（部署方案含两路径，W11 验收均认）

## 交付物（评分锚点）

- 个人MVP v0.4（打磨版，可演示）
- 腾讯云账号 + 免费额度申请完成
- 个人上线部署方案（含数据库选型 + AI功能部署考量）

—— 规格与知识锚定见 milestones §2.7；计入平时成绩（形成性）。提交前自检：打磨项有优先级排序与理由？数据库选型依据并发/部署形态而非"听说好用"？方案考虑了 W11 部署与 W12-W15 建模增强的集成？

## 卡住了找谁

卡住 → ①先问 AI（附报错与上下文截图）→ ②互助组（当日）→ ③课程群（教师承诺 24h 内响应）→ ④固定办公时间（1v1，时间见课程通知）。云账号/额度审核类问题直接走 ③ 并注明时限。

## 课后作业
1. 完成产品打磨
2. 完成云资源申请与部署方案
3. 本周末做阶段回顾(15min)，产出含DSR自检(MVP阶段)的阶段反思
