# Week 10 教学计划

## 主题
打磨迭代 + 上线准备

> **前置**：须已完成 W9 同侪互评并开始打磨。本周完成打磨并做上线准备。

## 本周学习目标

- 能按反馈优先级排序完成 v0.4 定向打磨，并说明"为什么先做这些"
- 能写出可执行的上线部署方案：部署目标、进程启动方式、数据库选型理由（首选 SQLite，需要多用户并发写再考虑 PostgreSQL）、AI 功能部署考量（API Key 管理、RAG 向量库存储）
- 能说明公网可访问与本地运行的关键区别（进程常驻、端口暴露、依赖环境）
- 能对照 DSR 七指导原则完成 MVP 阶段自检

## 预计投入

课堂 3×45 分钟。课外 10-12h（注意：腾讯云校园额度审核有等待期，周初就提交申请，别拖到周末）

## 教学内容
1. 据反馈定向打磨与技术债清理
2. 腾讯云账号与轻量应用服务器/CloudBase申请（校园免费额度）
3. 部署方案要点：公网可访问 vs 本地的关键区别 + 数据库选型（首选SQLite）+ AI功能部署考量（LLM API Key管理、RAG向量库存储）
4. 如何做阶段回顾：DSR 自检方法与范例（MVP阶段）——回顾动作本身在课后作业完成

## 课堂演示工具

| 环节 | 工具 | 用法 |
|---|---|---|
| 概念 | 薄幻灯 | 公网 vs 本地、SQLite 首选、Key / 向量库部署 |
| 现场主演示 | 浏览器（云控制台）+ 一份合格部署方案 | 走一遍腾讯云 / CloudBase 申请；对照 FAQ 讲 5 类报错 |
| 辅 | Streamlit 打开 v0.4 | 明确「可演示」长什么样 |
| 不做 | 课堂当场首次部署 | 不确定性已前移到课后试部署 |

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：1 份合格部署方案；云控制台已登录（或截图流程）；`deployment-faq.md` 可投影；v0.4 演示产品能打开。不当场首次部署。

**第1节 · 打磨到可演示（45 分钟）**

1. **互评未改完的先排序（10 分钟）**：为什么先做这几项；v0.4=可演示。
2. **打开一台 v0.4（10 分钟）**：Streamlit 看「可演示」长什么样（主路径 3 分钟能走完）。
3. **公网 vs 本地（25 分钟）**：薄幻灯：进程常驻、端口、依赖；SQLite 首选；Key 与向量库放哪。

**第2节 · 上线准备（45 分钟）**

4. **云账号申请走一遍（20 分钟）**：腾讯云轻量 / CloudBase；强调周初申请、审核等待。备选 Streamlit Cloud。
5. **FAQ 五类报错（15 分钟）**：环境 / 端口 / 依赖 / 防火墙 / API Key，对照 `deployment-faq.md`。
6. **方案文档结构（10 分钟）**：部署目标、启动方式、数据库理由、AI 部署考量、两路径。

**第3节 · 学生写方案（45 分钟）**

7. **起草个人部署方案（30 分钟）**：未申请云账号的当堂提交申请。
8. **DSR 自检方法（10 分钟）**：MVP 阶段七原则怎么对照；回顾动作在周末作业。
9. **收束（5 分钟）**：进阶者课后试部署、允许失败；W11 课堂只验收。本周无技能小练。

## 项目活动

**必做**
1. 完成根据互评反馈的定向打磨，产出v0.4（可演示版）
2. 申请腾讯云账号并领取校园/免费额度，确定上线方式
3. 撰写个人上线部署方案

**进阶（可选）**
4. 方案确定后即刻试部署：允许失败，记录报错即可——W11 课堂只做验收与排障工作坊，本周先踩坑可前移部署的不确定性（排障先查 `weeks/week10/deployment-faq.md`）

**兜底**
- 云额度审核无响应/过慢：改走 Streamlit Cloud 备选路线（部署方案含两路径，W11 验收均认）

## 交付物（评分锚点）

- 个人MVP v0.4（打磨版，可演示）
- 腾讯云账号 + 免费额度申请完成
- 个人上线部署方案（含数据库选型 + AI功能部署考量）

—— 规格与知识锚定见 milestones §2.7；计入平时成绩（形成性）。提交前自检：打磨项有优先级排序与理由？数据库选型依据并发/部署形态而非"听说好用"？方案考虑了 W11 部署与 W12-W15 建模增强的集成？
