# Week 02 教学计划

## 主题
金融数据全景 + opencode + 社区调研起步

## 教学内容
1. opencode命令行AI助手（Coding Agent入门与实战）
   - 安装配置opencode
   - 完成首次对话交互
   - 读取AGENTS.md接管项目上下文
   - 复现教师演示的案例
2. 金融数据源与获取（API/Web Scraping）
3. 数据生态概览
4. **自主学习**：Minimalist Entrepreneur社区先行方法（提前预习W3内容）
5. **自主学习**：用户访谈技巧与The Mom Test原则（提前预习W3内容）

## 项目活动
1. 完成opencode安装与配置
2. 用opencode完成首次对话交互
3. 用opencode探索金融数据生态，了解主要数据源的可得性与获取方式（不急于选题，聚焦建立数据全景认知）
4. 锁定目标用户聚集的社区并加入、开始倾听记录

## 交付物
- 数据源调研报告（含主要数据源可得性初验）
- 社区加入记录（社区名、加入方式、初步倾听记录）

## 课后作业
1. 完成数据源调研报告
2. 熟练使用opencode
3. 加入目标社区并记录3条真实用户问题
4. **自主学习**：阅读`knowledge/phase1-1-7-community-first.md`，理解社区先行方法论
5. **自主学习**：阅读`knowledge/phase1-1-6-user-insight.md`，掌握用户访谈基本技巧
