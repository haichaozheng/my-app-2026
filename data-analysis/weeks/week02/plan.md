# Week 02 教学计划

## 主题
金融数据全景 + opencode + 社区调研起步

## 本周学习目标

- 能根据 W1 公约问卷结果，和同学一起把分歧条款整理成课堂公约
- 能初始化个人项目仓库并创建 AGENTS.md 骨架，用 opencode 读取 AGENTS.md 接管项目上下文、完成首次交互并复现课堂案例
- 能列出 ≥2 个可用金融数据源并说明覆盖范围与获取方式，对每个候选方向完成数据可得性初验
- 能加入 1 个目标用户社区并完成初步倾听记录（用户原话 ≥3 条），理解"入社区正是为选题服务"

## 预计投入

课堂 3×45 分钟。课外 6-8h（另含两份 W3 自主预习材料约 1-2h）

## 教学内容
1. 用 W1 公约问卷数据，全班一起分析分歧条款，整理成课堂公约
2. opencode命令行AI助手（Coding Agent入门与实战）
   - 安装配置opencode
   - 初始化个人项目仓库、创建 AGENTS.md 骨架（模板 `templates/AGENTS.md`）
   - 读取AGENTS.md接管项目上下文，完成首次对话交互
   - 复现教师演示的案例
3. 金融数据源与获取（API/Web Scraping）
4. 数据生态概览
5. **自主学习**：Minimalist Entrepreneur社区先行方法（提前预习W3内容）
6. **自主学习**：用户访谈技巧与The Mom Test原则（提前预习W3内容）

## 课堂演示工具

| 环节 | 工具 | 用法 |
|---|---|---|
| 概念 | 薄幻灯（≤10页） | 金融数据生态全景、社区先行预告 |
| 现场主演示 | opencode 终端（投影放大字号） | 建 repo → 写入 AGENTS.md → 读取接管 → 复现案例 |
| 辅演示 | Trae | 终端输出看不清时，用同一脚本在 Trae 里拉通数据源 |

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：教师机 opencode 可运行；`templates/AGENTS.md` 与课堂案例仓库已克隆；终端字号放大；课程群发 `weeks/week02/venv-setup.md`；**W1 公约问卷已收齐并做成可投影的汇总**（条数、分歧点即可，不必精美）。

**第1节 · 公约 + 建仓（45 分钟）**

1. **分享上周 journal + 本周目标（5 分钟）**：随机邀请同学分享上周 journal（3 问：补上了哪个缺口 / 哪个判断不稳 / 下周先解哪个卡点）。W1 记在笔记里的迁入 `journal.md`。仓库本周才建；社区倾听为选题服务，不锁定题目。
2. **课堂公约（10 分钟）**：投影 W1 公约问卷汇总（教师课前收齐）。和同学一起看 1–2 条分歧意见，当场改成课堂公约，记入课程群。问卷即本课「真实数据」的一次练习：先有数据，再一起下判断。
3. **opencode 安装（10 分钟）**：教师投屏安装；学生跟做。装不上的先用 Trae，周末补齐，报错截图进群。
4. **初始化个人仓库（20 分钟）**：git 建 repo → 放入 `templates/AGENTS.md` 骨架，并把 `templates/journal.md` 复制到仓库根目录 → 按 `weeks/week02/venv-setup.md` 在仓库根目录建 `.venv`（`.gitignore` 写入 `.venv/`）→ 推到远端。教师一步一停，学生同步。解释一句：W1 的系统 Python 只负责「有解释器」；个人项目的包装进 `.venv`，以后部署也靠这份环境。

**第2节 · 接管与数据全景（45 分钟）**

5. **opencode 读取 AGENTS.md（15 分钟）**：当场对话一次，复现教师案例（先创建、再被读取）。
6. **金融数据生态（15 分钟）**：薄幻灯 ≤10 页：API / 网页 / 备选源；每个源只讲覆盖范围与获取方式。
7. **拉一次数据示范（15 分钟）**：opencode 或 Trae 实拉一个公开源；失败则换备选源，示范「可得性初验」怎么记。

**第3节 · 跟做（45 分钟）**

8. **学生可得性初验（20 分钟）**：对 ≥1 个候选方向实拉数据；不要求锁定选题。
9. **锁定社区（15 分钟）**：每人选定 1 个用户社区并注册/加入；示范如何记用户原话。
10. **收束（10 分钟）**：布置 W3 两份预习（社区先行、用户访谈）；技能小练见 `lab.md` 当堂起笔。提醒：本周起项目工作流主工具是 opencode，日常写代码仍用 Cursor（Trae 亦可）。当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 即时学习 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。

## 项目活动

**必做**
1. 初始化个人项目仓库：git 建 repo，放入 AGENTS.md 骨架，并把 `templates/journal.md` 复制到仓库根目录，按 `weeks/week02/venv-setup.md` 建项目虚拟环境（`.venv/` 勿提交）；随后用 opencode 读取 AGENTS.md 接管项目上下文，完成首次对话并复现课堂案例
2. 用opencode探索金融数据生态：候选方向可先列出但**不锁定**——对每个候选方向用 Prompt+AI 辅助编程实拉一次数据，验证可得性，聚焦建立数据全景认知
3. 锁定目标用户聚集的社区并加入、开始倾听记录：入社区本身就是选题探索的一部分——先用社区真实问题反哺选题，W3 收敛方向（社区先行）

**进阶（可选）**
- 提前选修网页数据采集（`knowledge/phase1-1-4b-web-data-collection.md`，W4 正式引入）
- 完成 W3 两份自主预习材料并做读书笔记

**兜底**
- 数据源拉不通：记录失败原因，换 `project-selection-guide.md` §7 备选数据源
- opencode 装不上：带报错走课程群，本周数据探索可先用 Trae 完成，仓库与 AGENTS.md 周末补齐
- 找不到目标社区：从选题指南推荐社区（雪球/股吧/知乎话题）任选其一先加入，方向可再调

## 交付物（评分锚点）

- 个人赛道意向（含候选方向、数据源可得性初验、社区加入记录）
- 个人项目仓库链接（含 AGENTS.md 骨架、journal.md 起始记录）

—— 规格与知识锚定见 milestones §1.2；计入平时成绩（形成性）。提交前自检：≥2 个数据源含获取方式？≥3 条用户原话？≥1 个 Prompt 探索对话记录？仓库链接含 AGENTS.md？本地有 `.venv` 且未提交该文件夹？

## 卡住了找谁

卡住 → ①先问 AI（附报错与上下文截图）→ ②互助组（当日）→ ③课程群（教师承诺 24h 内响应）→ ④固定办公时间（1v1，时间见课程通知）。opencode 安装/数据源拉不通类问题直接走 ③ 并附截图。
