## 第 2 节 · 国庆假日窗口：pandas 基础与 EDA（45 分钟）

要回答的问题：国庆前后的日收益，和普通交易日一样吗？

这是待检验的窗口，不是已经成立的因子。数据用 2001 年至今的上证指数日线，收到补课当天。2026 年节前 5 个交易日已经完整；节后只画到 10 月 10 日已经复牌的交易日，标明「截至10月10日」，不满 5 日的部分空着。

1. **分享上周 journal（5 分钟）**
   随机邀请同学分享。三问：补上了哪个缺口 / 哪个判断不稳 / 下周先解哪个卡点。没有落盘数据的，先借同伴公开集聚练。
2. **pandas 基础（25 分钟）**
   学生在 Jupyter 里自己输入、自己运行。教师先写一格，学生跟着敲一格。每格停问「这格得到了什么」。这一段不请 AI 代写。

   | 格 | 得到什么 |
   | --- | --- |
   | 下载并落盘 | 2001 年至今的上证指数日线。tushare，`000001.SH`。密钥用课堂笔记本里已写好的 |
   | 读入收盘价 | 只留下后面要用的收盘价 |
   | 日期、索引、排序 | `trade_date` 转为 datetime，设为索引，`sort_index`。不排序，下一格的收益率会用错相邻两天 |
   | 简单收益率 | `pct_change`，\(R=P_t/P_{t-1}-1\) |
   | 对数收益率 | 学生自己算 \(r=\ln(P_t/P_{t-1})=\ln(1+R)\)，例如 `log_return = np.log(close / close.shift(1))`。和 \(R\) 并排看几天：平常日几乎一样，涨跌很大时拉开。\(R\) 接近 0 时，\(\ln(1+R)=R-R^2/2+\cdots\approx R\)。后面的窗口分组仍用简单收益率 |
   | 打标签 | 每年节前 5 个交易日、节后 5 个交易日，其余为普通日 |
   | `groupby` | 按窗口看各组的个数和平均收益率 |

3. **当堂核对（15 分钟）**
   手敲到 `groupby` 为止。这 15 分钟把上面几格跑完，看节前、节后的天数是否接近。三张图放到第 3 节。
