# Week 05 教学计划

## 主题
数据清洗与探索 + Prompt驱动EDA + 手动流程转代码

> **前置**：须已完成 W4 项目数据获取与落盘（项目数据集：获取脚本+落盘数据+字段说明）。本周 EDA 在该数据集上进行。

## 本周学习目标

- 能对项目数据中每类缺失/异常说明清洗策略选择理由（删还是补、均值还是中位数、为什么）
- 能从 ≥3 个分析视角完成 EDA，并说明每个视角的选择理由与发现
- 能用 Prompt 让 AI 辅助发现 ≥3 条自己未预想到的洞察，并对其中 1 条做可信度判断
- 能用 opencode 将 W4 手动流程转化为代码，验证结果与手动一致

## 预计投入

课堂 3×45 分钟。课外 8-10h

## 教学内容
1. Pandas高级操作
2. 缺失值/异常值处理
3. 探索性数据分析（EDA）
4. AI辅助编程生成数据清洗代码、转化手动流程
5. Prompt驱动EDA洞察

## 课堂演示工具

| 环节 | 工具 | 用法 |
|---|---|---|
| 概念 | 薄幻灯（≤6页） | 清洗策略选择理由（删还是补、为什么） |
| 现场主演示 | Jupyter Notebook | cell-by-cell：缺失/异常 → 多视角 EDA；每个决策停问「为什么」 |
| 辅 | Trae / opencode | 把 W4 手动步骤转化成代码，并与手动结果对照 |
| 学生跟做 | Jupyter（分析）+ Trae（转化） | 用自己的落盘数据，不换课堂示例集交差 |

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：带清洗决策的 Jupyter 已跑通；W4 手动步骤的转化对照表可投影。

**第1节 · 清洗决策（45 分钟）**

1. **分享上周 journal + 接 W4（5 分钟）**：随机邀请同学分享上周 journal（3 问：补上了哪个缺口 / 哪个判断不稳 / 下周先解哪个卡点）。用的是自己落盘的数据；没有数据的先借同伴公开集聚练。
2. **策略选择（10 分钟）**：薄幻灯只讲「删还是补、为什么」，不讲 API 清单。
3. **Jupyter 演示（30 分钟）**：cell-by-cell 处理缺失/异常；每步停问「为什么这样选」。

**第2节 · EDA 与转化（45 分钟）**

4. **多视角 EDA（20 分钟）**：同一数据至少 3 个视角；每个视角说清「看什么、发现什么」。
5. **Prompt 驱动洞察（10 分钟）**：现场问 AI 要 3 条新洞察，挑 1 条做可信度判断并留对话。
6. **手动→代码（15 分钟）**：Trae/opencode 把 W4 某一步变成代码，与手动结果对照。

**第3节 · 跟做（45 分钟）**

7. **学生在自己数据上做（25 分钟）**：先写清 1 类清洗理由 + 1 个 EDA 视角。
8. **技能小练（15 分钟）**：`lab.md` 当堂起笔。
9. **收束（5 分钟）**：交付=EDA 报告 + 转化代码与对照；转化结果直接服务 W6/W7。当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 即时学习 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。

## 项目活动

**必做**
1. 基于W4落盘的项目数据集，完成数据清洗与 EDA，产出个人 EDA 报告
2. 用 opencode 将 W4 手动流程转化为代码，验证结果与手动一致（转化后的代码直接服务于 W6/W7 的产品构建）
3. 用 Prompt 生成至少 3 个洞察，保留对话记录

**进阶（可选）**
- 把 EDA 多视角封装为可复用分析函数，为 W6 可视化与 W7 产品铺路

**兜底**
- W4 数据集仍缺失：先借用互助组同伴的公开数据集完成清洗/EDA 技术练习，自己的数据周末补齐后重跑，不影响本周技能交付

## 交付物（评分锚点）

- 个人EDA报告
- 手动→自动转化代码（附验证结果对比；原 W4 规格随转化一并移至本周）

—— 规格与知识锚定见 milestones §2.2；计入平时成绩（形成性）。提交前自检：清洗策略有理由？≥3 分析视角？附 1 个 Prompt 洞察对话记录？转化代码与手动结果做过一致性对比？
