# Week 16 教学计划

## 主题
路演叙事 + 公开路演（产品公网可访问，现场可打开试用）

## 本周学习目标

- 能按"问题→方案→产品(含模型)→价值"故事线，向技术+管理双受众讲清自己的产品
- 能把 Demo 聚焦核心价值环节而非功能罗列
- 能按评审标准评价他人产品，为观众评分提供依据

## 预计投入

课堂 3×45 分钟。课外 4-6h（PPT/Demo 完整制作在课堂制作与彩排时段完成，W15 只交了大纲与脚本）

## 教学内容
1. 路演叙事与演讲：故事线、Demo设计、时间控制、价值传达有效性
2. 课堂制作与彩排时段：基于 W15 大纲完成 PPT 与 Demo
3. 公网访问与现场试用规则、评分方式与观众互动

## 课堂演示工具

| 环节 | 工具 | 用法 |
|---|---|---|
| 概念 | 薄幻灯（教师示范路演 ≤8 页） | 故事线「问题→方案→产品→价值」；Demo 只打核心环节 |
| 学生主工具 | 路演 PPT + 公网 Streamlit（须现场可打开） | 课堂制作与彩排；故障切录屏 |
| 教师机 | 浏览器打开学生产品 + 评分表 | 不用 Trae / Jupyter 讲新知识 |
| 不做 | 功能清单式长 PPT | 每页一个核心信息 |

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：教师示范路演 ≤8 页 + 公网产品可开；评分表与计时器；录屏兜底通道。课前在群公布每人时限（第 2 节、第 3 节分开计时，每节满 45 分钟即停）。

**第1节 · 叙事与制作（45 分钟）**

1. **故事线（12 分钟）**：问题→方案→产品（含模型）→价值；技术与管理双受众各听懂一句。
2. **教师示范路演（8 分钟）**：只打核心 Demo，不念功能清单。
3. **规则（5 分钟）**：产品须公网可打开；故障切录屏，流程同；观众可当场试用。
4. **学生赶 PPT/Demo（20 分钟）**：基于 W15 大纲；每页一个信息。

**第2节 · 路演上半场（45 分钟）**

5. **串讲（45 分钟）**：按抽签或学号；计时；他人打开链接试用。本节结束即停，不拖进课间。

**第3节 · 路演下半场（45 分钟）**

6. **继续串讲（35 分钟）**：接着上半场名单；超时即止。
7. **收束（10 分钟）**：评分方式；每人课后整理 3 条观众/评委意见，写入 `journal.md` 或留给 W17 报告。未轮完宣布 W17 第 1 节续场（不新开知识）。教师机只用浏览器+评分表。当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。

## 项目活动

**必做**
1. 课堂完成路演 PPT 与 Demo 并彩排
2. 全员公开路演：产品须公网可访问，其他同学和观众当场打开试用
3. 课程展示网站作为路演公众入口，现场提供可打开的产品链接

**兜底**
- 现场Demo故障：切换录屏Demo（计分流程相同），不因环境问题清零

## 交付物（评分锚点）

- 路演评分（评委+观众）

—— 规格与知识锚定见 milestones §4.1；计入个人项目（产品质量·路演Demo）。路演面向真实观众而非仅教师评分，价值传达有效性本身是评分维度。

## 卡住了找谁

卡住 → ①先问 AI（附报错与上下文截图）→ ②互助组（当日）→ ③课程群（教师承诺 24h 内响应）→ ④课堂一对一交流。路演当天现场问题直接找教师。

## 课后任务
1. 完成路演展示
2. 把路演反馈（观众/评委意见及他人试用情况）整理 3 条，作为 W17 迭代与反思素材
