# Week 14 教学计划

## 主题
大模型做数据分析（必做）+ 模型强化

> **前置**：须已完成 W13 模型v1.0（据反馈迭代）+ 用户反馈。本周引入LLM作为分析引擎。

## 本周学习目标

- 能完成 1 个 LLM 分析实验（解读ML模型结果/LLM辅助特征探索/LLM从文档提取洞察，三选一），以实验报告呈现设计与相对传统方法的比较结论
- 能针对自己的场景说明 LLM vs 传统 ML 的适用边界与互补
- 能据 W13 用户反馈迭代出模型 v1.1

## 预计投入

课外 6-8h

## 教学内容
1. LLM作为分析引擎——解读规律/生成洞察/代码生成做分析
2. LLM vs 传统ML适用边界与互补
3. 据W13用户反馈进一步迭代模型
4. LLM分析实验设计与执行

## 项目活动

**必做**
1. 用LLM完成至少1个分析实验（解读ML模型结果/LLM辅助特征探索/LLM从文档提取洞察，三选一），撰写实验报告
2. 说明LLM分析 vs 传统ML建模的适用边界与互补（结合自己的实验，而非泛泛而谈）
3. 据用户反馈迭代模型至 v1.1

**进阶（可选）**
- 把 LLM 分析与 W8/W9 的解读/RAG 链路结合；用 Agent 自动化实验流程

**兜底**
- LLM 实验效果不佳：不理想同样是合格的实验报告——失败模式与边界的记录正是 W15 criterion validity claim 的最真实素材

## 交付物（评分锚点）
