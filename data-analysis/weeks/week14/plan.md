# Week 14 教学计划

## 主题
量化交易基础：从 SMA 到 ML 信号 + 策略回测评估

> **前置**：W11-W13 已学三种模型——线性回归、KNN、决策树/随机森林。本周把它们用到量化交易场景中：用模型预测涨跌生成买卖信号，用策略回测评估效果。SMA 策略回测（`Trading strategy evaluation - sma.ipynb`）是本周的起点——从规则型信号升级为 ML 型信号。

### 为什么本周学量化交易？

W11 你学了线性回归（train/test split），W12-W13 加了 KNN 和决策树/随机森林。但模型学了做什么用？最直接的金融应用就是**量化交易**——用模型预测涨跌，生成买卖信号，用回测检验到底赚不赚钱。

本周你先从最简单的规则型信号开始：SMA 均线交叉——"均线交叉能赚钱吗？"答案是：参数调好了在训练集上能赚，但样本外未必。然后你升级为 ML 型信号：

- 用随机森林预测"明天涨不涨"→ 生成买卖信号
- 用线性回归预测收益率 → 仓位大小
- 用 KNN 找相似交易日 → 辅助判断

这就是 ML 信号生成——不是"哪个模型最好就用哪个"，而是把模型的预测能力转化为交易决策，再用回测检验到底赚不赚钱。

## 本周学习目标

- 能说明量化交易的基本流程：数据→信号生成→回测→评估
- 能用 ≥1 种已学模型（线性回归/KNN/决策树·随机森林）从金融数据生成交易信号
- 能用策略回测评估信号质量（收益、夏普比率、最大回撤），并与 SMA 基线对比
- 能说明多模型融合的思路（投票/加权）及其相比单一模型的优势

## 预计投入

课堂 3×45 分钟。课外 6-8h

## 教学内容
1. 量化交易基础：数据→信号生成→回测→评估的完整流程；SMA 策略回测入门（`Trading strategy evaluation - sma.ipynb`）
2. ML 信号生成：用 RF/KNN/线性回归预测涨跌方向→生成买卖信号
3. 多模型融合思路：投票法（多数表决）、加权法（按模型表现分配权重）
4. 策略回测评估：收益曲线、夏普比率、最大回撤、胜率；训练集 vs 测试集（W11 train/test split 的复用）
5. 参考 `Stock Market One-Day Ahead Movement Prediction Using Disparate Data Sources.pdf`：学术研究如何用多源数据做股价方向预测

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：`Trading strategy evaluation - sma.ipynb` 已跑通；ML 信号 Notebook 已跑通（RF 预测涨跌→信号→回测）。

**第1节 · 从 SMA 到 ML 信号（45 分钟）**

1. **分享上周 journal + 接 W13（5 分钟）**：随机邀请同学分享上周 journal（3 问：补上了哪个缺口 / 哪个判断不稳 / 下周先解哪个卡点）。本周把 W11-W13 学的三种模型用到量化交易中。
2. **SMA 策略回测入门（15 分钟）**：用 `Trading strategy evaluation - sma.ipynb` 演示——SMA 信号生成→策略收益 vs 买入持有→参数网格搜索→样本外测试。点破：SMA 是规则型信号（均线交叉），本周升级为 ML 型信号（模型预测涨跌→生成信号）。
3. **ML 信号生成演示（20 分钟）**：用上证指数数据→构造特征（技术指标/收益率/波动率）→用随机森林预测"明天涨不涨"→预测结果转为买卖信号（预测涨→买入，预测跌→空仓）→回测。对比 SMA 基线：ML 信号比均线信号好多少？
4. **多模型融合思路引入（5 分钟）**：一个模型的信号不够稳——投票法（RF + KNN + 线性回归三个预测涨跌，多数表决）、加权法（按各自准确率分配权重）。一句话：融合不是为了用更多模型，是为了降低单一模型的盲区。本周先理解思路，下周 W15 实践。

**第2节 · 策略回测评估（45 分钟）**

5. **回测评估指标（15 分钟）**：收益曲线（策略 vs 买入持有）、夏普比率（风险调整后收益）、最大回撤（最惨的时候亏多少）、胜率（涨跌预测准确率）。每个指标一句话解释含义。
6. **训练集 vs 测试集（15 分钟）**：W11 的 train/test split 在量化交易中的直接应用——参数/模型在训练集上调好，必须在没见过的测试集上验证。过拟合在交易中意味着"回测很赚钱，实盘很亏钱"。
7. **教师演示完整流程（15 分钟）**：数据→特征构造→RF 预测→信号生成→回测→评估指标→与 SMA 基线对比。一步到位走完，学生照着改自己的数据。

**第3节 · 学生实践 + 收束（45 分钟）**

8. **学生做 ML 信号 + 回测（30 分钟）**：用自己的项目数据或课堂数据，用 ≥1 种模型生成交易信号并回测。分步检查点：
   - [ ] 数据加载成功，特征已构造
   - [ ] ≥1 种模型预测涨跌并生成信号
   - [ ] 回测跑通，有收益曲线和评估指标
   - [ ] 与 SMA 基线或买入持有对比了
   - [ ] 能一句话说清"ML 信号比 SMA 好在哪/差在哪"
   跑通的学生尝试用第二个模型生成信号，对比两个模型的效果（为下周融合做准备）。
9. **收束（15 分钟）**：当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。本周回顾：W11-W13 学的三种模型，本周用到量化交易中——ML 做预测，信号做交易，回测做验证。下周 W15：多模型信号融合 + 路演准备。
