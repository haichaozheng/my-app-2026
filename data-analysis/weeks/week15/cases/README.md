# Week15 案例：多模型信号融合 Capstone——三个模型投票，比一个准吗？

> **课程整合案例**。本案例是 W11→W14 故事线的终点：把三种模型各自的预测信号融合起来，回测看融合是否比单一模型更稳。本目录完全自包含，自带数据与脚本。

## 案例问题

> **三个模型投票，比一个模型准吗？能赚更多钱吗？**

W11 学了线性回归，W12 学了 KNN，W13 学了决策树/随机森林。W14 把随机森林单独拿来做交易信号。本周把三个模型的信号**融合**——投票法（多数表决）和加权法（按准确率分配权重）——回测对比单一模型，看融合是否更鲁棒。

## 五策略对比设计

| 策略 | 信号来源 | 类型 |
|---|---|---|
| 买入持有 | 一直满仓 | 基准 |
| SMA 交叉 | ma_5 > ma_20 | 规则型基线 |
| 单一 RF | 随机森林预测 | 单一 ML（W14 复用） |
| **投票融合** | 逻辑回归 + KNN + RF 多数表决 | **融合（等权）** |
| **加权融合** | 三模型按测试准确率加权 | **融合（加权）** |

## 两种融合方法

### 投票法（等权多数表决）

```python
# 三个模型各自预测涨(1)/跌(0)，取多数
vote = signal_lr + signal_knn + signal_rf
fused_signal = (vote >= 2).astype(int)  # ≥2 票 → 持仓
```

直觉：三个模型里有两个说"涨"就买。简单、无参数，但忽略了模型间强弱差异。

### 加权法（按准确率分配权重）

```python
# 按各自测试集准确率分配权重
weights = [acc_lr, acc_knn, acc_rf]  # 谁准谁权重大
weighted_vote = w_lr * signal_lr + w_knn * signal_knn + w_rf * signal_rf
fused_signal = (weighted_vote >= 0.5 * sum(weights)).astype(int)
```

直觉：更准的模型话语权更大。比投票法多一步——先用测试集算准确率，再定权重。

## 教学要点

- **融合不是为了用更多模型，是为了降低单一模型的盲区**：RF 可能在趋势行情中表现好，KNN 在震荡行情中表现好，融合后两种行情都不太差
- **投票法 vs 加权法**：投票简单但忽略强弱，加权稍复杂但更合理——工程上先跑投票看有没有提升，再试加权
- **融合不一定更好**：如果三个模型都基于同一份特征、同一份数据，它们可能犯了同样的错——融合救不了。真正有效的融合需要多源信息（如价格 + 文本 + 宏观）
- **回测仍是试金石**：不管模型多复杂，最终看回测指标——夏普、回撤、胜率
- **capstone 闭环**：W11 的 train/test split → W12 的特征工程 → W13 的模型选择 → W14 的信号 + 回测 → W15 的融合——一条完整路径
