# Week 15 教学计划

## 主题
模型评估与建模产品化（必做）

> **前置**：须已完成 W14 模型v1.0（据反馈迭代）与 W13 LLM 对照实验。本周聚焦评估与产品化；路演叙事与完整材料制作移至 W16 课堂完成，本周只交 PPT 大纲与 Demo 脚本。

## 本周学习目标

- 能报告评估指标（MSE/R²/准确率/F1/混淆矩阵）并解释指标含义、交叉验证的作用与偏差-方差权衡
- 能写出 ≥1 条 criterion validity claim：产品效能与一个明确参考实体（基线模型/手动分析/既有工具/空RAG模块）比较，说清"赢在哪、怎么知道的"
- 能把模型嵌入产品（训练→推理→展示），准备 10-20 条 evals 回归测试并写入 repo，撰写使用文档
- 能依据用户反馈与设计原则完成 UX 优化

## 预计投入

课堂 3×45 分钟。课外 10-12h（DSR 严谨性落点周；路演内容已移至 W16 课上）

## 教学内容
1. 评估指标深入（MSE/R²/准确率/F1/混淆矩阵）、交叉验证、偏差-方差权衡
2. 设计科学有效性（白话版）：criterion validity claim = 产品效能 vs 明确参考实体的比较——参考实体首选复用 W14 多模型对比中的基线模型结果（也可用手动分析/既有工具/空RAG模块）；课上给 2 个示例；论文轨可选加 causal/context validity
3. 把模型嵌入产品（训练→推理→展示架构）；进阶可选：Agent自动化/Skill封装/AB测试/深度评估
4. evals回归测试：10-20条"问题—预期答案"写入repo（AI功能的反馈回路）
5. UX优化

## 课堂演示工具

| 环节 | 工具 | 用法 |
|---|---|---|
| 概念 | 薄幻灯 | 指标含义、criterion validity 两个示例（白话） |
| 现场主演示 | Trae + Streamlit | 训练→推理→产品展示；打开 repo 里 evals 示范 3 条「问题—预期答案」 |
| 辅 | Jupyter | 需展开混淆矩阵 / 偏差-方差图时用，不替代产品嵌入 |
| 路演 | 不在本周做完整 PPT | 只讲大纲与 Demo 脚本长什么样 |

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：criterion validity 两个白话示例；产品内「训练→推理→展示」可演示；evals 文件 3 条样例。

**第1节 · 评估与有效性（45 分钟）**

1. **指标含义（20 分钟）**：MSE/R² 或准确率/F1/混淆矩阵（按回归/分类分头）；交叉验证与偏差-方差各用一句人话。
2. **criterion validity（25 分钟）**：产品 vs 明确参考实体；两例（其一复用 W14 基线）。模型不占优也可 vs 手动分析。

**第2节 · 嵌入产品（45 分钟）**

3. **训练→推理→展示（20 分钟）**：Trae + Streamlit 走一遍，不用 Jupyter 代替产品。
4. **evals（15 分钟）**：打开 repo 示范 3 条「问题—预期答案」；要求本周写到 10–20 条。
5. **UX 据反馈改一点（10 分钟）**：只改用户已经抱怨的，不新开功能。

**第3节 · 文档与路演预备（45 分钟）**

6. **使用文档骨架（15 分钟）**：谁用、怎么打开、模型边界、Key 配置。
7. **路演大纲长什么样（15 分钟）**：问题→方案→产品→价值；Demo 脚本只写核心 3 步。完整 PPT 留 W16 课上。
8. **学生开工（15 分钟）**：嵌入或写 claim 草稿。收束：周末 Launch 阶段 DSR 自检。本周无技能小练。

## 项目活动

**必做**
1. 评估模型（指标+交叉验证+偏差-方差），完成 ≥1 条 criterion validity claim
2. 将模型嵌入产品，撰写使用文档
3. 准备 evals 回归测试并写入 repo
4. 据 W14 反馈完成产品 v1.1 打磨（含 UX）
5. 写路演 PPT 大纲 + Demo 脚本（只到大纲与脚本；完整材料 W16 课上制作）
6. 本周末做阶段回顾(15min)，产出含DSR自检(Launch阶段)与有效性claim草稿的阶段反思

**进阶（可选）**
7. Agent 自动化/Skill 封装/AB 测试；消融实验（causal validity）

**兜底**
- 模型效果不理想：criterion claim 可改与"手动分析基线"比较——模型不占优也能说明产品的价值环节在哪
