# Week 15 教学计划

## 主题
多模型信号融合 + 路演准备

> **前置**：W14 已学量化交易基础（SMA→ML 信号 + 策略回测评估）。本周前半做多模型信号融合实践，后半开始准备路演。W16 全员公开路演。

### 为什么本周要留时间准备路演？

W11-W14 你学了三种模型（线性回归/KNN/决策树·随机森林），并把它用到量化交易中。但你的产品和分析能力，最终要**讲给别人听**——投资者、用户、评委。一个好产品讲不好，等于没做。

本周用一节课完成多模型信号融合（W14 已学思路，本周实践），剩下两节课全部用于路演准备：故事线设计、PPT 大纲、Demo 脚本。W16 课上制作完整 PPT 并彩排，本周只到大纲与脚本。

## 本周学习目标

- 能用 ≥2 种已学模型（线性回归/KNN/决策树·随机森林）从金融数据生成交易信号，并尝试融合多个模型的信号
- 能说明多模型融合的思路（投票/加权/分层）及其相比单一模型的优势
- 能按"问题→方案→产品(含模型)→价值"故事线，写出路演 PPT 大纲与 Demo 脚本
- 能把 Demo 聚焦核心价值环节而非功能罗列

## 预计投入

课堂 3×45 分钟。课外 4-6h（路演大纲与脚本课后完善）

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：多模型信号 Notebook 已跑通（RF+KNN+线性回归投票融合→回测）；教师示范路演 ≤8 页备好。

**第1节 · 多模型信号融合 + 课程总结（45 分钟）**

1. **多模型信号融合实践（25 分钟）**：
   - **演示（10 分钟）**：用上证指数数据→RF + KNN + 线性回归三个模型各自预测涨跌→投票法融合（多数表决）→回测→对比单一模型。看融合是否比单一模型更稳（夏普比率更高、最大回撤更小）。
   - **学生实践（15 分钟）**：用自己的项目数据或课堂数据，用 ≥2 种模型生成信号并融合。分步检查点：
     - [ ] ≥2 种模型预测涨跌并生成信号
     - [ ] 融合信号跑通（投票法或加权法）
     - [ ] 回测有评估指标，和单一模型对比了
   跑通的学生尝试加权法（按各自准确率分配权重）或加入 LLM 情感信号。
2. **课程总结（20 分钟）**：回顾 W11-W15 完整路径：
   - W11：线性回归（train/test split 的引入）
   - W12：KNN + 特征工程
   - W13：决策树 / 随机森林
   - W14：量化交易基础（ML 信号 + 策略回测评估）
   - W15：多模型融合 + 路演准备
   一句话串：三种模型各有视角（线性/邻居/规则），融合起来更鲁棒。你的产品用了哪种/哪几种？路演时要讲清楚。

**第2节 · 路演叙事 + PPT 大纲（45 分钟）**

3. **路演叙事方法论（15 分钟）**：故事线"问题→方案→产品(含模型)→价值"。技术与管理双受众各听懂一句。Demo 设计原则：只打核心价值环节，不念功能清单。教师示范路演 ≤8 页。
4. **学生写 PPT 大纲（30 分钟）**：每人写出路演 PPT 大纲（≤8 页），每页一个核心信息。分步检查点：
   - [ ] 第 1 页：问题是什么（一句话讲清痛点）
   - [ ] 第 2 页：方案思路（你怎么解决的）
   - [ ] 第 3-5 页：产品核心功能 + 模型（Demo 聚焦环节）
   - [ ] 第 6 页：价值与数据（效果、用户反馈、评估指标）
   - [ ] 第 7-8 页：下一步 / 总结
   教师巡场，帮学生把"问题"写准——路演最怕开头没讲清痛点。

**第3节 · Demo 脚本 + 互助审稿 + 收束（45 分钟）**

5. **Demo 脚本设计（20 分钟）**：写出 Demo 脚本——路演时打开产品哪几个页面、点哪个按钮、说什么话。分步检查点：
   - [ ] Demo 路径 ≤3 步（从打开到核心价值展示）
   - [ ] 每步配一句话解说
   - [ ] 有兜底方案（现场打不开怎么办→录屏）
6. **互助组审稿（15 分钟）**：组内互看 PPT 大纲 + Demo 脚本，给 ≥2 条反馈：故事线清不清？Demo 聚焦不聚焦？时间够不够（路演每人 5-8 分钟）？
7. **收束（10 分钟）**：当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。本周回顾：多模型融合实践完成；路演大纲与 Demo 脚本就绪。下周 W16 路演：把你的产品和模型讲给观众听。W16 课上制作完整 PPT 并彩排，本周大纲与脚本是基础。

## 项目活动

**必做**
1. 多模型信号融合实践：用 ≥2 种模型生成交易信号，尝试融合并回测
2. 路演 PPT 大纲（≤8 页，每页一个核心信息）
3. Demo 脚本（Demo 路径 ≤3 步，每步配解说，有兜底方案）

**进阶（可选）**
- 加权法融合（按模型准确率分配权重），对比投票法
- 加入 LLM 情感信号（新闻/公告解读）作为辅助信号
- 路演大纲含数据支撑（评估指标、用户反馈引用）

**兜底**
- 数据不适合做交易信号（如非股价类项目）：用课堂数据完成融合练习，路演中说明"我的项目数据不适合做交易信号，但理解了多模型融合的思路"
- 路演大纲写不出来：先写一句话"我的产品解决什么问题"，再展开
