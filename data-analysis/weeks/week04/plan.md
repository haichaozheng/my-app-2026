# Week 04 教学计划

## 主题

手动流程先行 + 项目数据获取与落盘 + 批判性思维与判断

> **前置**：第 2 节用户需求分析课堂上没讲，改到 W5 第 1 节。第 3 节不按提案取数，改为一份独立的 API 练习：自选 1 家上市公司，用 tushare 取数。

## 本周学习目标

- 能编写数据获取脚本（API 或网页采集），正确处理限流/复权/对齐并落盘为项目数据集，说明数据源与落盘格式的选择理由
- 能在已落盘数据上用 Excel/纸笔手动完成一次从数据到洞察的完整分析，产出数据流图、计算公式与假设清单
- 能对 ≥1 个关键洞察做偏误自检，或对 AI 辅助生成的分析结果做可信度判断

## 预计投入

课堂 3×45 分钟。课外 12-15h —— 全课程工程时间最长的一周（限流、复权、反爬耗时波动大），建议与其他课程作业提前错峰

## 教学内容

1. 项目数据获取与落盘（复用W2金融数据生态知识：AKShare/Tushare获取、限流与复权处理、落盘CSV/DuckDB）
2. 网页数据采集（requests + BeautifulSoup静态页面、crawl4ai动态页面与LLM友好输出、爬虫伦理与合规：robots.txt/频率限制/法律边界/财经场景特殊注意）
3. Minimalist Entrepreneur先建手动流程理念
4. 数据分析思维链
5. 批判性思维与判断（偏误自检、AI输出判断、决策框架）
6. 用AI辅助编程加速数据获取脚本编写

> 本周只要求"拿到数据 + 手动跑通逻辑"；"手动流程转化为代码"移入 W5，与清洗代码一并完成。

## 教学步骤

**第1节 · 应用API获取财经数据**

要用 Jupyter，就选 W3 建好的项目虚拟环境。建议在这个环境里安装 `ipykernel`：Cursor 里选中 `.venv` 之后，单元格才能把代码交给这个 Python 执行。没装进 `.venv` 时，笔记本打得开，单元格跑不了，或跑到系统 Python / Anaconda `base` 上。

1. **开场·先安心态（约 3 分钟）**：本周是全课程工程时间最长的一周，限流、复权、反爬都可能卡人。任何人多少都有焦虑和压力，不否认它。办法是用价值观与人生观来引导自己：想清楚这门课与这个项目对自己意味着什么，从意义里长出无视困难的勇气；注意力放回「下一步具体做什么」，焦虑就不再困扰自己。点到即止，进入技术环节。
2. **激活** `.venv`：在项目根目录打开终端。Windows PowerShell：`.\.venv\Scripts\activate`。Mac：`source .venv/bin/activate`。提示符前出现 `(.venv)` 再往下做。
3. **安装** `ipykernel`：在已经出现 `(.venv)` 的终端里执行 `python -m pip install ipykernel`。装完可再执行一次 `python -m pip freeze > requirements.txt`。
4. **选解释器再跑一格**：Cursor 里 `Ctrl+Shift+P` → **Python: Select Interpreter** → 选路径中有 `.venv` 的那一个。打开 `weeks/week04/structured_data.ipynb`，单元格运行 `import sys; print(sys.executable)`，输出路径里应有 `.venv`。对上即停。

内核确认后，按该笔记本的教学内容往下做：

- How to build a career in AI
- 初步认识并应用 pandas
- 使用 tushare 获取股票行情数据
- 应用 concurrent.futures 做并发操作

**第2节 · 用户需求分析**：课堂上没讲。整节改到 W5 教学步骤的第 1 节。

**第3节 · 动手感受 API 获取数据（45 分钟）**

**提交截止：2026年10月16日晚上8点。** 布置和收束都要说一遍。

1. **布置作业（8 分钟）**：先写明截止时间：**2026年10月16日晚上8点**。自由选 1 家感兴趣的上市公司；针对这家公司提 1 个问题；用 tushare 取与该公司相关的数据（不限于行情、财务，宏观、新闻也可以）；用采到的数据试着回答这个问题。笔记本交四部分：公司名称与基本简介、研究问题及其内涵、数据采集、数据分析与问题解答。
2. **当堂开工（30 分钟）**：在第 1 节已选中 `.venv` 的笔记本里写下公司名和那一个问题，并成功拉下至少一张表。tushare 密钥已由教师写进课堂 Jupyter，本节不用 `.env`，也不要再装 `python-dotenv`。拉不通的记下报错，课后补。
3. **收束（7 分钟）**：课上交不出完整分析。课后把四部分补全，**2026年10月16日晚上8点**前提交。当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。
