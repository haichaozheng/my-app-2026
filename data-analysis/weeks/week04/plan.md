# Week 04 教学计划

## 主题
手动流程先行 + 批判性思维与判断 + Coding Agent上机实验（Skill与Agent开发）

## 教学内容
1. Minimalist Entrepreneur先建手动流程理念
2. 数据分析思维
3. 批判性思维与判断（偏误自检、AI输出判断、决策框架）
4. **Coding Agent上机实验：Skill与Agent开发**——教师演示构建一个完整Skill，学生跟随复现（基于各自手动验证的分析流程）

## 项目活动
1. 基于Week03批准的项目提案，选定一个分析任务
2. 用Excel/纸笔手动完成一次完整分析流程，验证逻辑正确性
3. 记录手动过程中发现的边界问题和业务逻辑假设
4. 用opencode将手动流程转化为代码（AI辅助编程加速），验证结果与手动一致
5. 上机实验中跟随教师演示，复现一个完整Skill的构建，适配到自己的分析流程

## 交付物
- 个人手动分析报告（含数据流图、计算公式、边界条件、假设清单）
- 手动→自动转化代码（附验证结果对比）
- 复现的Skill（跟随教师演示完成，适配自己的分析流程）

## 课后作业
1. 完成手动分析报告
2. 反思分析过程中的判断与偏误
3. 调试完善复现的Skill，确保可运行
