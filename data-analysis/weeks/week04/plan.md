# Week 04 教学计划

## 主题
手动流程先行 + 项目数据获取与落盘 + 批判性思维与判断

> **前置**：须已获 Week03 批准的提案，本周为提案项目获取并落盘数据。

## 本周学习目标

- 能编写数据获取脚本（API 或网页采集），正确处理限流/复权/对齐并落盘为项目数据集，说明数据源与落盘格式的选择理由
- 能在已落盘数据上用 Excel/纸笔手动完成一次从数据到洞察的完整分析，产出数据流图、计算公式与假设清单
- 能对 ≥1 个关键洞察做偏误自检，或对 AI 辅助生成的分析结果做可信度判断

## 预计投入

课堂 3×45 分钟。课外 12-15h —— 全课程工程时间最长的一周（限流、复权、反爬耗时波动大），建议与其他课程作业提前错峰

## 教学内容
1. 项目数据获取与落盘（复用W2金融数据生态知识：AKShare/Tushare获取、限流与复权处理、落盘CSV/DuckDB）
2. 网页数据采集（requests + BeautifulSoup静态页面、crawl4ai动态页面与LLM友好输出、爬虫伦理与合规：robots.txt/频率限制/法律边界/财经场景特殊注意）
3. Minimalist Entrepreneur先建手动流程理念
4. 数据分析思维链
5. 批判性思维与判断（偏误自检、AI输出判断、决策框架）
6. 用AI辅助编程加速数据获取脚本编写

> 本周只要求"拿到数据 + 手动跑通逻辑"；"手动流程转化为代码"移入 W5，与清洗代码一并完成。

## 课堂演示工具

| 环节 | 工具 | 用法 |
|---|---|---|
| 概念 | 薄幻灯（≤8页） | 手动流程先行、爬虫合规红线 |
| 思维链主演示 | Excel（或纸笔投影） | 用已落盘小表手动走完「数据→洞察」，写出公式与假设清单 |
| 工程主演示 | Trae | API / requests 获取、限流与落盘；课前备好可回退脚本 |
| 辅 | Jupyter | 只打开「下一步会变成代码」的骨架，不在本周写完转化 |

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：已落盘的课堂小表（Excel）；可回退的获取脚本；合规自检清单。提醒本周课外 12–15h，课上只把「拿到数据 + 手动跑通」做会。

**第1节 · 先拿到数据（45 分钟）**

1. **本周边界（5 分钟）**：只要求落盘 + 手动逻辑；转化代码留 W5。
2. **合规红线（10 分钟）**：robots.txt、频率、财经场景注意；网页采集者必须先填自检清单。
3. **获取脚本演示（30 分钟）**：Trae 演示 API 或 requests：限流、对齐、落盘 CSV；超时切回退脚本。学生看自己提案该走哪条源。

**第2节 · 手动跑通逻辑（45 分钟）**

4. **为何先手动（8 分钟）**：薄幻灯点「先建手动流程」；不讲转化。
5. **Excel/纸笔走一遍（25 分钟）**：教师用小表从数据到洞察，当场写公式、边界、假设清单。
6. **偏误与 AI 判断（12 分钟）**：对刚才 1 个洞察做偏误自检，或对一段 AI 结论问「信不信、凭什么」。

**第3节 · 开做（45 分钟）**

7. **学生开工（30 分钟）**：有源的写获取脚本；源未通的先用课堂小表完成手动分析骨架。教师巡视限流/反爬。
8. **骨架预告（8 分钟）**：可选打开 Jupyter 空骨架「W5 会变成代码」，不写完。
9. **收束（7 分钟）**：周五前报备换源；交付=数据集+手动报告。本周无技能小练。当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 即时学习 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。可把分析中的判断与偏误写入该条。

## 项目活动

**必做**
1. 基于Week03批准的项目提案，编写数据获取脚本（AKShare/Tushare/requests/crawl4ai），处理限流/复权/对齐，落盘为项目数据集（CSV/DuckDB/Markdown，含字段说明）
2. 若项目数据需要从网页采集（如贝壳房价、巨潮公告、财经新闻），使用requests或crawl4ai采集并落盘；采集前完成合规自检清单
3. 在已落盘数据上用Excel/纸笔手动完成一次完整分析流程，验证逻辑正确性
4. 记录手动过程中发现的边界问题和业务逻辑假设

**进阶（可选）**
- 量化/行情类项目：按数据频率设计复权与对齐方案，为后续回测与建模做准备

**兜底**
- 数据源彻底拉不到：改用 `project-selection-guide.md` §7 备选源，或收缩数据定义（换粒度/换市场），周五前在课程群报备调整，不让周中卡死
- 限流/反爬被封：降频 + 本地缓存断点续传；解决不了带报错走课程群

## 交付物（评分锚点）

- 项目数据集（获取脚本+落盘数据+字段说明；若含网页采集须附合规自检清单）
- 个人手动分析报告（含数据流图、计算公式、边界条件、假设清单）

—— 规格与知识锚定见 milestones §2.1；计入平时成绩（形成性）。提交前自检：数据源与落盘格式选择有理由（而非"调通即可"）？思维链每步"为什么/发现什么/下一步"写清了吗？≥1 个偏误自检或 AI 可信度判断？

## 卡住了找谁

卡住 → ①先问 AI（附报错与上下文截图）→ ②互助组（当日）→ ③课程群（教师承诺 24h 内响应）→ ④固定办公时间（1v1，时间见课程通知）。限流/封禁/采集受阻类问题直接走 ③。

## 课后任务
1. 完成项目数据集落盘并提交获取脚本
2. 完成手动分析报告
3. 把分析过程中的判断与偏误写入 `journal.md`（课堂上记即可，本周不单独交日志）
