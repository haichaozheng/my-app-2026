# Week 13 教学计划

## 主题
对照大模型与传统分析（适用边界 + 神经网络基础）

> **前置**：须已完成 W12 树模型与特征工程。对照对象是 W11-W12 的传统模型（回归/决策树/随机森林等），不依赖用户反馈收口。本周引入 LLM 作为分析引擎。

## 本周学习目标

- 能完成 1 个 LLM 分析实验（解读ML模型结果/LLM辅助特征探索/LLM从文档提取洞察，三选一），以实验报告呈现设计与相对传统方法的比较结论
- 能说清神经网络的基本结构（神经元/层/激活函数）与训练原理（W11 梯度下降的复用），并判断自己的项目是否适合引入神经网络
- 能针对自己的场景说明 LLM vs 传统 ML 的适用边界与互补

## 预计投入

课堂 3×45 分钟。课外 6-8h

## 教学内容
1. LLM作为分析引擎——解读规律/生成洞察/代码生成做分析
2. 神经网络基础串讲（课堂）：神经元→层→激活函数→用梯度下降训练（W11 梯度下降的复用）→ LLM 本质上是超大规模神经网络；为何在金融表格数据上神经网络往往不是首选（数据量、可解释性）
3. LLM vs 传统ML适用边界与互补
4. LLM分析实验设计与执行

## 课堂演示工具

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：同一小数据集上「W11–W12 模型结果」与「LLM 解读」两栏可并排打开。

**第1节 · 边界与神经网络（45 分钟）**

1. **本周不是再接一层聊天（5 分钟）**：对照对象是自己的回归/树模型；不依赖用户反馈收口。
2. **神经网络串讲（25 分钟）**：神经元→层→激活→梯度下降复用→LLM 是超大规模网络；金融表格为何往往不首选 NN。
3. **LLM vs 传统 ML（15 分钟）**：适用边界与互补，落到「你的数据形态」。

**第2节 · 对照实验（45 分钟）**

4. **三选一题干（10 分钟）**：解读 ML 结果 / LLM 辅助特征 / 从文档抽洞察。
5. **教师做完一个（25 分钟）**：左栏传统模型，右栏 LLM；当场写「谁在哪类任务上更合适」。
6. **失败也是结果（10 分钟）**：不理想记录可作 W15 criterion claim 素材。

**第3节 · 开做（45 分钟）**

7. **学生写实验设计（20 分钟）**：选哪一题、对照哪个 W11–W12 模型、成功哪句话。
8. **技能小练（15 分钟）**：`lab.md` 当堂起笔。
9. **收束（10 分钟）**：进阶 MLP 课外；不现场训大模型。反馈继续滚，W14 收口。当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 即时学习 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。

## 项目活动

**必做**
1. 用LLM完成至少1个分析实验（解读ML模型结果/LLM辅助特征探索/LLM从文档提取洞察，三选一），撰写实验报告
2. 说明LLM分析 vs 传统ML建模的适用边界与互补（结合自己的实验，对照 W11-W12 传统模型，而非泛泛而谈）

**进阶（可选）**
- 把 LLM 分析与 W8/W9 的解读/RAG 链路结合；用 Agent 自动化实验流程
- 用 sklearn MLP 在自己数据上试跑神经网络，与 W12 树模型/W11 回归对比——验证"表格数据上神经网络未必占优"的判断

**兜底**
- LLM 实验效果不佳：不理想同样是合格的实验报告——失败模式与边界的记录正是 W15 criterion validity claim 的最真实素材
