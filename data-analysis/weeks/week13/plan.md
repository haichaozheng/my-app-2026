# Week 13 教学计划

## 主题
决策树与随机森林

> **前置**：须已完成 W12 KNN + 特征工程。本周深入树模型，升级 W11-W12 的线性/KNN 基础模型。

## 本周学习目标

- 能说解决策树的分裂直觉（信息增益）与随机森林"集体投票更稳"的原理（bagging+随机特征）
- 能用决策树/随机森林升级或对比 W11-W12 模型，结合特征重要性完善特征
- 能对比已学三种模型（线性回归/KNN/决策树）的思路差异，并说明各自适用场景

## 预计投入

课堂 3×45 分钟。课外 6-8h

## 教学内容
1. 决策树（课堂讲授）：树的分裂直觉（信息增益/基尼系数）、过拟合倾向（树太深）、剪枝一句话带过——配套视频 12.1 课后回看
2. 随机森林（课堂讲授）：bagging + 随机特征 → 为何比单树稳、特征重要性如何反哺 W12 特征工程——配套视频 12.2 课后回看
3. 与 W11-W12 模型对比：线性回归学规律（fit 参数）、KNN 找邻居（不学习）、决策树学规则（if-else）——三种思路的差异与适用场景
4. 用决策树/随机森林升级或对比自己的项目模型

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：决策树/森林对照 Notebook 已跑通（含特征重要性图）。

**第1节 · 决策树（45 分钟）**

1. **分享上周 journal + 接 W12（5 分钟）**：随机邀请同学分享上周 journal（3 问：补上了哪个缺口 / 哪个判断不稳 / 下周先解哪个卡点）。本周深入树模型。
2. **决策树分裂直觉（20 分钟）**：Jupyter 看一次分裂过程——树是一连串 if-else 二分问题，每次分裂选信息增益最大的特征。用课堂数据演示：根节点怎么选特征、分裂后子节点怎么继续。
3. **决策树的过拟合倾向（10 分钟）**：树太深 → 记住噪声 → 训练分高测试分低。一句话提剪枝（`max_depth` 限制）。这和 W11 讨论的学习率/过拟合是同一个问题。
4. **学生跑决策树（10 分钟）**：用自己的数据或 `gdp_satisfaction.csv` 跑 `DecisionTreeClassifier`/`DecisionTreeRegressor`，看训练 vs 测试分数差距。

**第2节 · 随机森林（45 分钟）**

5. **随机森林 vs 单树（15 分钟）**：同一数据对比——单树容易过拟合，森林（多棵树投票/平均）更稳。bagging（有放回抽样）+ 随机特征（每次分裂只看部分特征）→ 为什么能降低过拟合。
6. **特征重要性（15 分钟）**：随机森林给出每个特征的重要性排名——直接反哺 W12 特征工程：重要性高的特征保留，低的考虑丢弃或重构。
7. **三种模型对比（10 分钟）**：一句话串三种思路——线性回归学规律（fit 参数，适合线性关系）、KNN 找邻居（不学习，适合小数据）、决策树学规则（if-else，适合非线性+可解释）。各自什么时候更好。
8. **学生跑随机森林（5 分钟）**：换 `RandomForestClassifier`，对比决策树的分数和特征重要性。

**第3节 · 独立实践 + 收束（45 分钟）**

9. **学生用树模型升级项目（25 分钟）**：用自己的数据跑决策树/随机森林，对比 W11-W12 模型。分步检查点：
   - [ ] 树模型跑通，训练/测试分数都有了
   - [ ] 特征重要性排名已记录
   - [ ] 能一句话说清"树模型比 W11/W12 模型好在哪/差在哪"
10. **技能小练（12 分钟）**：`lab.md` 当堂起笔。
11. **收束（8 分钟）**：当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。本周回顾：决策树学 if-else 规则，随机森林多树投票更稳，特征重要性反哺特征工程。下周 W14 量化交易基础：把模型用到交易信号生成与策略回测中。
