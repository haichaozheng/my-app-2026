# Week 08 技能小练 — 一条 Chain 的最小闭环

> 定位：本周里程碑（MVP v0.2 含 LLM 解读）的热身，约 30-45 分钟；计入平时成绩"技能小练"。
> Key 未就绪的先看 `weeks/week08/llm-key-guide.md`（免费额度自申 → 受阻用课程演示 Key）。

## 任务

用 LangChain 构建一条最小 Chain：

1. PromptTemplate 定义一个带两个变量的模板：`{data_summary}` + `{question}`，要求输出固定格式（如"结论/依据/不确定性"三段）
2. 输入你产品数据的一段真实摘要 + 一个问题，跑通并保存输出
3. **边界测试 2 次**：`data_summary` 给空字符串；给一段与财经无关的乱码——记录输出发生了什么（胡编？拒答？格式崩坏？）
4. 据此修改你的 Template（如加"若信息不足请直接说无法回答"），再跑一遍对比

## 提交

Chain 代码片段 + 两次边界测试的前后输出对比 + 你从对比中得出的 1 条设计结论。

## 自检（达标线）

- [ ] 输出格式约束真实生效过（对比第 3、4 步）
- [ ] 这一步的记录直接可用于 v0.2 交付物的"可信度评估"章节
