| 维度 | 现有课程 | 本课程 |

## 三、课程理念：Learn by Building

**整学期围绕一个金融 AI Agent 项目展开**，每周完成一个 milestone。

### 旗舰项目：FinAgent —— 个人金融研究助手

学生从头构建一个能完成以下任务的 AI Agent：

```
输入："分析贵州茅台最近一季度表现，对比五粮液，生成投资备忘录"
输出：自动抓取数据 → 计算指标 → 生成报告（图文并茂的 PDF/网页）
```

### 每周 Milestone 概览

| 周 | Milestone | 核心知识点 | 产出 |
|----|-----------|-----------|------|
| 1 | 热身：用 opencode 获取股价数据 | AI 编程基础、Prompt 工程 | 打印股票数据 |
| 2 | 工具：搭建数据获取管线 | webfetch / tushare / websearch | 可复用的数据获取器 |
| 3 | Skill：封装专业知识 | Skill 概念、SKILL.md 编写 | 自己的金融 data skill |
| 4 | 分析：价格分析与可视化 | pandas + matplotlib 基本功 | K 线图 + 技术指标图 |
| 5 | 分析：基本面数据接入 | 财报/宏观经济数据 API | 基本面分析模块 |
| 6 | 中期展示 | 项目进度演示 +  feedback | 可运行的 Agent 原型 |
| 7 | Agent 核心：任务编排 | opencode agent / function calling | Agent 能理解"帮我分析茅台" |
| 8 | Agent 增强：工具注册 | 自定义工具扩展 | Agent 能用自己写的工具 |
| 9 | 报告生成：Markdown → PDF/PPT | Markdown / Puppeteer / PPT 生成 | Agent 输出完整报告 |
| 10 | 产品化：Web 前端 | 简单的聊天 UI | 浏览器可用的 Agent |
| 11 | 打磨：错误处理 / 边界情况 | try-catch、retry、日志 | 生产级健壮性 |
| 12 | 终期展示 | Demo Day | 完整 FinAgent 产品 |

## 四、课程模块（12 周 × 2 课时）

### Phase 1：基础（第 1-3 周）—— "让 AI 帮你干活"

> 目标：学生能用 opencode 完成基础的金融数据任务

**第 1 课：AI 编程入门**
- opencode 是什么、怎么装、怎么用
- 第一次 Prompt 实战："帮我获取股票数据"
- 工具认知：read / write / bash / glob / grep
- 作业：用 opencode 获取任意 3 只股票近 30 日数据

**第 2 课：Skill 基础与应用**
- webfetch / websearch 详解
- Skill 概念：按需加载、节约上下文
- tushare skill 实战
- gstack 介绍
- 作业：创建自己的第一个 Skill（新闻抓取）

**第 3 课：Prompt 工程与 AI 协作**
- 好的 Prompt vs 坏的 Prompt
- 结构化 Prompt：角色 + 上下文 + 任务 + 格式
- 迭代式开发：如何让 AI 修正代码
- 作业：优化已有 Prompt，对比效果差异

### Phase 2：金融分析（第 4-6 周）—— "让 AI 懂金融"

> 目标：学生能用 opencode 完成完整的金融分析流水线

**第 4 课：金融数据处理**
- 股票日线 / 分钟线 / 基本面
- pandas 基础操作（AI 辅助）
- 数据清洗与存储
- 作业：构建一个"股票数据获取 Pipeline"

**第 5 课：技术分析与可视化**
- 均线 / MACD / RSI / 布林带
- matplotlib / plotly 可视化
- 作业：生成一份带图表的"个股技术分析报告"

**第 6 课：多标的分析 + 中期项目**
- 对比分析、相关性分析
- 组合分析
- **中期 Demo：FinAgent 原型演示**

### Phase 3：Agent 构建（第 7-10 周）—— "让 AI 自主工作"

> 目标：学生能构建一个能自主完成金融任务的 AI Agent

**第 7 课：Agent 核心概念**
- AI Agent 是什么：感知 → 思考 → 行动
- opencode 的 Agent 能力
- Function Calling 原理
- 作业：构建一个"命令行金融助手"

**第 8 课：工具链注册与扩展**
- 自定义工具：注册自己的 Python 函数
- 工具编排：多工具组合
- 作业：让 Agent 同时调用数据 + 分析 + 绘图工具

**第 9 课：报告生成与输出**
- 自动生成 Markdown 报告
- Markdown → PDF / PPT / HTML
- 作业：Agent 输出一份"完整股票研究报告"

**第 10 课：前端交互**
- 简单的 Web UI（gradio / streamlit）
- Agent 响应实时展示
- 作业：FinAgent Web 版

### Phase 4：打磨与展示（第 11-12 周）—— "让它可靠"

**第 11 课：生产化**
- 错误处理：API 限流 / 网络超时 / 数据缺失
- 日志与调试
- Prompt 优化技巧：few-shot、chain-of-thought
- 作业：完善 FinAgent 健壮性

**第 12 课：Demo Day**
- 5 分钟产品演示
- 代码展示 + 架构说明
- 同学互评 + 老师点评
- 最佳项目评选

## 五、考核方式

| 项目 | 权重 | 说明 |
|------|------|------|
| 每周作业 | 30% | 每周 1 个小任务，检验当周知识点 |
| 中期 Demo | 20% | 第 6 周 Agent 原型演示 |
| 期末项目 | 40% | FinAgent 完整产品 |
| 课堂参与 | 10% | 提问、互评、结对贡献 |

### 评分侧重：**工程产出 > 理论记忆**

- 不考概念背诵，**只考能跑出什么**
- 加分项：项目有真实用户 / GitHub Star / 功能超出 MVP

## 六、混合背景分层设计

每节课的任务分为三层：

| 层级 | 适合人群 | 任务示例 |
|------|---------|---------|
| 🌱 基础 | 编程新手 | 用 opencode 获取数据并打印 |
| 🌿 进阶 | 大部分学生 | 构建可复用的分析函数 |
| 🌲 挑战 | CS 背景 / 快手学生 | 封装成 Skill 并让 Agent 调用 |

## 八、风险点

| 风险 | 概率 | 缓解 |
|------|------|------|
| 学生基础差距大 | 高 | 分层任务 + 结对编程 |
| tushare API 不稳定 | 中 | 预备 fallback 数据源 |
| AI 生成代码学生学不到东西 | 中 | 强调理解每行代码在做什么 |
| 项目范围太大完不成 | 中 | 期中 checkpoint 砍范围 |
| opencode 功能变更 | 低 | 每学期初更新教学大纲 |
