## 场景

用户有一批股吧评论（中文金融文本），需要快速判断每条评论的情感倾向（正面/中性/负面），并生成整体摘要。

## 输入

- 评论数据文件（`.txt` 或 `.csv`），每行一条评论
- 示例数据：`sse_comments.txt`（上证指数股吧评论 401 条）

## 分析步骤

1. **读取数据**：加载数据文件，确认评论条数和格式
2. **逐条分析**：对每条评论判断情感倾向
   - **正面（1）**：看多、利好、买入推荐、乐观预期
   - **中性（0）**：陈述事实、询问信息、无明显情感
   - **负面（-1）**：看空、利空、抱怨、悲观预期
3. **识别难点**：注意反讽（"又要割韭菜了，真好"→负面）、网络用语（"yyds"→正面）、混合情感（取主导倾向）
4. **生成摘要**：
   - 情感分布（正面/中性/负面各占比）
   - 高频话题（被反复提及的关键词或主题）
   - 典型评论摘录（每类情感选 2-3 条代表）

## 输出格式

```
## 股评情感分析报告

### 概览
- 总评论数：N 条
- 正面：X 条（XX%）
- 中性：Y 条（XX%）
- 负面：Z 条（XX%）

### 高频话题
1. 话题A（出现 N 次）
2. 话题B（出现 N 次）
3. 话题C（出现 N 次）

### 典型评论
**正面**：
- "评论原文" — 理由
**负面**：
- "评论原文" — 理由

### 分析说明
[对整体情绪的解读，1-2 句话]
```

## 注意事项

- 金融评论常有反讽和隐喻，不能只看字面意思
- "利好"可能是反讽（"利好茅台"模因），需结合上下文判断
- 短评论（<5 字）如果情感不明显，标为中性
- 如果评论提及具体股票代码或公司名，在摘要中标注
