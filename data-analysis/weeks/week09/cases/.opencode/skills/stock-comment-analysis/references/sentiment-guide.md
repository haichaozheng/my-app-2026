# 金融评论情感判断参考指南

## 情感分类标准

| 标签 | 含义 | 典型特征 |
|---|---|---|
| 1（正面） | 看多、乐观 | 买入推荐、利好消息、上涨预期、积极情绪 |
| 0（中性） | 无明显倾向 | 陈述事实、询问信息、技术分析讨论 |
| -1（负面） | 看空、悲观 | 利空消息、下跌预期、抱怨、消极情绪 |

## 常见金融网络用语

| 用语 | 含义 | 情感倾向 |
|---|---|---|
| yyds | 永远的神（极度看好） | 正面 |
| 割韭菜 | 散户被套亏损 | 负面 |
| 满仓 | 全仓买入 | 视语境（乐观时正面，恐慌时负面） |
| 空仓 | 清仓卖出 | 视语境 |
| 涨停 | 达到涨幅上限 | 正面 |
| 跌停 | 达到跌幅上限 | 负面 |
| 抄底 | 低位买入 | 正面（但隐含之前下跌） |
| 跑路 | 撤离 | 负面 |
| 加仓 | 增加持仓 | 正面 |
| 减仓 | 减少持仓 | 偏负面 |

## 反讽识别

金融评论中反讽常见，不能只看字面：

| 评论字面 | 实际含义 | 正确标注 |
|---|---|---|
| "利好茅台" | 模因，讽刺什么都能被解读为利好 | 负面 |
| "又要割韭菜了，真好" | 反讽，实际是悲观 | 负面 |
| "稳了稳了" | 可能真稳，也可能讽刺暴跌后强行乐观 | 需结合上下文 |
| "感谢主力砸盘" | 反讽，实际不满 | 负面 |

## 混合情感处理

一条评论同时包含正面和负面信息时：
- 取**主导倾向**（篇幅更多或情感更强的部分）
- 如果正负势均力敌，标为中性
- 在理由中说明「同时提到 X（正面）和 Y（负面），主导倾向为 Z」
