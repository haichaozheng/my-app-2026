# Week 17 教学计划

## 主题
反思与展望

## 本周学习目标

- 能在最终报告中区分"做了什么"（经历）与"学到了什么"（知识），产出个人知识框架重构图（映射到 knowledge-map 节点）
- 能写全 DSR 定位：artifact 类型 + 知识贡献定位 + ≥1 条 criterion validity claim + 参考实体 + relevance/rigor 证据
- 能完成组内 360° 匿名互评与协作贡献记录（如实记录"谁帮了你"，供他人互评印证）

## 预计投入

课堂 3×45 分钟。课外 6-8h（最终报告为主要工作量）

## 教学内容
1. Founder's Playbook Scale阶段思维：产品的下一步（继续迭代/开源/参赛/创业）
2. 反思方法论与个人知识框架重构（课堂工作坊）
3. 期末360°互评实施流程与协作贡献记录规范

## 课堂演示工具

| 环节 | 工具 | 用法 |
|---|---|---|
| 概念与工作坊 | 薄幻灯 + 白板/共享文档 | 知识框架重构（映射 knowledge-map）；DSR 定位五要素 |
| 互评 | `templates/peer-review.md`（在线表单或打印） | 当堂完成 360°；不投影代码 |
| 辅 | 浏览器打开最终产品 / repo | 个别对照 `templates/final-report.md` 结构 |
| 不做 | 新工具、新库 | 本周只收口 |

## 教学步骤

每周 3 节课，每节 45 分钟（课间另计）。课前：knowledge-map 一页可投影；`final-report.md` 的 DSR 定位节打开；360° 互评表（在线或打印）按组发好。不上新工具。若 W16 路演未轮完，第1节先续讲再进入工作坊。

**第1节 · 下一步与重构（45 分钟）**

1. **Scale 一问（10 分钟）**：继续迭代 / 开源 / 参赛 / 创业，每人选一个并写一句理由。
2. **经历 vs 知识（10 分钟）**：最终报告禁止只写「做了什么」。
3. **知识框架工作坊（25 分钟）**：对照 knowledge-map 勾自己真正用过的节点，画一张重构草图。

**第2节 · DSR 定位（45 分钟）**

4. **五要素（15 分钟）**：artifact 类型、知识贡献定位、≥1 条 criterion claim、参考实体、relevance/rigor 证据。
5. **对照模板写草稿（25 分钟）**：打开 `templates/final-report.md` 当堂填 DSR 节骨架。
6. **论文轨一句（5 分钟）**：causal/context 与 Level 2 仅进阶，不占全班时间。

**第3节 · 互评与收口（45 分钟）**

7. **360° 匿名互评（25 分钟）**：组内填写；如实写「谁帮了你」。
8. **仓库与链接（10 分钟）**：repo + 产品地址；已下线则附 Demo 视频。
9. **收束（10 分钟）**：报告截止与自检五问。本周无技能小练、不投影代码。当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。提醒：本周提交截至今日的 `journal.md` 全文作为作业（与期末报告分开交）。

## 项目活动

**必做**
1. 撰写个人项目最终报告（`templates/final-report.md`，含必做的"DSR 定位"节）
2. 整理个人产品 repo，给出可公开访问链接（repo + 产品地址；产品已下线则附 Demo 视频）
3. 课堂完成对组内其他成员的 360° 匿名互评
4. 提交个人仓库 `journal.md`（截至本周的全文，作为作业；DSR 全程定位写在期末报告，不另开反思文件）

**进阶（可选）**
- 论文轨：完整有效性论证（causal/context validity），把 RAG 流水线/特征方案抽象为 method/model，冲 Level 2 定位

**兜底**
- 产品未完整上线：报告说明原因 + repo + 本地演示视频仍构成完整评估证据（功能完整度按实际完成度计分，不额外惩罚）

## 交付物（评分锚点）

- 个人项目最终报告 —— milestones §4.2；计入个人项目（报告，占个人项目40%）
- 个人产品仓库链接
- 360° 互评表（`templates/peer-review.md`）—— 计入协作互评（满分10分，属平时成绩，期末评定）

—— 提交前自检：知识框架图映射到 knowledge-map 节点了吗？区分"经历"与"知识"了吗？DSR 定位五要素齐了吗？Scale 下一步有思考吗？

## 卡住了找谁

卡住 → ①先问 AI（附报错与上下文截图）→ ②互助组（当日）→ ③课程群（教师承诺 24h 内响应）→ ④固定办公时间（1v1，时间见课程通知）。报告写作拿不准的优先约办公时间。
