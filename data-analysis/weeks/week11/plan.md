### 为什么本周开始学建模？

你的产品已经上线，用户能打开看到可视化和大模型解读。但用着用着，用户会问：

- "这只股票明天会涨吗？"
- "我的组合下周预期收益多少？"
- "这只债券会不会违约？"

你的产品答不了——因为它只会**描述过去**，不会**预测未来**。从"看数据"到"用数据做预测"，就是机器学习的入口。本周给你产品的第一个预测能力：从你自己的项目数据出发，建一个回归或分类模型。不是学完理论再找数据练，而是**你的产品需要它，所以学它**。

## 本周学习目标

- **能说明自己的产品为什么需要建模**——用户问了什么预测类问题、产品目前答不了、建模能补上什么缺口
- **能说明大模型能预测为什么还要学传统 ML**——垂直领域数值型预测，基于数据建模往往更好；传统 ML 从你的数据中训练规律，大模型没见过你的数据；两者各有分工，产品最终结合
- 能用简单例子说明训练/测试划分的必要性——"用全部数据训练的模型，遇到新数据可能就崩了"
- 能针对自己的问题说明为什么选回归/分类、特征从哪来
- 能用梯度下降的可视化（学习率太大发散、太小收敛慢）解释模型如何从数据中学习
- 能用 `gdp_satisfaction.csv` 跑通线性回归完整流程（sklearn + 手写 SGD），并说明 `fit` 到底做了什么
- 能对第一个基础模型做初步评估与过拟合自检

## 教学内容

1. **训练/测试划分的直觉**：为什么不拿全部数据训练？——用 `gdp_satisfaction.csv` 演示：全量 fit 看似 R² 不错，划出测试集后测试分往往更低；模型可能"记住"了训练数据而非"学会"了规律。一句话：参数在训练集上学好，必须在没见过的测试集上验证（对应 notebook：`machine learning for stock prediction.ipynb` §train/test split）
2. **预测任务与 ML 范式**：垃圾邮件分类、情感分析、股价方向预测→分类/回归；监督/无监督/强化学习；生成模型 vs 判别模型（对应 notebook：`machine learning for stock prediction.ipynb` §prediction tasks + §what is ML）
3. **梯度下降**：模型如何从数据中"学习"——用 f(x)=x² 可视化演示学习率过大发散、过小收敛慢；batch/SGD/mini-batch 一句话带过（对应 notebook §gradient descent）
4. **线性回归**：`gdp_satisfaction.csv`（GDP 与生活满意度）→ 散点图 → sklearn `LinearRegression` → 画回归线 → 看系数；闭式解一句话提（`least squares.docx` 课后参考）；**手写 SGD 填空**：notebook 中 `gd()` 函数体为空，学生填写梯度更新公式（`code.docx` 有答案）
5. **接到自己的数据**：三步改法——改数据路径 / 选目标列 / 选特征列

**第1节 · 从产品到预测（45 分钟）**

1. **知识缺口：你的产品缺什么（8 分钟）**：打开一个已上线的学生产品，现场问全班："如果你是用户，用了一周后会想问什么？"引导到预测类问题——"明天涨不涨""收益预期多少""会不会违约"。教师点破：你的产品目前只会**描述过去**（可视化 + LLM 解读），答不了**预测未来**的问题。这个缺口就是本周开始填的——机器学习。
2. **大模型能预测，为什么还要学传统 ML？（8 分钟）**：学生一定会问——"我 W8/W9 已经用大模型做情感分析了，预测涨跌不也能问大模型吗？"教师正面回答：大模型确实能做判断，但对于**垂直领域的数值型预测**，基于数据建模往往更好。原因：①**大模型没见过你的数据**——它是通用模型，预训练时没学过你的基金净值、个股特征、用户行为日志；传统 ML 直接从你的数据中**训练**出规律（fit 的过程），模型学会了你数据里的模式；②**可量化**——回归模型给出具体数值（预期收益率 2.3%），不是"大概会涨"；③**可复现**——同一模型同一数据结果一致，大模型每次回答可能不同；④**成本极低**——sklearn 在本地毫秒级跑完，不花一分钱 API 费用。收束："大模型擅长理解和生成文本，传统 ML 擅长从你的结构化数据中做数值预测。**不是二选一，是各有分工**——你的产品最终会两者结合：ML 做预测，LLM 做解读。"
3. **预测任务与 ML 范式（15 分钟）**：用 `machine learning for stock prediction.ipynb` §prediction tasks + §what is ML。三类预测任务举例：垃圾邮件分类（文本→分类）、情感分析（文本→分类）、股价方向预测（指标→分类）；回归——预测汽车价格、收益预期。引出监督/无监督/强化学习三范式，生成模型 vs 判别模型一句话带过。收束：本周做监督学习中的回归（线性回归），KNN 分类下周 W12 讲。
4. **训练/测试划分直觉（14 分钟）**：用 `gdp_satisfaction.csv` 演示——先用**全量数据** fit → R² 看起来不错。问全班："如果有个新国家的数据，模型还能预测准吗？"再 `train_test_split` 划开 → 训练集 fit → 测试集评估 → 对比全量 fit 的分（测试分往往更低）。点破：模型可能"记住"了训练数据而非"学会"了规律；参数在训练集上学好，必须在没见过的测试集上验证，否则就是"自欺欺人"。一句话过渡："这个概念 W14 量化交易中会直接用到——回测就是测试集验证。接下来看模型如何从数据中学习。"

**第2节 · 线性回归：模型如何从数据中学习（45 分钟）**

5. **梯度下降直觉（15 分钟）**：用 notebook §gradient descent 的 f(x)=x² 可视化——初始 x=10，学习率 η=0.2 正好收敛；改 η=1.1 看发散（结果 61.9，越跑越远）；改 η=0.05 看收敛太慢。一句话总结：学习率太大→发散，太小→慢，这就是模型"学习"的核心机制——沿着损失函数下降方向逐步更新参数。batch/SGD/mini-batch 一句话带过（"全量算太慢，逐条算太快但抖，折中取一小批"）。
6. **线性回归演示：GDP 与生活满意度（15 分钟）**：用 `gdp_satisfaction.csv`——加载 → 散点图（直觉：GDP 越高满意度越高）→ sklearn `LinearRegression` → `fit` → 看系数（`model.coef_`）→ 画回归线 → 预测。闭式解一句话提：`np.linalg.inv(X.T.dot(X)).dot(X.T).dot(y)`（notebook 有对应代码，`least squares.docx` 有推导，课后参考）。每步一句话解释"为什么这步在前"。
7. **手写 SGD 填空（10 分钟）**：notebook 中 `gd(eta,w,b,x,y)` 函数体为空——学生填写梯度更新公式：`d_w = (w*x + b - y) * x`，`d_b = (w*x + b - y)`，`w = w - eta * d_w`，`b = b - eta * d_b`。填完后跑 100000 次迭代，对比 sklearn 结果是否一致。`code.docx` 有完整答案。这是理解"`fit` 到底做了什么"的关键——不是魔法，就是反复用梯度下降更新参数。
8. **接到自己的数据（5 分钟）**：教师演示三步改法：①`pd.read_csv` 换成自己的文件；②`y = df['目标列']`；③`X = df[['特征1','特征2']]`。学生当场尝试——有合适标签的直接改，没有的用课堂数据练手、周末换回。卡在"我的数据没有标签"的引导：哪些列可以当 y？日期能构造标签吗（如"次日涨跌"）？

**第3节 · 独立建模 + 技能小练 + 收束（45 分钟）**

9. **学生独立建模（25 分钟）**：用自己的项目数据建回归模型。分步检查点（教师巡场时逐个确认）：
    - [ ] 数据加载成功，X 和 y 的 shape 合理（不是空、不是全 NaN）
    - [ ] `train_test_split` 在 `fit` 之前
    - [ ] 跑出了指标（R²/MSE），不是 NaN
    - [ ] 能一句话说清"为什么选回归"
    跑通的学生尝试改一个超参数（如 `fit_intercept`）看指标变化，或换一组特征列再跑一次；没自己数据的继续用 `gdp_satisfaction.csv` 练手，周末换回。
10. **技能小练（12 分钟）**：`lab.md` 当堂起笔——用玩具数据做 train_test_split → 拟合 → 输出指标 → 把测试集混进训练再跑一次看分数虚高 → 三句话回答（为什么选这个模型 / 换另一个行不行 / 跑分可信吗）。
11. **收束（8 分钟）**：当日在 `journal.md` 追加 1 条（今天做了什么 / 关键决定 / 学习并掌握的新东西 / 卡点 / 互助记录）。互助记录只写「谁帮了你、对项目有何影响」，没有则写「无」。本周回顾：产品缺预测能力→ML 补上→线性回归从数据中学规律（梯度下降）→`fit` 不是魔法是参数更新。下周 W12 进入 KNN + 特征工程，从另一个角度看模型如何做分类。
