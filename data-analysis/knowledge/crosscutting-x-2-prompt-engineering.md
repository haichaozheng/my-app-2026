# Prompt Engineering贯穿

> **引入时机**：W1全程 | **核心挑战**：如何从"随便问"进化到"精准指令"，再到"将Prompt嵌入产品"？ | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

Prompt Engineering不是一门独立的"技巧课"，而是贯穿整个项目生命周期的核心能力。在W1，你可能只是用简单的中文提问让AI帮你写函数；到了W8，你需要设计结构化的Prompt来让AI生成完整的API；到了W13，Prompt本身可能成为你产品的一部分——用户输入问题，你的产品构造Prompt调用LLM返回分析结果。不理解这种演进，你会一直停留在"随便问"的低效阶段。

对于财经院校学生而言，Prompt Engineering的价值不仅在于编程效率。在金融行业，越来越多的工具直接基于LLM——从投资研究助手到合规检查工具。理解Prompt的设计逻辑，等于理解了这些工具的能力边界和使用方法，这是未来职场的必备素养。

更重要的是，Prompt Engineering教会你一种"精准表达需求"的思维方式。这种思维方式不仅适用于AI交互，也适用于与同事沟通需求、向领导汇报方案、向客户展示价值。把话说清楚、说完整、说有结构——这是Prompt Engineering背后的元能力。

## 这个知识点的核心内容

### Prompt Engineering的四阶段演进

**阶段一：简单Prompt（W1-W3）**
- 特征：自然语言直接提问，无结构
- 示例：`帮我写个计算移动平均线的函数`
- 局限：AI回答泛泛，需要多轮追问
- 适用：快速探索、学习新API、生成简单代码

**阶段二：结构化Prompt（W4-W9）**
- 特征：有角色、背景、要求、格式的结构化指令
- 模板：
```
## 角色
你是一个Python数据分析专家，熟悉pandas和金融数据处理

## 背景
我正在构建A股分析工具，需要处理日线数据

## 任务
编写一个函数，计算股票的N日动量因子

## 要求
1. 输入：DataFrame（包含date、close列），N（整数）
2. 输出：Series，为N日动量值
3. 处理缺失值：用前值填充
4. 不要使用未来数据（look-ahead bias）

## 格式
只输出代码，不要解释
```

**阶段三：Prompt链（W8-W14）**
- 特征：将复杂任务拆解为多个Prompt，串行或并行执行
- 示例：股票分析Prompt链——
  1. Prompt1：提取财报关键指标
  2. Prompt2：基于指标生成财务健康评分
  3. Prompt3：结合市场数据生成投资建议
- 价值：每个环节可独立调试和优化，整体效果可控

**阶段四：Prompt作为产品特性（W13-W17）**
- 特征：Prompt嵌入产品，成为用户交互的核心环节
- 示例：用户输入"分析贵州茅台的投资价值"→产品自动构造Prompt→调用LLM→返回结构化分析
- 设计要点：
  - System Prompt定义AI角色和行为边界
  - User Prompt模板化，动态填充用户输入和数据
  - 输出格式约束（JSON Schema），确保可解析

### 核心Prompt技术

**角色设定**：给AI一个明确的角色，回答质量和专业度显著提升。
```
你是一位有10年经验的量化研究员，擅长A股因子投资。
回答时请结合A股市场特点，注意区分A股与其他市场的差异。
```

**Few-Shot示例**：通过示例展示期望的输出格式和风格。
```
请分析股票的风险等级，按以下格式输出：

示例1：
股票：贵州茅台（600519）
风险等级：低
理由：大盘蓝筹，波动率低于市场平均，流动性充裕

示例2：
股票：XXX科技（688XXX）
风险等级：高
理由：科创板小盘股，波动率显著高于市场，流动性一般

现在请分析：{用户输入的股票}
```

**思维链（Chain of Thought）**：要求AI展示推理过程，提高复杂问题的准确性。
```
请逐步分析以下股票是否值得投资：
1. 先分析基本面（营收、利润、ROE趋势）
2. 再分析技术面（趋势、支撑压力位）
3. 然后分析市场情绪（资金流向、机构持仓变化）
4. 最后综合给出建议，并标注置信度

股票数据如下：{数据}
```

**输出格式约束**：强制结构化输出，确保结果可程序化处理。
```
请以JSON格式输出分析结果，严格遵循以下schema：
{
  "stock_code": "string",
  "risk_level": "low|medium|high",
  "factors": [
    {"name": "string", "score": "number", "direction": "positive|negative"}
  ],
  "recommendation": "string",
  "confidence": "number (0-100)"
}
```

### 面向金融场景的Prompt设计模式

**数据注入模式**：将实时数据嵌入Prompt，让AI基于真实数据回答。
```
以下是贵州茅台最近5个交易日的行情数据：
日期,开盘,最高,最低,收盘,成交量
2024-01-15,1680.00,1695.50,1672.00,1688.00,12345
...

基于以上数据，请分析短期走势。
```

**多视角分析模式**：让AI从不同角色/视角分析同一问题。
```
请分别从以下三个视角评估该投资组合的风险：
1. 量化分析师视角：关注波动率、相关性、VaR
2. 基本面分析师视角：关注估值、盈利质量、行业周期
3. 合规视角：关注集中度、流动性、监管限制

组合信息：{组合数据}
```

**对比分析模式**：让AI对比分析多个标的。
```
请对比以下三只银行股的投资价值，从估值、成长性、分红率三个维度打分（1-10分），
并给出最终推荐排序及理由：
1. 招商银行（600036）
2. 宁波银行（002142）
3. 工商银行（601398）

数据如下：{数据}
```

### Prompt调优方法论

**迭代优化循环**：
1. 编写初始Prompt
2. 测试3-5个不同场景
3. 分析失败案例，识别系统性问题
4. 修改Prompt（增加约束、补充示例、调整结构）
5. 重新测试验证

**评估指标**：
- 准确性：输出是否符合事实
- 一致性：相同输入是否产生相同输出
- 完整性：是否覆盖了所有要求的维度
- 格式合规：输出是否可被程序解析

## 关键细节与易错点

1. **忽视System Prompt的重要性**：很多学生只关注User Prompt，但System Prompt决定了AI的基础行为模式。对于金融产品，System Prompt必须包含：角色定义、行为边界（不提供具体买卖建议）、输出格式、安全约束。

2. **Prompt过长或过短**：过短导致AI理解不足，过长导致AI注意力分散。最佳长度取决于任务复杂度——简单任务5-10行，复杂任务20-40行。关键是信息的结构化程度而非长度。

3. **不测试边界情况**：Prompt在正常情况下表现好不代表在边界情况也可靠。必须测试：空输入、极端数据、恶意输入、超长输入。

4. **混淆"AI能回答"和"AI能可靠回答"**：AI几乎总能给出回答，但可靠性差异巨大。对于金融场景，不可靠的回答比没有回答更危险。始终设置置信度阈值和免责声明。

5. **Prompt中包含敏感信息**：不要在Prompt中放入API Key、用户真实数据、商业机密。使用占位符替代，运行时动态填充。

## 金融数据分析示例

**从简单到结构化的进化——股票分析Prompt**：

**W2简单版**：
```
帮我分析一下贵州茅台这只股票
```
问题：AI回答泛泛，没有数据支撑，无法程序化使用

**W6结构化版**：
```
## 角色
你是一位A股基本面分析师

## 任务
基于以下财务数据，分析贵州茅台的投资价值

## 数据
{财务数据JSON}

## 要求
1. 从盈利能力、成长性、估值水平三个维度分析
2. 每个维度给出1-10分评分和理由
3. 最终给出综合建议：买入/持有/卖出
4. 标注分析的时间范围和数据来源

## 格式
Markdown表格+段落
```

**W13产品嵌入版**：
```python
SYSTEM_PROMPT = """
你是一个智能股票分析助手。你的职责是基于用户提供的股票数据提供分析。
重要规则：
1. 不提供具体买卖建议，只提供分析参考
2. 所有分析必须基于提供的数据，不得编造
3. 如果数据不足以得出结论，明确说明
4. 输出必须遵循指定的JSON格式
"""

def generate_analysis(stock_code, stock_data):
    user_prompt = f"""
    请分析以下股票：
    股票代码：{stock_code}
    行情数据：{stock_data['market_data']}
    财务数据：{stock_data['financial_data']}
    
    请按以下JSON格式输出：
    {{
        "stock_code": "{stock_code}",
        "analysis": {{
            "fundamental": {{"score": 0, "reason": ""}},
            "technical": {{"score": 0, "reason": ""}},
            "risk": {{"level": "", "factors": []}}
        }},
        "summary": "",
        "disclaimer": "以上分析仅供参考，不构成投资建议"
    }}
    """
    return call_llm(SYSTEM_PROMPT, user_prompt)
```
