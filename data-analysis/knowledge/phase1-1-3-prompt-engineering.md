# Prompt Engineering基础

> **引入时机**：W1-2 | **核心挑战**：如何与LLM有效交互，让它帮我完成任务？ | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

在金融数据分析项目中，你会频繁使用LLM（大语言模型）来辅助各种任务：生成代码、解释数据、撰写报告、设计分析方案等。但很多同学发现，同样用ChatGPT或Claude，有人能获得高质量的输出，有人却只得到泛泛而谈的废话——差异往往不在工具本身，而在你如何向AI提问。

Prompt Engineering（提示工程）就是"如何与LLM有效沟通"的方法论。它不是玄学或技巧堆砌，而是一套有章可循的交互原则。掌握这些原则后，你可以：更准确地描述需求，减少AI的"猜"和"编"；获得结构化、可操作的建议而非泛泛的描述；在金融专业领域获得更精准的回答；通过迭代对话逐步逼近最优方案。

在PBL的课程中，AI是你的核心学习伙伴之一。当你遇到知识缺口（Gap），第一步往往不是去翻教科书，而是向AI提出精准的问题。Prompt Engineering的质量直接决定了你"查漏补缺"的效率——一个好问题能在5分钟内帮你打通知识堵点，一个模糊的问题可能让你在AI的废话中浪费半小时。

## 这个知识点的核心内容

### 核心原则：清晰性、上下文、约束

**清晰性（Clarity）**：你的指令应该明确、具体、无歧义。避免模糊的描述，尽量用精确的语言表达意图。

- 差的prompt："帮我分析一下股票数据"
- 好的prompt："分析以下A股日K线数据，计算5日均线和20日均线的金叉死叉信号，统计过去一年中金叉出现后5个交易日的平均收益率"

**上下文（Context）**：提供足够的背景信息，让AI理解你的场景和需求。上下文包括：你的角色/身份、任务的背景、已有条件、相关数据或代码。

- 差的prompt："收益率怎么算？"
- 好的prompt："我正在用Python分析A股日K线数据，DataFrame包含open/high/low/close列，收盘价是前复权价格。如何计算日收益率和累计收益率？请给出Pandas代码。"

**约束（Constraints）**：明确限定AI输出的范围、格式、深度等，防止AI"跑题"或输出过于冗长。

- 差的prompt："讲讲技术指标"
- 好的prompt："用200字解释MACD指标的计算逻辑，包括DIF、DEA、MACD柱的定义，不需要代码，不需要历史背景"

### Prompt模式：角色扮演、分步指导、示例驱动

**角色扮演（Role Prompting）**：给AI赋予一个专业角色，引导它以该领域的专业视角回答。

```
你是一位有10年经验的量化分析师，擅长A股市场技术分析和因子研究。
请从量化投资的角度，评估以下技术指标在A股市场的有效性：
1. 均线系统（MA5/MA20/MA60）
2. MACD
3. RSI
对于每个指标，说明其逻辑依据和A股市场的特殊注意事项。
```

**分步指导（Chain-of-Thought）**：要求AI按步骤思考，避免跳步导致遗漏或错误。特别适合复杂分析任务。

```
请按以下步骤分析这份股票数据：
1. 首先描述数据的基本统计特征（行数、列名、数据类型、缺失值比例）
2. 然后识别数值型列的分布特征（均值、标准差、偏度、峰度）
3. 接着分析各列之间的相关性，找出相关性最高的3对变量
4. 最后基于以上分析，建议3个值得深入探索的分析方向
每步给出具体数值和结论。
```

**示例驱动（Few-Shot）**：提供1-3个输入输出示例，让AI理解你期望的格式和风格。

```
将以下金融术语转换为简洁的定义：

示例1：
输入：市盈率
输出：股价与每股收益的比率，衡量股票估值水平，PE=Price/EPS

示例2：
输入：夏普比率
输出：超额收益与波动率之比，衡量风险调整后收益，Sharpe=(Rp-Rf)/σp

请定义：动量因子、换手率、波动率
```

### 金融领域的Prompt技巧

**指定市场和时间范围**：金融领域的概念在不同市场有差异，明确市场可以避免混淆。

```
针对中国A股市场（沪深交易所，非港股通），解释以下概念的特殊之处：
- T+1交易制度对技术分析的影响
- 涨跌停板限制对收益率计算的影响
- 前复权vs后复权对技术指标的影响
```

**要求引用数据源**：让AI提供具体的数据来源，便于你验证。

```
列出A股市场主要行业分类体系，包括：
- 申万行业分类（最新版本和分类数量）
- 证监会行业分类
- 中证行业分类
每个分类体系请提供官方来源链接或权威参考。
```

**设定专业深度**：根据你的水平调整AI输出的深度。

```
我是财经院校本科生，正在学习金融数据分析。
请用我能理解的语言解释"多因子模型"，假设我了解基本的统计学概念（均值、方差、回归）但不了解因子投资理论。
包含：直觉解释→数学表达→A股市场应用→局限性，每个部分2-3句话。
```

### 迭代式Prompt工作流

一次Prompt很难得到完美结果，需要通过多轮对话逐步优化：

1. **初稿Prompt**：描述基本需求，获取AI的初步输出
2. **审查输出**：检查AI的回答是否准确、完整、符合预期
3. **补充Prompt**：指出不足之处，要求AI补充、修正、深化
4. **验证Prompt**：要求AI自我检查或提供验证方法

```
[第1轮] "帮我设计一个A股行业轮动策略的分析流程"
[第2轮] "上面提到的'动量因子'部分，请给出具体的计算方法和Python代码"
[第3轮] "代码中的shift(1)是用来避免未来数据的，请解释为什么需要这一步，以及还有哪些地方可能出现look-ahead bias"
[第4轮] "请检查上面给出的完整分析流程，确认是否存在逻辑漏洞或遗漏的步骤"
```

### 常见Prompt反模式

- **过于宽泛**："告诉我关于股票的一切" → AI无法组织有效输出
- **一次问太多**：在一个Prompt中塞入5个独立问题 → AI可能遗漏或混淆
- **缺少反馈循环**：收到不满意的回答后直接换话题 → 应该追问和修正
- **忽略AI的局限性**：让AI直接给出投资建议或预测股价 → AI无法也不应提供此类信息
- **不验证直接用**：AI给出的金融公式、统计数据等未经核实就直接使用 → 可能包含"幻觉"

## 关键细节与易错点

### 把Prompt当作搜索引擎查询

很多同学习惯像用搜索引擎一样使用LLM——输入几个关键词期待精确匹配。但LLM是生成式模型，它需要理解你的完整意图才能给出好的回答。从"股票数据"变为"我有一份A股日K线CSV数据，包含日期、开盘价、收盘价、成交量列，我想计算5日均量，请给出Pandas代码"——效果会天差地别。

### 忽略AI输出中的"幻觉"

LLM会"自信地"编造不存在的事实，在金融领域这尤其危险。它可能引用不存在的论文、编造不存在的指标公式、给出错误的市场数据。对AI提供的任何事实性信息，都应该通过权威来源验证。特别是：具体数值、统计数据、法规条文、API参数。

### 一次Prompt期望完美结果

这是最常见的误区。好的Prompt Engineering是迭代的过程，不是"一句话搞定一切"。第一轮获取框架，第二轮补充细节，第三轮修正错误，第四轮优化表达。在项目实践中，一个复杂的分析方案可能需要5-8轮对话才能完善。

### 过度依赖角色扮演

角色扮演是有效技巧，但要注意：AI扮演"量化分析师"并不意味着它真的具备量化分析师的专业判断力。它可能以专业语气输出不专业的建议。角色扮演改变的是输出的风格和角度，而非AI的能力边界。

### 不指定输出格式

当你需要特定格式的输出时（如JSON、表格、代码），一定要在Prompt中明确指定。否则AI可能以段落文字描述一个本应结构化呈现的内容。比如"以表格形式列出以下5个技术指标的计算方法、适用场景和注意事项"比"介绍以下5个技术指标"更有可能得到结构化输出。

## 金融数据分析示例

**场景**：你获取了一份A股上市公司财务数据，想要用LLM辅助你进行系统化的数据探索。

**第1轮Prompt：描述数据，获取初步分析方向**

```
我有一份A股上市公司的财务数据（CSV格式），包含以下字段：
- 股票代码、股票名称、行业（申万一级）
- 报告期、营业收入、净利润、总资产、净资产
- 毛利率、净利率、ROE、资产负债率
- 数据范围：2020-2025年，约5000家公司

作为金融数据分析专家，请：
1. 建议这份适合做哪3类分析（每类2-3句话说明思路）
2. 每类分析需要先做哪些数据预处理
3. 可能遇到的数据质量问题及应对方案
```

**第2轮Prompt：针对选定方向深入**

```
我对"行业盈利能力对比分析"这个方向很感兴趣。
请给出详细的分析步骤，包括：
1. 如何按行业汇总计算各财务指标的中位数和均值
2. 如何识别行业内异常值（如ROE异常高或低的公司）
3. 如何可视化展示行业间差异（推荐2-3种图表类型）
4. 给出第1步的Pandas代码
```

**第3轮Prompt：验证和补充**

```
上面代码中使用了groupby().median()和groupby().mean()，
但金融数据常有极端值导致均值失真。
1. 请补充使用截尾均值（trimmed mean）的代码
2. 对于ROE这种可能为负值的指标，中位数是否仍然是最合适的集中趋势度量？
3. 行业内公司数量差异很大（银行30多家 vs 电子400多家），直接比较行业均值是否公平？需要怎么调整？
```

**第4轮Prompt：生成完整代码**

```
综合以上讨论，请给出完整的分析代码，要求：
- 使用Pandas和Plotly
- 包含数据加载、预处理（处理缺失值和异常值）、行业汇总、可视化
- 代码中包含中文注释说明关键步骤
- 输出3张图：行业ROE箱线图、行业净利率排名条形图、ROE vs 资产负债率散点图（按行业着色）
```

这个迭代过程展示了如何通过多轮对话，从模糊的分析想法逐步演进为具体可执行的代码方案。
