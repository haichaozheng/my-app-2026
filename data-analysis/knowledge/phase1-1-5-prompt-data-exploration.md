# Prompt驱动的金融数据探索

> **引入时机**：W2 | **核心挑战**：拿到数据后不知道从哪里开始分析，如何用Prompt引导探索？ | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

在项目初期，你获取到了一份数据——可能是一份A股日K线CSV、一份财务报表数据集、或者一个宏观经济指标的时间序列。这时候最常见的问题是"然后呢？"数据有了，但不知道从哪里开始分析、该关注什么、有什么规律可挖。

传统做法是先学完统计学、数据分析的所有方法，然后逐个尝试。但这在PBL中效率太低——你需要快速找到最有价值的分析方向，而不是大海捞针。Prompt驱动的数据探索方法，就是利用LLM作为你的"探索伙伴"，通过结构化的对话引导你从数据概览逐步深入到有价值的发现。

这种方法的核心优势在于：LLM不会替你做分析，但会帮你提出好问题、建议分析方向、解释你观察到的现象。就像一个经验丰富的前辈坐在你旁边，不是告诉你答案，而是引导你思考。在金融数据分析中，这种引导特别有价值——金融数据的特征（如非平稳性、厚尾分布、周期性）需要特定的探索策略，而LLM了解这些专业特征。

## 这个知识点的核心内容

### LLM作为探索伙伴

LLM在数据探索中的角色不是"自动分析器"，而是"苏格拉底式提问者"和"领域知识顾问"。它可以：

- 帮你快速了解数据的整体特征和潜在问题
- 基于金融领域知识建议有价值的分析方向
- 解释数据中观察到的异常现象可能的原因
- 将你的模糊直觉转化为具体的分析步骤
- 帮你评估分析结果的合理性和金融含义

但LLM不能：直接看到你的数据（除非你粘贴数据摘要）、替代你运行代码、保证分析结论的正确性。因此，有效的数据探索是"AI引导方向 + 人工执行验证"的协作模式。

### Prompt模板体系

以下是一套经过验证的数据探索Prompt模板，按照探索阶段组织：

**模板1：数据概览**

```
我有一份[数据类型]数据，包含[字段列表]，数据量约[行数]行。
数据时间范围是[起始]到[结束]。
请作为金融数据分析专家，建议：
1. 首先应该检查的5个数据质量问题
2. 最基本的描述性统计应该关注哪些指标
3. 这类数据常见的"坑"有哪些
```

**模板2：特征发现**

```
基于以下数据摘要：
[粘贴df.describe()和df.info()的输出]

请分析：
1. 哪些字段的分布特征值得关注（如偏度、异常值、多峰分布）
2. 哪些字段之间可能存在有意义的关联
3. 数据中可能存在的质量问题（如缺失模式、异常值特征）
4. 基于金融领域知识，这份数据最可能揭示的3个业务洞察
```

**模板3：方向选择**

```
我已完成初步数据探索，主要发现：
[列出3-5个关键发现]

我的项目目标是[项目目标]。
请建议3个可深挖的分析方向，对于每个方向：
1. 分析思路（2-3句话）
2. 所需的具体方法/技术
3. 可能的金融含义
4. 实现难度（简单/中等/困难）
```

**模板4：方案细化**

```
我选择深入分析[选定方向]。
请给出具体的分析步骤，包括：
1. 需要的额外数据或预处理
2. 分析方法的数学/统计原理（简要）
3. Python实现的关键代码框架
4. 预期结果和解读方式
5. 可能的陷阱和验证方法
```

### 迭代探索工作流

有效的数据探索不是一次性对话，而是一个迭代深化的过程：

**第1步：描述数据基本特征**

```python
import pandas as pd

df = pd.read_csv("data/stock_daily.csv", parse_dates=["日期"])
print(df.info())
print(df.describe())
print(f"缺失值:\n{df.isnull().sum()}")
print(f"日期范围: {df['日期'].min()} ~ {df['日期'].max()}")
```

将以上输出粘贴给LLM，获取数据质量评估和初步分析建议。

**第2步：识别潜在关联**

基于LLM的建议，选择2-3个方向进行可视化探索：

```python
import plotly.express as px

fig = px.scatter(df, x="成交量", y="涨跌幅", trendline="ols",
                 title="成交量与涨跌幅的关系")
fig.show()
```

将观察结果告诉LLM，获取更深层的分析建议。

**第3步：建议3个可深挖的分析方向**

综合前面的发现，让LLM帮助你评估和排序分析方向：

```
基于以上探索，我发现：
1. 成交量放大的日子涨跌幅波动更大
2. 每月月初和月末的成交量有规律性变化
3. 连续上涨3天后第4天跌的概率约60%

请建议3个最值得深挖的分析方向，并排序。
```

**第4步：选定的分析方向，让LLM给出具体实现方案**

进入具体的分析实现阶段，此时Prompt从"探索式"转为"构建式"。

### 金融数据探索的特殊考虑

金融数据与一般数据不同，探索时需要特别注意：

- **时间依赖性**：金融数据是时间序列，不能随机打乱顺序，不能忽略时间结构
- **非平稳性**：股价本身是非平稳的，通常需要转换为收益率等平稳序列再分析
- **厚尾分布**：金融收益率分布通常有厚尾特征，正态分布假设可能不适用
- **波动聚集**：大波动之后倾向于出现大波动（GARCH效应）
- **日历效应**：月初/月末、周一/周五、节假日前后可能有系统性差异
- **幸存者偏差**：只分析当前上市的公司会忽略已退市的公司

## 关键细节与易错点

### 不给LLM提供数据摘要就问分析方向

LLM看不到你的数据，如果你只说"我有一份股票数据，该怎么分析"，它只能给出泛泛的建议。必须提供具体的`df.describe()`、`df.info()`、缺失值统计、样本数据等，LLM才能给出有针对性的建议。

### 跳过数据质量检查直接探索

这是最常见也最危险的错误。数据中可能有：停牌导致的全零行、分红除权导致的价格跳变、代码错误导致的数据错位、不同来源数据的时间不对齐。如果不先检查和清洗数据，后续所有分析都建立在错误的基础上。数据探索的第一步永远是数据质量评估。

### 将LLM的"猜测"当作"发现"

LLM基于数据摘要可能推测出某些模式，比如"成交量与涨跌幅可能正相关"。这只是一个值得验证的假设，不是结论。你必须用代码实际计算相关性、画图验证，才能确认。LLM的价值在于帮你生成假设，验证假设的工作必须你自己做。

### 一次问太多方向

"请帮我分析这份数据的所有方面"——这样的Prompt会得到浅薄且不聚焦的回答。每次对话聚焦1-2个方向，深入挖掘后再转向其他方向。探索是渐进的，不是一蹴而就的。

### 忽视金融含义只看统计特征

数据分析的最终目的是产生业务洞察。如果你发现"某指标的自相关性在第5阶显著"，这本身没有意义；你需要问"这在金融上意味着什么"——可能是周度效应，可能是月度反转，需要用金融逻辑解释统计发现。

## 金融数据分析示例

**场景**：你获取了沪深300成分股2020-2025年的日K线数据，想要进行系统化探索。

**第1步：数据概览Prompt**

```
我有一份沪深300成分股的日K线数据，包含字段：
股票代码、日期、开盘价、最高价、最低价、收盘价、成交量、成交额
数据范围：2020-01-02至2025-06-30，约300只股票×1300个交易日
数据来源：AKShare（前复权）

请作为金融数据分析专家，建议：
1. 这类多股票面板数据首先应该检查的5个数据质量问题
2. 最基本的描述性统计应该关注哪些指标
3. 这类数据常见的"坑"
```

**第2步：执行LLM建议的数据质量检查**

```python
df = pd.read_csv("data/hs300_daily.csv", parse_dates=["日期"])

print("缺失值统计:")
print(df.isnull().sum())

print("\n每只股票的数据量:")
stock_counts = df.groupby("股票代码").size()
print(f"均值: {stock_counts.mean():.0f}, 标准差: {stock_counts.std():.0f}")
print(f"最少: {stock_counts.min()}, 最多: {stock_counts.max()}")

print("\n涨跌幅统计:")
df["涨跌幅"] = df.groupby("股票代码")["收盘价"].pct_change()
print(df["涨跌幅"].describe())

print("\n极端涨跌幅:")
extreme = df[df["涨跌幅"].abs() > 0.095]
print(f"涨跌幅超过9.5%的记录: {len(extreme)}条")
print(extreme[["股票代码", "日期", "涨跌幅"]].head(10))
```

**第3步：将结果反馈给LLM，获取深入分析建议**

```
数据质量检查结果：
1. 缺失值：成交量列有约0.3%的缺失值（主要是停牌日）
2. 每只股票数据量：均值1285条，标准差87，最少1056条（次新股）
3. 涨跌幅：均值0.0003，标准差0.019，偏度-0.15，峰度5.8
4. 极端值：涨跌幅超过9.5%的记录共23条（可能是复牌首日或ST股）
5. 2024年6月之后的数据量明显减少（部分数据尚未更新）

基于以上发现，请建议3个最有价值的分析方向。
```

**第4步：选定方向，获取实现方案**

```
我选择"行业间轮动效应分析"这个方向。

数据现状：我有沪深300成分股的日K线数据（前复权），
以及每只股票的申万行业分类标签。

请给出详细分析步骤，包括：
1. 如何计算行业日收益率（使用流通市值加权还是等权？）
2. 如何衡量行业间的轮动强度（推荐2-3种方法）
3. 如何识别领先-滞后行业关系
4. 每步给出Pandas/Plotly代码框架
5. 预期结果和可能的金融解读
```
