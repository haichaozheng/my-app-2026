# 金融领域知识

> **引入时机**：W2全程 | **核心挑战**：做金融数据分析项目，但金融知识不够怎么办？ | **层级**：Recommended

## 为什么要在项目阶段学习这个知识点？

数据分析课程教的是工具和方法，但如果不懂金融领域知识，你用这些工具分析出来的结果可能毫无意义——甚至在金融意义上是错误的。比如，你在回测量化策略时不处理A股的T+1交易制度，回测结果就是虚的；你在做行业分析时混淆了申万行业分类和证监会行业分类，结论就对不上号。

金融领域知识不是"先学完再做项目"，而是"边做边学、按需深入"。本知识点为你提供一个金融知识的自学习框架，帮助你在项目过程中按需补充金融背景。你不需要成为金融专家，但你需要知道哪些知识对你的项目是必要的，以及如何高效地获取这些知识。

对于财经院校学生，你们已经有一定的金融基础，但可能缺乏"从数据视角理解金融"的习惯。金融规则和数据之间的关系比你们想象的更紧密——交易规则决定了数据结构，监管要求约束了数据处理方式，市场微观结构影响了分析结论的可靠性。

## 这个知识点的核心内容

### 金融数据分析必知的领域知识模块

**模块一：A股市场结构**
- 交易所体系：上交所（主板60x/科创板688）、深交所（主板000/创业板300）、北交所（8xx）
- 交易制度：T+1、集合竞价（9:15-9:25）、连续竞价（9:30-11:30, 13:00-14:57）、收盘集合竞价（14:57-15:00）
- 涨跌幅限制：主板±10%、创业板/科创板±20%、北交所±30%、ST股±5%
- 停牌与复牌：临时停牌、长期停牌、ST/*ST制度

**模块二：金融数据类型与来源**
- 行情数据：Tick/分钟/日/周/月K线，OHLCV
- 财务数据：三大报表（资产负债表、利润表、现金流量表）、关键财务指标
- 另类数据：资金流向、龙虎榜、融资融券、大宗交易、限售解禁
- 宏观数据：CPI、PPI、PMI、M2、社融、LPR

**模块三：估值与定价基础**
- 绝对估值：DCF（现金流折现）、DDM（股利折现）
- 相对估值：PE/PB/PS/EV-EBITDA，适用行业不同
- 分红与除权除息：对股价和收益计算的影响
- 复权方式：前复权、后复权、不复权，不同场景用不同复权

**模块四：风险管理基础**
- 市场风险：波动率、相关性、系统性风险vs非系统性风险
- 信用风险：违约概率、信用评级、信用利差
- 流动性风险：买卖价差、成交量、冲击成本
- 合规风险：内幕交易、操纵市场、适当性管理

**模块五：行业与公司分析**
- 行业分类体系：申万行业分类（最常用）、证监会行业分类、GICS
- 产业链分析：上中下游关系，景气度传导
- 竞争格局：集中度（CR3/CR5/HHI）、进入壁垒
- 商业模式：不同行业的核心驱动因素不同（银行看净息差、零售看同店增长、科技看研发转化）

### 关键金融概念与数据分析的关系

| 金融概念 | 数据分析影响 | 常见错误 |
|---------|-------------|---------|
| T+1制度 | 收益计算必须用次日开盘价 | 用当日收盘价计算买卖收益 |
| 停牌 | 停牌期间数据缺失，不能简单填充 | 用0或前值填充成交量 |
| 涨跌停 | 涨停时无法买入，跌停时无法卖出 | 回测时假设涨跌停可以成交 |
| 除权除息 | 复权处理影响收益率计算 | 不复权计算收益，产生虚假波动 |
| ST制度 | ST股涨跌幅5%，交易规则不同 | 统一用10%涨跌幅限制回测 |
| 退市 | 幸存者偏差：只看现存股票 | 回测时不包含已退市股票 |

### 自学习策略

**策略一：问题驱动学习**
- 不要从教材第一页开始读，而是从项目遇到的具体问题出发
- 例：需要计算收益率时，搜索"A股收益率计算 复权"→理解复权→实现代码

**策略二：数据驱动理解**
- 获取真实数据，通过可视化理解金融概念
- 例：下载贵州茅台的日K线，标注除权除息日，观察复权前后的差异

**策略三：案例驱动深化**
- 学习真实案例比理论更有价值
- 例：2015年股灾期间的涨跌停数据、2020年原油宝事件的衍生品风险

**策略四：社区学习**
- 雪球、集思录、东方财富等社区的实战讨论
- 知乎上"量化投资"话题下的高质量回答
- GitHub上开源量化项目的文档

## 关键细节与易错点

1. **复权方式选择错误**：前复权适合看历史走势图，后复权适合计算真实收益率，不复权适合看真实价格。量化回测必须用后复权或前复权+正确处理分红。选错复权方式是新手最常犯的错误之一。

2. **忽视交易成本**：回测时只算理论收益不考虑佣金、印花税、滑点。A股交易成本约0.15%-0.3%（双边），高频策略可能被成本吃掉全部利润。

3. **混淆不同行业分类**：申万一级行业31个，证监会行业门类更粗。不同数据源可能用不同分类体系，混用会导致分析错误。

4. **财务数据的时间点问题**：年报在次年4月底前披露，一季报在4月底前披露。如果你用当年年报数据回测当年的策略，就犯了前视偏差。

5. **对"异常值"的误判**：金融数据中的"异常值"可能不是噪声，而是真实的市场事件（涨跌停、闪崩、乌龙指）。简单剔除可能丢失重要信息。

## 金融数据分析示例

**场景：构建A股股票分析仪表盘时需要掌握的核心金融知识**

**第一步：理解数据结构**
```python
import akshare as ak

# 日K线数据结构
df = ak.stock_zh_a_hist(symbol="600519", period="daily", start_date="20240101")
# 列：日期,开盘,收盘,最高,最低,成交量,成交额,振幅,涨跌幅,涨跌额,换手率
# 注意：涨跌幅已经是百分比形式，如 2.5 表示涨2.5%
```

**第二步：处理复权**
```python
# 前复权数据（用于看图）
df_qfq = ak.stock_zh_a_hist(symbol="600519", period="daily", adjust="qfq")

# 后复权数据（用于计算真实收益）
df_hfq = ak.stock_zh_a_hist(symbol="600519", period="daily", adjust="hfq")

# 不复权数据（用于看真实价格）
df_no = ak.stock_zh_a_hist(symbol="600519", period="daily", adjust="")
```

**第三步：计算正确收益率**
```python
# 错误：不复权数据直接计算收益率（忽略分红影响）
returns_wrong = df_no['收盘'].pct_change()

# 正确：用后复权数据计算真实收益率
returns_correct = df_hfq['收盘'].pct_change()
```

**第四步：处理停牌**
```python
# 停牌日的特征：成交量为0
suspended = df[df['成交量'] == 0]

# 处理方式：停牌日用前值填充价格，收益率为0
df.loc[df['成交量'] == 0, '收盘'] = df['收盘'].ffill()
df.loc[df['成交量'] == 0, '日收益率'] = 0
```
