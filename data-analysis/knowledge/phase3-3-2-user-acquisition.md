# 获客与推广方法论

> **引入时机**：W12 | **核心挑战**：产品上线了但没人用，如何让目标用户知道并愿意尝试？ | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

你花了数周开发了一个金融数据分析产品，部署上线后满怀期待地等待用户——但访问量几乎为零。这是绝大多数产品的真实遭遇：构建产品只是第一步，让目标用户知道并愿意尝试是另一个同样困难的挑战。在PBL课程中，你的项目最终需要公开展示和获取真实用户反馈，如果没有人用你的产品，你就无法验证产品价值，也无法获得改进的方向。

很多技术出身的人有一个误区：只要产品足够好，用户自然会来。这在现实中几乎不会发生。在信息过载的时代，用户注意力是最稀缺的资源，你的产品需要在众多竞争者中脱颖而出。理解获客方法论，能让你有策略地推广产品，而不是盲目地到处发链接。

金融数据产品的用户通常是垂直领域的专业人士或投资爱好者，他们活跃在特定的社区和平台。精准触达这些用户，比广撒网更高效。学习获客方法论不仅是为了课程项目，更是产品思维的核心组成部分——理解用户从哪里来、如何被吸引，是任何产品成功的基石。

## 这个知识点的核心内容

### 获客渠道概览

获客渠道可以分为付费渠道和免费渠道，对于学生项目和早期产品，应优先利用免费渠道：

- **社交媒体**：微信公众号、小红书、B站、知乎、微博。每种平台有不同的内容形式和用户画像，需要针对性创作
- **垂直社区**：雪球、东方财富股吧、集思录、且慢、Reddit的r/stocks和r/algotrading。这些社区聚集了你的核心用户群
- **内容营销**：通过撰写有价值的分析文章、教程或研究报告吸引用户。内容本身就是产品价值的证明
- **SEO（搜索引擎优化）**：让你的产品页面在搜索结果中排名靠前，获取持续的自然流量
- **口碑传播**：现有用户推荐新用户，是最有效的获客方式，但前提是你的产品要足够好

### 金融产品推广策略

金融数据产品的推广有其特殊性：

- **展示而非告诉**：金融用户对空话免疫，用真实的数据分析案例展示产品能力。比如"我们分析了近3年A股所有行业ETF的相关性，发现了这些轮动规律"
- **借用热点**：市场大跌、板块异动、政策发布时，用你的产品快速给出分析，顺势推广
- **免费增值模式**：核心功能免费，高级功能付费。降低用户尝试门槛
- **社区参与而非广告**：在金融社区中先建立专业形象，再自然地介绍产品。硬广会被社区排斥
- **数据可视化传播**：精美的图表和可视化天然适合社交媒体传播，让产品成果自带传播力

### 增长指标体系

衡量获客效果需要关注以下指标：

- **获客数量**：新增用户数、注册数、下载量
- **获客成本（CAC）**：获取一个新用户的平均成本，学生项目应追求接近零的CAC
- **激活率**：注册后实际使用产品的用户比例
- **留存率**：用户持续使用产品的比例，次日留存、7日留存、30日留存
- **推荐率（NPS）**：用户愿意推荐产品的程度，NPS>30算不错
- **增长漏斗**：从曝光→点击→注册→使用→留存的转化率分析

### 增长实验方法

获客不是一次性的活动，而是持续实验的过程：

1. **提出假设**："如果我发布一篇关于行业轮动的分析文章到雪球，会有50人点击产品链接"
2. **最小化实验**：写一篇文章，附带产品链接，发布到雪球
3. **测量结果**：统计链接点击量、新注册数
4. **学习迭代**：如果效果好就加大投入，效果差就调整策略

## 关键细节与易错点

### 只做产品不做推广

最常见的错误是把100%时间花在产品开发上，0%时间用于推广。对于早期产品，产品和推广的精力分配建议至少7:3。产品做得再好，没人知道就等于零价值。

### 在错误的渠道推广

在程序员社区推广金融产品，或在时尚平台推广量化工具，都是渠道错配。要找到你的目标用户聚集的地方。金融数据产品的核心用户在雪球、东方财富、集思录等平台，而不是Hacker News。

### 推广内容像广告

用户对广告天然抵触，尤其是金融社区的用户对推销极度敏感。推广内容必须提供价值——一个有趣的数据发现、一个实用的分析视角、一个能帮用户赚钱的洞察。价值先行，产品介绍自然带出。

### 忽视留存只看新增

每天100个新用户但第二天全走了，不如每天10个新用户但7个留下来。获客的终极目标是留存，没有留存的增长是虚假繁荣。追踪留存指标，确保用户来了愿意留下。

### 推广和产品价值脱节

推广时承诺的功能和实际体验差距大，会导致用户快速流失和负面口碑。推广内容应基于产品已有的真实能力，而非未来的计划。

## 金融数据分析示例

**场景**：你开发了一个A股行业轮动分析工具，能展示行业间相关性、资金流向和轮动信号。产品部署上线后，需要找到第一批用户。

**策略1：内容营销——雪球社区**

```
标题：我用Python分析了A股28个申万行业近3年的相关性，发现了这些轮动规律

正文：
最近用自己开发的工具分析了A股行业间的相关性矩阵，
发现几个有趣的现象：
1. 银行和地产的相关性从2024年的0.8下降到了0.3
2. 电子和计算机始终高度相关（0.7+），但与消费相关性为负
3. 每次市场反弹，率先启动的行业有规律性

[附上相关性热力图]

工具链接：https://your-app.streamlit.app（示例地址）
可以自定义时间段和行业范围
```

**策略2：微信社群运营**

在投资俱乐部微信群中，先分享有价值的市场分析，在讨论中自然提到"我用自己做的工具跑了下数据"，当群友表现出兴趣时再分享产品链接。

**策略3：SEO优化**

在产品页面中包含关键词：`A股行业轮动`、`行业相关性分析`、`板块资金流向`、`申万行业分析工具`，让搜索引擎用户能找到你。

**策略4：增长指标追踪**

```python
import streamlit as st

page_views = st.session_state.get("page_views", 0)
st.session_state["page_views"] = page_views + 1

if "user_source" not in st.session_state:
    source = st.query_params.get("source", "direct")
    st.session_state["user_source"] = source
```

通过URL参数追踪用户来源（`?source=xueqiu`、`?source=wechat`），分析哪个渠道最有效。

## 拓展学习

- **增长黑客方法论**：Sean Ellis提出的增长方法论，强调数据驱动的增长实验，适合早期产品
- **《引爆点》**：Malcolm Gladwell著，理解信息传播和流行趋势的经典读物
- **产品冷启动**：如何从零开始获取第一批用户的策略和案例
- **AARRR漏斗模型**：Acquisition、Activation、Retention、Referral、Revenue，完整的用户生命周期框架
- **社区运营**：在垂直社区建立影响力的方法论，比传统广告更适合金融产品
