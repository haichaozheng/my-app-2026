# 路演展示与Demo

> **引入时机**：W16 | **核心挑战**：如何在公开场合展示产品、说服评委和观众？ | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

项目做了17周，如果最后5分钟讲不清楚，所有努力可能付之东流。路演展示不是简单的"做PPT然后念"，而是一次精心设计的沟通——你需要在极短时间内让评委理解你做了什么、为什么有价值、以及你如何证明它有效。对于财经院校学生而言，路演能力不仅是课程要求，更是未来在投资银行、咨询公司、创业融资等场景的核心竞争力。

Demo是路演中最具风险也最具冲击力的环节。一个流畅的现场演示可以瞬间建立信任，而一次崩溃的演示则可能毁掉整个展示。你需要学会如何在不确定性中控制演示节奏，如何准备Plan B，以及如何将技术亮点转化为观众能感知的价值。

路演还是一次完整的叙事训练。从hook到future，每一个环节都在回答观众心中的一个问题。掌握这套叙事结构，不仅适用于课程展示，也适用于未来的商业提案、投资路演和产品发布。

## 这个知识点的核心内容

### 路演叙事结构：Hook→Problem→Solution→Demo→Future

**Hook（开场钩子）**：用一组震撼数据、一个反常识事实或一个真实场景在15秒内抓住注意力。例如："过去一年A股波动率超过40%，但90%的个人投资者没有系统化的风险管理工具。"

**Problem（问题定义）**：清晰定义你要解决的问题，让观众产生共鸣。问题必须是具体的、可量化的、与受众相关的。避免泛泛而谈"数据分析很重要"。

**Solution（方案阐述）**：用一句话概括你的解决方案，然后用2-3个要点说明核心价值。避免罗列技术栈，聚焦用户价值。

**Demo（现场演示）**：展示产品最核心的功能链路，不要试图展示所有功能。Demo路径应提前设计并反复排练。

**Future（未来展望）**：简述产品下一步计划，展示你的长期思考和野心。

### Demo准备与执行策略

**Demo脚本设计**：将Demo拆解为5-8个步骤，每步有明确的操作和预期输出。写出逐字脚本，包含每一步的鼠标点击和口头解说。

**风险控制**：
- 录制备用视频：现场Demo失败时切换到视频演示
- 准备脱机数据：不依赖网络连接的本地数据集
- 关键步骤截图：在关键节点准备截图，以防实时展示失败

**Demo节奏**：5分钟Demo分配——开场hook(30秒)→核心功能演示(3分钟)→亮点展示(1分钟)→收尾(30秒)。

### 现场Q&A应对策略

**预判问题**：列出评委可能问的10个问题并准备回答。常见问题类型：
- 技术实现细节（"这个指标怎么计算的？"）
- 商业模式（"用户愿意付费吗？"）
- 数据来源（"数据从哪来的？可靠性如何？"）
- 竞争优势（"和现有工具比有什么不同？"）

**回答框架**：先确认理解问题→直接回答→补充论据→回归核心价值。如果不知道，诚实承认并说明会如何解决。

**危机处理**：遇到质疑时不要防御性回应，先认可对方的关注点，再补充你的思考。

### 常见Demo失败模式

| 失败类型 | 原因 | 预防措施 |
|---------|------|---------|
| 实时数据加载失败 | 网络不稳定 | 使用本地缓存数据 |
| 操作失误 | 紧张+未排练 | 逐字脚本+5次以上彩排 |
| 功能堆砌 | 想展示太多 | 只演示核心链路 |
| 评委走神 | 缺乏叙事节奏 | 每步都有价值阐述 |
| 超时 | 没有时间意识 | 掐表排练 |

### PPT设计原则

- 一页一个核心信息
- 数据可视化优于表格
- 用截图/动图展示产品而非纯文字描述
- 字号不小于24pt
- 配色统一，避免花哨动画

## 关键细节与易错点

1. **Demo不是功能巡览**：最常见错误是"点这里→看这个→再看那个"，变成功能列表。Demo应该讲述一个用户故事——某个用户遇到问题，通过你的产品如何解决。

2. **Hook不是标题页**："大家好，我是张三，今天展示的是XX系统"不是Hook。Hook必须在3秒内制造信息差或情绪冲击。

3. **技术细节的度**：评委中有技术人员也有业务人员。技术细节点到为止，用类比说明复杂概念。被追问时再展开。

4. **排练不到位**：5分钟的Demo至少需要10次完整排练，其中3次是在正式环境（投影、翻页器、计时器）下的模拟。

5. **忽视收尾**：Future环节不是可有可无的。它展示你的长期思考，也是评委评估项目潜力的重要依据。

## 金融数据分析示例

以下是一个股票分析仪表盘的5分钟Demo脚本示例：

**Hook（0:00-0:30）**：
> "2024年1月，A股单日最大跌幅超过3%的日子有7天。我妈妈那天打电话问我该不该卖——她不知道，我也不知道。但我想，应该有工具能帮她。"

**Problem（0:30-1:00）**：
> "个人投资者面对市场波动时缺乏系统化的分析工具。现有工具要么太专业（Wind终端年费10万+），要么太简陋（券商App只有基本K线）。我们需要一个中间地带。"

**Solution（1:00-1:30）**：
> "我们构建了StockLens——一个面向个人投资者的智能股票分析仪表盘。三个核心价值：一键风险评估、多维因子分析、个性化组合建议。"

**Demo（1:30-4:30）**：
```
# 操作脚本
# Step 1: 输入股票代码 600519（贵州茅台）
#   → 展示风险雷达图（波动率、最大回撤、夏普比率）
# Step 2: 切换到因子分析页
#   → 展示动量因子、价值因子评分
# Step 3: 添加到虚拟组合
#   → 展示组合风险分散效果
# Step 4: 触发风险预警
#   → 模拟市场下跌场景，展示预警推送
```

**Future（4:30-5:00）**：
> "下一步计划：接入实时行情推送、添加策略回测功能、开发微信小程序端。我们的愿景是让每个个人投资者都有专业级的风控能力。"
