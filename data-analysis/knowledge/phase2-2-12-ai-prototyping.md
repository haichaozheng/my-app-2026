# AI辅助编程加速原型

> **引入时机**：W8 | **核心挑战**："原型搭建速度慢，如何用AI辅助编程加速？" | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

在原型阶段，速度就是一切。你可能需要2天完成K线图、1天完成筛选功能、1天完成AI问答……但用传统方式逐行写代码，一个功能就要花半天。AI辅助编程工具（Cursor、GitHub Copilot、ChatGPT）可以将编码速度提升3-5倍，让你在同样的时间内完成更多功能迭代，收集更多用户反馈。

关键不在于AI能帮你写多少代码，而在于你如何与AI协作。同样是让AI写代码，有人花1小时调试AI生成的bug，有人花10分钟就得到可用代码。区别在于Prompt的质量、验证的方法、以及你是否理解AI生成代码的逻辑。

### 面向UI代码的Prompt模式

生成Streamlit/Gradio代码的有效Prompt模式：

**模式1：从需求到代码**

```
请用Streamlit创建一个银行股分析仪表板，包含以下功能：
1. 侧边栏选择股票（从["601398","600036","601166"]中选择）
2. 主区域显示K线图（使用plotly，中国市场红涨绿跌）
3. K线图下方显示成交量柱状图
4. 顶部显示3个指标卡片：收盘价、涨跌幅、PE

数据获取使用akshare库的stock_zh_a_hist函数。
请确保使用@st.cache_data缓存数据获取。
```

**模式2：从示例到变体**

```
以下是我的现有Streamlit代码：
[粘贴代码]

请在此基础上添加以下功能：
1. 增加多股票对比标签页
2. 对比视图使用归一化收益率（以起始日为基准）
3. 添加下载CSV按钮
```

**模式3：从Bug到修复**

```
我的Streamlit应用出现以下错误：
[粘贴错误信息]

相关代码：
[粘贴代码]

应用功能：获取银行股数据并展示K线图。
请分析错误原因并给出修复方案。
```

### 迭代式细化

AI生成代码后，通过迭代细化提升质量：

**第1轮：生成骨架**
```
用Streamlit创建银行股仪表板，包含K线图和基本筛选。
```

**第2轮：修正问题**
```
K线图颜色需要改为中国市场惯例（红涨绿跌），
成交量的柱子颜色也应该跟涨跌一致。
```

**第3轮：添加细节**
```
请在K线图上添加5日和20日均线，
均线颜色分别为蓝色和橙色。
```

**第4轮：优化体验**
```
添加加载状态提示（st.spinner），
数据获取失败时显示友好错误信息而非报错。
```

### Cursor工作流

Cursor是当前最强的AI编程IDE，核心工作流：

1. **Composer模式**：描述需求，AI生成多文件代码
2. **Chat模式**：选中代码，提问或要求修改
3. **Inline编辑**：按Ctrl+K，描述修改意图
4. **@引用**：用@file引用其他文件作为上下文

Cursor高效使用技巧：
- 始终提供项目上下文（@file引用现有代码）
- 一次只做一件事，不要一个Prompt要求5个功能
- 生成后立即运行验证，不要积累未验证代码
- 将常用模式写入项目规则文件（.cursorrules）

### 代码验证与质量保证

AI生成的代码必须验证：

```python
# 验证清单
# 1. 功能验证：运行代码，确认输出正确
# 2. 边界验证：空数据、单条数据、大数据量
# 3. 错误处理验证：网络超时、数据缺失、格式异常
# 4. 安全验证：是否硬编码API key、是否有SQL注入

def test_ai_generated_code():
    # 测试正常情况
    df = get_stock_data("601398")
    assert len(df) > 0
    assert "收盘" in df.columns

    # 测试边界情况
    df_empty = get_stock_data("000000")  # 不存在的代码
    # 应该有错误处理而非crash

    # 测试数据质量
    df = get_stock_data("601398")
    returns = df["收盘"].pct_change()
    assert returns.abs().max() < 0.15  # A股涨跌停限制
```

### .cursorrules配置

为金融数据项目创建项目规则：

```
# 项目规则

## 技术栈
- Python 3.10+, Streamlit, Plotly, AKShare, Pandas
- 中国A股数据，遵循中国市场惯例

## 代码规范
- K线图和所有金融图表使用红涨绿跌配色
- 数据获取函数必须使用@st.cache_data缓存
- 所有外部API调用需要错误处理（try/except）
- 股票代码格式为6位数字字符串

## 禁止
- 不要硬编码API密钥
- 不要使用未复权价格计算收益率
- 不要在groupby时忘记按股票分组
```

## 关键细节与易错点

- **误区：AI生成的代码可以直接用**。必须验证功能和边界情况，AI经常生成看似正确但有细微bug的代码
- **误区：Prompt越长越好**。结构清晰、需求明确的短Prompt比冗长的描述更有效
- **易错：不提供现有代码上下文**。AI不知道你的项目结构，生成的代码可能与现有代码风格冲突
- **易错：一次要求太多功能**。逐个功能生成+验证，比一次生成全部更可靠
- **易错：不理解就接受**。必须理解AI生成代码的逻辑，否则出bug无法调试

## 金融数据分析示例

用Cursor从零生成Streamlit银行股仪表板：

**Prompt 1（骨架生成）**：
```
请用Streamlit创建一个银行股分析仪表板应用。

功能需求：
1. 侧边栏：选择股票（601398工商银行、600036招商银行、601166兴业银行）
2. 主区域顶部：4个指标卡片（收盘价、日涨跌幅、PE、PB）
3. 主区域中部：Plotly K线图（中国市场红涨绿跌），下方成交量
4. 主区域底部：近期10天数据表格

数据获取用akshare的stock_zh_a_hist函数，使用@st.cache_data。
```

**Prompt 2（添加对比功能）**：
```
请在现有仪表板中添加"行业对比"标签页：
1. 同时展示3只银行股的归一化收益率曲线
2. 归一化方式：以选定起始日期的价格为基准100
3. 用不同颜色区分各银行，添加图例
4. 下方显示3只银行的收益率统计对比表
```

**Prompt 3（添加AI问答）**：
```
请添加"AI分析"标签页：
1. 用户输入关于当前选中股票的问题
2. 调用OpenAI API返回分析
3. System prompt设定为"你是一个A股银行板块分析专家"
4. 将当前股票的关键数据（收盘价、PE、近期涨跌幅）作为上下文传入
5. 使用streaming输出
```

**验证步骤**：
```bash
# 运行应用
streamlit run app.py

# 检查清单：
# □ 侧边栏选择是否切换正确
# □ K线图颜色是否红涨绿跌
# □ 成交量柱是否与涨跌颜色一致
# □ 切换股票时数据是否更新
# □ 对比标签页3条线是否正确
# □ AI问答是否正常返回
# □ 网络异常时是否有友好提示
```
