# Deep Research

> **引入时机**：W3 | **核心挑战**：如何用AI做深度调研，快速了解一个领域？ | **层级**：Essential

## 为什么要在项目阶段学习这个知识点？

在项目初期，你需要快速了解一个领域——无论是确定分析方向、评估市场机会、还是理解技术方案的可行性。传统调研方式（读论文、查报告、搜资料）耗时巨大，而且对于非专业领域的信息，你可能连该搜什么都不知道。AI深度调研工具可以在几分钟内完成传统方式需要数小时甚至数天的调研工作。

但AI调研不是简单的"问ChatGPT"——它需要一套系统化的方法。如果你只是随意提问，AI可能给你肤浅的概括或包含错误的总结；如果你掌握了正确的调研工作流，AI可以成为你的"研究助理"，帮你从定义问题到综合分析到交叉验证，产出结构化的调研报告。

在金融数据分析项目中，Deep Research特别适合以下场景：快速了解某个行业或概念（如"ESG投资在中国的发展现状"）、评估技术方案的可行性（如"用NLP分析A股财报文本的现有研究"）、竞品分析（如"现有的A股数据可视化产品有哪些"）、领域知识补充（如"量化因子投资的学术框架"）。这些调研在项目启动阶段至关重要，决定了你项目的方向和质量。

## 这个知识点的核心内容

### AI深度调研工具

目前适合深度调研的AI工具包括：

**Perplexity AI**：以搜索为核心的AI助手，实时检索互联网信息并附上来源链接，适合事实性调研。Pro版本支持Deep Research模式，可以自动进行多轮搜索和综合。

**ChatGPT Deep Research**：OpenAI推出的深度调研功能，可以自动规划搜索策略、执行多轮检索、综合多个来源的信息，生成结构化的研究报告。适合需要深入综合分析的调研任务。

**Claude**：Anthropic的AI助手，擅长长文本分析和综合推理，适合分析已有的文档和报告。虽然不具备实时搜索能力，但可以用Artifacts功能生成结构化输出。

**通义千问/文心一言**：中文能力强的AI助手，对中文互联网信息覆盖更好，适合需要中文资料的调研任务。

**选择建议**：
- 需要实时信息和来源链接 → Perplexity
- 需要深度综合分析 → ChatGPT Deep Research
- 需要分析已有文档 → Claude
- 需要中文互联网资料 → 通义千问

### 调研工作流：定义→收集→综合→验证

**定义阶段（Define）**：明确调研的目标和边界。

一个模糊的调研需求会导致模糊的结果。在开始之前，用5分钟明确：

```markdown
调研主题：[具体主题]
调研目的：[为什么需要这个调研，决策依赖什么信息]
关键问题：
1. [最需要回答的问题1]
2. [最需要回答的问题2]
3. [最需要回答的问题3]
调研边界：
- 时间范围：[如2020-2025年]
- 地域范围：[如中国A股市场]
- 深度要求：[如概览级/操作级/学术级]
```

**收集阶段（Gather）**：使用AI工具系统化收集信息。

使用结构化Prompt进行调研：

```
请对以下主题进行深度调研：[调研主题]

调研要求：
1. 覆盖以下关键问题：[列出3-5个关键问题]
2. 时间范围：[指定]
3. 地域/市场范围：[指定]
4. 请提供具体的数据、案例和来源

输出格式：
- 每个关键问题独立成节
- 包含具体数据和来源引用
- 在末尾列出所有参考来源
```

**综合阶段（Synthesize）**：将收集到的信息整合为有逻辑的洞察。

调研的产出不是信息堆砌，而是结构化的洞察。使用以下框架组织调研结果：

```markdown
# 调研报告：[主题]

## 执行摘要
[3-5句话总结核心发现和结论]

## 关键发现

### 发现1：[标题]
- 核心结论：[1-2句话]
- 支撑数据：[具体数据和来源]
- 对项目的影响：[这如何影响你的项目决策]

### 发现2：[标题]
...

## 未解答的问题
[调研中发现的仍需深入探索的问题]

## 建议的下一步行动
[基于调研结果，建议的具体行动]
```

**验证阶段（Verify）**：交叉验证AI提供的关键信息。

AI调研结果中可能包含"幻觉"——编造的数据、错误的引用、过时的信息。对以下类型的信息必须验证：

- 具体的数字和统计数据
- 政策法规的条款和生效时间
- 市场规模和增长率
- 技术方案的具体细节
- 来源链接是否真实存在

### 构建结构化调研报告

好的调研报告应该让读者（包括未来的自己）能够快速理解核心结论和决策依据。

**报告结构模板**：

```markdown
# [主题]深度调研报告

> 调研人：[姓名] | 日期：[日期] | 调研工具：[使用的AI工具]

## 1. 调研背景与目的
[为什么做这个调研，要回答什么问题]

## 2. 核心发现
[3-5条最重要的发现，每条1-2句话]

## 3. 详细分析

### 3.1 [子主题1]
[详细内容，包含数据、案例、来源]

### 3.2 [子主题2]
...

## 4. 对项目的影响
[调研发现如何影响你的项目方向、技术选型、优先级等]

## 5. 风险与不确定性
[调研中发现的潜在风险和信息缺口]

## 6. 参考来源
[所有参考来源的列表，包含URL和访问日期]
```

### 多工具协同调研

不同AI工具有不同优势，组合使用效果最佳：

1. **Perplexity**：快速获取事实性信息、最新数据、来源链接
2. **ChatGPT Deep Research**：深度综合分析、生成结构化报告
3. **Claude**：分析已有的PDF报告、学术论文等长文档
4. **传统搜索**：补充验证关键信息、查找AI可能遗漏的来源

推荐工作流：
```
Perplexity快速概览 → ChatGPT Deep Research深度分析 → Claude综合已有文档 → 人工交叉验证
```

## 关键细节与易错点

### 把AI调研当作权威来源

AI生成的调研报告不等于专业研究报告。AI可能编造数据、混淆来源、遗漏关键信息。任何将用于项目决策的调研结论，都必须通过原始来源验证。AI调研是"快速获取方向感"的工具，不是"替代专业研究"的工具。

### 调研问题过于宽泛

"帮我调研一下量化投资"——这样的问题会让AI产出一份泛泛的百科式回答。好的调研问题应该是具体的、可操作的："中国A股量化私募基金在2023-2025年的主要策略类型有哪些？各自的管理规模和收益特征是什么？"

### 忽略信息时效性

金融领域的很多信息有强时效性——监管政策、市场数据、技术方案都可能随时变化。AI的训练数据有截止日期，它可能提供过时的信息。对于时效性强的信息（如最新的监管政策、当前的市场数据），必须通过官方来源验证。

### 只用单一工具

不同AI工具的搜索能力、分析深度、中文覆盖各有差异。只用一个工具可能遗漏重要信息。比如Perplexity擅长实时搜索但分析深度有限，ChatGPT Deep Research擅长综合分析但可能对中文互联网覆盖不足。

### 缺乏验证就用于决策

调研结果如果直接影响项目方向选择，必须经过验证。特别是：市场是否存在（需求验证）、技术是否可行（可行性验证）、数据是否可获取（数据验证）。这三个维度中任何一个的错误假设都可能导致项目失败。

## 金融数据分析示例

**场景**：你想了解"中国量化基金行业发展现状"，以确定你的项目是否可以做"量化因子分析仪表板"。

**第1步：定义调研需求**

```markdown
调研主题：中国量化基金行业发展现状（2023-2025）
调研目的：评估"量化因子分析仪表板"产品的市场需求和可行性
关键问题：
1. 中国量化私募基金的规模和数量趋势如何？
2. 主流量化策略类型有哪些？各自的占比和表现如何？
3. 量化基金对数据分析工具的需求痛点是什么？
4. 现有量化分析工具有哪些？用户评价如何？
调研边界：
- 时间范围：2023-2025年
- 地域范围：中国大陆
- 深度要求：概览级，足以支撑产品方向决策
```

**第2步：使用ChatGPT Deep Research进行深度调研**

```
请对中国量化基金行业（2023-2025）进行深度调研，重点关注：

1. 行业规模：量化私募的管理总规模、产品数量、增速趋势
2. 策略分布：股票量化、CTA、固收+、多策略等的占比和变化
3. 典型痛点：量化基金经理和研究员在数据分析方面的主要痛点
4. 工具生态：现有量化分析工具（Wind、聚宽、米筐、掘金等）的功能覆盖和用户评价
5. 技术趋势：AI/ML在量化投资中的应用现状

请提供具体数据和来源，时间范围为2023-2025年。
```

**第3步：使用Perplexity补充验证关键数据**

```
2024年中国量化私募基金管理总规模是多少？请提供具体数据来源。
```

```
聚宽(JoinQuant)和米筐(RiceQuant)量化平台的功能对比，2024年最新情况。
```

**第4步：综合调研报告**

```markdown
# 中国量化基金行业深度调研报告

> 调研人：[姓名] | 日期：2025-07-17 | 工具：ChatGPT Deep Research + Perplexity

## 核心发现
1. 中国量化私募管理规模约1.5-2万亿元（2024年），较2021年峰值有所回落
2. 股票量化策略占比最高（约60%），CTA策略其次（约20%）
3. 中小型量化团队缺乏专业的因子分析工具，依赖自研脚本和Excel
4. 现有平台（聚宽/米筐）偏策略回测，缺少独立的因子研究模块

## 对项目的影响
- "量化因子分析仪表板"方向可行，但应聚焦中小量化团队而非头部机构
- 差异化方向：提供独立的因子研究工具，而非又一个回测平台
- 数据源以AKShare/Tushare为主，降低用户成本
```

## 拓展学习

- **Perplexity AI**：https://www.perplexity.ai/ 以搜索为核心的AI助手，Deep Research模式可以自动执行多轮搜索和综合
- **ChatGPT Deep Research功能**：OpenAI推出的深度调研功能，适合需要综合多个来源的调研任务
- **《学会提问》**：Neil Browne著，批判性思维经典，帮助你评估AI调研结果中信息的可靠性
- **Google搜索技巧**：site:、filetype:、intitle:等高级搜索操作符，提升传统搜索效率
- **学术搜索引擎**：Google Scholar、中国知网、SSRN，用于验证AI提供的学术引用是否真实存在
