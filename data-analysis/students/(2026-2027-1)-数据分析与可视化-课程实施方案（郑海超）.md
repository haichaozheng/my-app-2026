## 三、课程内容概要



### （一）课程指导思想

在新时代背景下，金融数据分析与可视化课程旨在培养具备深厚理论基础和实践能力的复合型、创新型人才。本课程紧密围绕国家金融战略需求与金融强国建设目标，注重理论与实践相结合，强调金融数据分析技术服务于金融安全、服务实体经济与防范化解金融风险的能力培养。

本学期课程全面升级为 **PBL（项目式学习）+ AI赋能** 模式：学生围绕金融领域的真实数据与真实用户需求，在17周内独立构建、上线并公开展示一个属于自己的金融数据分析产品。课程以设计科学研究（DSR）为方法论锚定，使项目实践既具教学真实性又具学术严谨性；通过"AI赋能的一人公司（OPC）+ 互助小组"组织形式，培养学生运用人工智能工具（AI辅助编程、Prompt Engineering、LangChain、RAG、Agent等）解决复杂问题的能力和创新创业思维，使学生有潜力产出公开产品乃至学术论文等高水平成果。

在教学过程中，教师始终坚持正确的政治方向，将思想政治教育贯穿课程各环节；课程同时强调金融伦理、数据合规与社会责任，引导学生树立正确的金融价值观和数据安全观，自觉维护国家金融安全，为构建和谐金融环境贡献力量。

### （二）课程思政

1. 在课程内容中，融入中国数据分析科学发展史。以数据分析科学发展与时代划分的重要联系作为切入点，介绍数据分析科学发展与国民经济发展的重要关系，结合全国金融工作会议精神，强调金融是国家重要的核心竞争力、金融安全是国家安全的重要组成部分，引导学生学好专业课，为国家发展和社会进步贡献自己的力量，培养和树立社会责任感。
2. 将最新的金融数据分析新闻资讯、科研动态、应用实例引入课堂，以我国金融改革发展取得的新成就、人工智能自主创新进展为素材，激发学生的爱国热情和自豪感，激励其为国家振兴、民族强盛而努力学习。
3. 树立典型人物的励志故事，通过介绍取得重大科学技术成就并具有爱国热情的人物和事件，引导青年学生热爱祖国、热爱科学、珍惜美好的学习生活，激发学生爱国情怀以及在本专业创造人生成就的巨大热情。
4. 结合课程特点强化特色思政元素：数据采集合规与数据安全意识（数据安全法、个人信息保护）、科学严谨与诚实守信（批判性思维、不造假、评估有据）、创新创业服务国家需要（普惠金融、服务实体经济）、AI治理与负责任使用人工智能。



### （三）课程目标

1. 理解并掌握利用Python进行金融数据分析的基本思路和方法（采集→清洗→分析建模→可视化完整流程），提高动手能力及独立思考和分析能力。
2. 深入了解Python的各种基础功能以及与数据分析相关的工具：例如NumPy、Pandas、Scikit-learn、statmodels、Plotly、Pyecharts、Streamlit等。
3. 掌握利用API或爬虫等方式从网络获取金融数据的方法，理解数据采集的合规与伦理要求。
4. 掌握机器学习基础模型（线性/逻辑回归、朴素贝叶斯、SVM、决策树与随机森林、神经网络基础）和程序实现方法，能通过多模型公平对比选择模型，并能对模型进行合理评估。
5. 掌握AI赋能的编程工具（opencode、Cursor、Trae等）与AI应用开发技术栈（Prompt Engineering、LangChain、LLM API、RAG、Agent/Skill），能在产品中集成真实解决用户痛点的AI功能。
6. 掌握从真实需求出发发现、验证并产品化一个金融数据分析问题的完整方法（用户洞察、社区调研、快速原型、部署上线、获客与用户反馈迭代），培养创新与创业思维。



### （四）课程要求

1. 按时完成课程资料学习。
2. 按时提交作业。
3. 课程项目：采用"AI赋能的一人公司（OPC）+ 互助小组"模式。鼓励学生5人一组组成互助小组（组内不要求共享同一赛道或领域），**每人独立完成并交付一个属于自己的金融数据分析产品**，学期末公开路演展示。路演时产品须公网可访问，其他同学和观众可当场打开试用。选题来源为财经新闻驱动、真实需求驱动、个人爱好三档，须经用户访谈验证真实需求。
4. 项目工作流：以个人项目仓库（repo）为项目管理中枢，每轮迭代产出/更新 requirements → design → scope 三个文档，并维护一份稳定的 AGENTS.md；git提交历史即学习审计轨迹。
5. 反思与日志：每周提交周反思日志，项目仓库内维护项目日志（journal.md），阶段边界周（W3/W10/W15/W17）须完成含DSR自检的阶段反思。
6. 学术诚信：所有AI辅助使用情况须如实记录；不得抄袭、代做；数据采集须合规。



### （五）教学方法与组织形式

- **PBL六要素**：真实问题（金融社区真实痛点）、持续探究（17周迭代）、学生自主权（三档选题+三选一实验）、反思（双层日志+DSR自检）、同伴互评（W9组内互评）、公开产品（公网部署+路演；路演现场其他人可打开产品）。
- **知识组织方式**：知识按项目阶段而非学科章节组织，按 Challenge→Gap→Knowledge→Apply 节奏在需求时刻引入。
- **AI基础工具栈渐进融入**：Prompt+AI辅助编程（起步）→ LangChain+LLM API（必做）→ RAG（选做升级）→ 建模增强（ML基础与基础模型地图 → 决策树与随机森林课堂讲授+朴素贝叶斯自学 → 对照大模型与传统分析+神经网络基础 → 多模型对比+SVM自学 → 模型评估与产品化）→ AI系统评估（贯穿全阶段）。
- **DSR方法论锚定**：以DSR三循环（相关性/严谨性/设计）与DSRM六步为方法论骨架；产品即artifact、评估即evaluation、用户反馈即相关性循环证据。全员必做"简短DSR定位 + ≥1条有效性（criterion validity）声明"。

## 四、考核方式

采用"**总成绩 = 平时成绩(50分) + 个人项目(50分)**"结构。平时成绩含其他条目40分与协作互评10分。凡打分处一律采用百分制（0-100），评出的百分制分再折算为对应分数。


| 考试形式           | 考察内容                   | 考察方式                        | 分值  |
| -------------- | ---------------------- | --------------------------- | --- |
| 平时 · 其他条目（形成性） | 出勤与参与、技能小练、阶段里程碑、反思与日志 | 教师综合评分后折算（子项不细分）            | 40% |
| 平时 · 协作互评      | 组内互助贡献                 | 期末 360° 匿名互评                | 10% |
| 个人项目（期末，终结性）   | 产品质量、项目报告              | 最终产品 + 公开路演（现场公网可访问） + 最终报告 | 50% |
